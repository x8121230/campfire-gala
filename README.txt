幻界・微光星芽谷 v3.22 紀念品圖鑑

安裝：關閉遊戲，將 src、assets 合併覆蓋到目前 v3.21 專案。只需這兩個資料夾；其他檔案為說明與預覽。這是增量更新，需要保留既有 SouvenirProgression.js、StarsproutInventory.js 與其依賴。

入口：營地或丘陵 → 背包 → 左側「紀念品圖鑑」。
六款繪本美術、大格子、未收集剪影、三種篩選、點選故事、下一級點數與屬性獎勵。鍵盤 Escape 返回背包。
紀念品永久收藏、不佔背包格子。普通1點、稀有2點，同ID只計一次。每級需要5、10、15…點，收藏仍保留；升級循環傷害／敏捷／HP／SP。
圖鑑讀取營地與丘陵共用的既有 souvenirs 存檔，不會重置、補發或改動背包物品。新玩家顯示0/6與未收集剪影。

本版尚未加入取得事件。下一批 v3.23 接首件收藏、首次擊敗南瓜兔與升級回饋；取得方式仍可再討論。
Preview_Souvenir_v3_22.html 可直接用瀏覽器打開；其中3件已收集是展示資料，不寫入遊戲存檔，也不代表已實裝掉落。

驗證：6項模組測試通過，包含唯一ID、點數等值、重複領取、舊存檔、成長循環、存檔往返。尚未進行Windows完整遊戲測試。
