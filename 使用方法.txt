水果數數・幼童版 v0.1｜果園候選・累積直接覆蓋更新版

適用方式：直接貼進「森林益智樂園_v2_完整測試版」

1. 先關閉 Game Viewer。
2. 開啟本壓縮檔，把裡面的 src、assets、docs、使用方法.txt 全部選取。
3. 貼到「森林益智樂園_v2_完整測試版」的根目錄。
4. Windows 詢問時選擇「取代目的地中的檔案」。
5. 重新開啟遊戲。
6. 進入「首頁 → 小遊戲列表 → 觀察推理」。
7. 選擇新卡片「水果數數」。

請注意：
- 不要把外層資料夾 Jump_Climb_Kids_v0_1_Direct_Update 整個再包一層貼入。
- 正確結果是遊戲根目錄原本的 src 與本更新的 src 合併，assets 也同樣合併。
- 本更新是累積版，已包含冰原與火山系列、雲端滑翔、恐龍山谷跑酷、水流迷宮、跳躍登頂、星光湖畔，以及本次水果數數。
- 不需要 DEMO，也沒有 UPDATE 子資料夾。
- docs 只是遊戲方式與更新紀錄，不影響執行。

本次會覆蓋的舊檔案：
- src/main.js
- src/data/MiniGameCatalog.js

本次果園候選新增：
- src/scenes/FruitCountingGame.js
- src/data/FruitCountingData.js

- docs/minigame_updates/水果數數幼童版_v0.1.md

若進入首頁後沒看到「水果數數」，請完全關閉 Game Viewer 後重開；
看到卡片但顯示場景未接入，代表 src/main.js 沒有成功覆蓋。
