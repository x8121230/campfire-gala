森林星航瘋狂隊 v0.5.0｜第一階段：武器與戰鬥

【更新方法】
1. 將壓縮檔解壓縮。
2. 把裡面的 assets、src、tests、docs 與 starflight-play.html 全部複製到「森林益智樂園_v2_完整測試版」根目錄，選擇合併資料夾、取代同名檔案。
   根目錄就是原本 index.html 所在的位置。不要把整個壓縮檔的外層資料夾再套進去。
3. 從原本遊戲列表進入「森林星航瘋狂隊」，確認標題顯示 v0.5。
4. 若要用 GitHub Pages 測試：將變更 Commit，然後 Push origin，等待 Pages 部署完成。
   完成後原遊戲入口仍可使用；也可直接開啟：
   https://x8121230.github.io/campfire-gala/starflight-play.html?v=0.5
   這個網址必須在你上傳本包後才會生效，目前未替你部署。
5. 手機請橫放。舊畫面請重新整理，或加上上面的 ?v=0.5 再開啟。

本包保留根目錄 index.html、src/main.js、衣櫃與存檔系統。
主要覆蓋檔只有星航規則與星航場景；另附專用試玩頁與所需星航素材。
試玩頁可獨立由 HTTP 網站伺服器開啟，不需安裝套件；不要用 file:// 直接雙擊。
本機有 Python 時，可在解壓根目錄執行 python -m http.server 8000，再開 http://localhost:8000/starflight-play.html。

【這版怎麼玩】
左側搖桿／WASD／方向鍵：移動。普攻固定自動三連發，三發後停頓。
J／右下大按鍵：特殊攻擊。
K／空白鍵／大招按鍵：能量滿時使用星光祝福。
L／武器艙按鍵：暫停戰鬥並選擇特殊武器。
P／Esc：一般暫停；在武器艙按下則返回。
Shift：慢速精細移動。
沒有套裝主動技能時不顯示第四顆鍵；本階段尚未串接套裝技能。

【雷射已依最新確認修改】
點一下 → 自動集氣 0.5 秒 → 從機體當下位置向右發射 → 進入 5 秒 CD。
放開或滑出按键不會取消；連點不會重複排隊。
集氣中仍可以移動與自動普攻。
開武器艙暫停集氣；不換武器時返回繼續剩餘集氣。
換成另一把武器會取消尚未完成的集氣，不扣雷射 CD。
已發射的武器保留各自 CD，換回來不會重置。
大招或墜落會取消未發射的集氣，避免演出結束後突然補射。

【三種特殊武器】
聚氣雷射：集氣 0.5 秒；發射後 CD 5 秒；穿透敵人，會被實體地形擋住。
炸裂彈：點一下立即發射；命中後波及附近敵人；CD 4 秒。
幸運草散彈：點一下七向發射；CD 3 秒。
所有傷害、CD 與回能都是第一階段暫定數值，之後依手感調整。

【其他本次完成】
- 2 HP：第一次受傷有短暫無敵；第二次有效受傷進入 1 秒墜落後敗北。
- 本階段心形補給不回血；兩次有效受傷就是本次出擊結束。
- 命中與淨化回能，有回能速度上限；大招傷害不會回充自己。
- 妹妹精靈 3 秒時停演出、全畫面清彈與傷害，恢復後有短暫保護。
- 大招演出使用已有精靈圖片及位移／淡入，尚未使用衣櫃紙娃娃。
- 武器艙暫停全部戰鬥時間，包括敵人、子彈、卷軸、集氣、CD。
- 返回武器艙有 0.8 秒戰場預覽提醒，清除殘留操作輸入。
- 補給星星只強化種子普攻，不再強制切換特殊武器。
- 右側三顆按鍵：特殊攻擊、大招、武器艙；特殊技與大招有獨立聲音與狀態提示。

【接下來的製作順序】
第二階段：森林機艙、3 秒發射動畫、紙娃娃特寫、母上守護安全復活。
第三階段：3～4 個長區域、上下分岔、空中／湖泊／洞穴環境威脅與敵人。
第四階段：其他飛行夥伴、武器、套裝主動技能與隱藏內容。

本次仍沿用 v0.4 的航線與 BOSS 以比較武器手感，尚未改為長區域分岔。
