# 動物點心隊 v0.1｜幼童試玩更新

本版新增獨立遊戲，不修改衣櫃、帽子、公仔、既有地圖或既有小遊戲規則。
整合基準：先前的 wardrobe_v5_3 原始碼。首頁測試列表原有 8 款，新增後為 9 款。

## 先選擇使用方式

| 資料夾 | 用途 | 是否放進正式專案 |
| --- | --- | --- |
| UPDATE | 正式專案需要的增量更新 | 只合併裡面的 src 與 assets |
| DEMO | 不依賴原遊戲的獨立試玩 | 不要覆蓋進正式專案 |
| DOCS | 遊戲方式、素材規格、更新及測試紀錄 | 不必覆蓋 |

## A. 接到你目前的遊戲

1. 先備份原專案，尤其是 `src/main.js` 與 `src/data/MiniGameCatalog.js`。
2. 將 `UPDATE/src` 與 `UPDATE/assets` 的內容合併到專案同名資料夾；不要刪掉原資料夾，也不要把 UPDATE 這一層整個放進 src。
3. 本更新只覆蓋兩個原有檔案：`src/main.js`、`src/data/MiniGameCatalog.js`。其他都是新檔案。
4. 完整關閉再重開 Game Viewer，或瀏覽器強制重新整理。
5. 進入「首頁 → 小遊戲列表 → 全部」第一張卡片，或「反應節奏」分頁，選「動物點心隊」。

**如果你的 main.js 或遊戲總表在 v5.3 之後又加入了其他內容，不要直接覆蓋這兩個檔案。** 請照 DOCS/INTEGRATION.md 合併新增部分，或提供目前版本再整合。

看不到卡片通常是總表尚未更新／快取未刷新；看到卡片但顯示未接入，則檢查 main.js 是否註冊 AnimalSnackGame。新場景自己載入素材，不需要改 PreloadScene。

## B. 只想先試玩

進入 DEMO 資料夾，在該資料夾開啟終端機：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Windows 也可以用 `py -3 -m http.server 8000 --bind 127.0.0.1`。
接著用瀏覽器開 `http://localhost:8000/demo.html`。
DEMO/StartDemo.bat 可在已安裝 Python 的 Windows 上啟動伺服器。
**不要直接雙擊 demo.html，也不要把 DEMO 複製進正式系統。** JavaScript 模組需要 HTTP 伺服器；Phaser 已放在包內，不需連線下載。

## 這一版有哪些內容

- 小兔子／紅蘿蔔、小猴子／香蕉、熊貓／竹子。
- 新生成的三位空手動物與葉翼點心飛行器，透明背景 PNG。
- 點選點心便自動配送；也支援在點心列拖曳，或鍵盤 1、2、3。
- 前三位客人提供圖像提示、沒有催促；後面才開始慢慢移動。
- 送錯會彈開並顯示圖像提示；漏接會重新排隊。
- 十二位客人、三段漸進速度、暫停／說明、音效開關、重玩及返回列表。
- 不扣主畫面愛心，不發放正式寶箱、不解鎖成就、不寫入正式進度。

這是「分類配送」MVP，尚非密集彈幕射擊版。暫不加入多客人同屏、手動瞄準、成人難度、背景音樂、語音、正式獎勵和地圖入口。
