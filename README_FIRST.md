# 森林星航瘋狂隊 v0.8.1｜49 款清單整合修正包

這是正式整合用 `UPDATE`，基底是仁豪於 2026-09-12 上傳的 48 款《森林益智樂園_v2_完整測試版》程式碼。

## 安裝

1. 關閉 Phaser Launcher 中正在執行的遊戲。
2. 備份目前《森林益智樂園_v2_完整測試版》資料夾。
3. 解壓縮本更新包。
4. 將解壓後看到的 `src`、`assets`、`tests`、`starflight-play.html` 等內容，全選複製到遊戲根目錄。
5. Windows 詢問時選擇「取代目的地中的檔案」。
6. 重新使用 Phaser Launcher 開啟專案。

## 正常結果

- 小遊戲總數由 48 變成 49。
- 「全部」第一頁應看到「森林星航瘋狂隊」。
- 「反應節奏」分類也應看到它。
- 點擊卡片後會進入 v0.8.1 飛行機艙。
- 單獨開啟 `starflight-play.html` 時，頁面標題為 v0.8.1。

## 注意

本包已保留你目前的 48 款清單，不要再拿舊 v0.8 完整包覆蓋，否則可能把後續新增遊戲清單蓋回舊版。

詳細修改內容請看 `CHANGELOG_STARFLIGHT.md`。
