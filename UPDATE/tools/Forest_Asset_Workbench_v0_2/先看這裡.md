# 森林素材驗收台 v0.2

這是獨立工具，請解壓到新的資料夾；不用放進「森林益智樂園」覆蓋，也不用啟動遊戲。

v0.2 已改成衣服定稿的四層順序：衣服背景、衣服本體、帽子／髮型／表情、特效。簡單衣服只放「衣服本體」即可。

## 三步開始

1. 解壓縮整包，雙擊 **index.html**。Windows 也可以雙擊 **Start_Forest_Workbench.bat**。建議使用 Edge 或 Chrome。
2. 開啟後已有 6 張範例素材，可以立即換衣服、換帽子、看公仔和首領影格。
3. 按右上角「選取遊戲資料夾」，選你電腦上的「森林益智樂園_v2_完整測試版」根資料夾。

瀏覽器可能將資料夾選取動作稱為「上傳」。本程式不連線傳送檔案，而是在本機瀏覽器內讀取你選的檔案；選取資料夾也不會啟動裡面的遊戲程式。

不用安裝 Python、Node.js 或設定 localhost。請保留 index.html、style.css、core.js、app.js、demo-data.js 在同一個資料夾。

## 四個分頁

| 分頁 | 第一版能做的事 |
|---|---|
| 服裝・紙娃娃 | 選衣服與帽子，切換白／深色／棋盤格背景，開關七個圖層槽位，調整前後順序、X／Y、比例，自動換帽，截圖 |
| 公仔・控制者 | 瀏覽角色圖片，完整圖片／等格切片／標準 Atlas，播放暫停、慢放、單格前後、水平翻轉 |
| 怪物・動作 | 同一影格播放器，可檢查首領與敵人圖集；動畫資料齊全時可播放相應影格序列 |
| 獨立遊戲 | 讀取 MiniGameCatalog.js，核對同名場景檔，查看場景直接引用目錄內的圖片；獨立試玩待接入 |

## 紙娃娃怎麼試

在左側點衣服，再切到「帽子」點一頂。右側點圖層名稱，選擇素材或修改位置。↑ 代表移到更後方；↓ 代表移到更前方。

X／Y 的單位是人物主畫布像素。既有 v5.5、v5.6、v5.9 帽子沿用旧定位公式；非標準尺寸素材可以在驗收台手動調整比例。所有調整只影響目前預覽，不寫回遊戲。

如果你的本機有 PaperDollLayers.js 的靜態 LAYER_FILES／OUTFIT_LAYERS 設定，並且能找到整組圖片，會嘗試載入分層。缺檔時仍使用原版人物圖。可手動替換每層素材來檢查草稿。

**前髮、後髮等空槽位不代表已完成髮型拆圖。** 舊服裝中的人物、衣服、頭髮仍在同一張圖裡，不會因為打開這個工具就自動分離。

## 公仔／怪物怎麼試

- 沒找到角色時，開啟「顯示全部圖片」，或用路徑搜尋。自動分類是依檔名推測，可能需要手動找。
- 等格圖集：選「等格切片」，設定每列幾格、幾列，再指定起始與結束格。影格從 0 開始編號。
- 如果圖集裡是六個不同首領，播放只是逐格巡覽，並不是首領的攻擊動畫。
- 標準 JSON Atlas：程式會找 meta.image 或同名 PNG，支援非旋轉、含裁切位移的影格。旋轉影格會略過並顯示提示。
- 攻擊碰撞、大招範圍、移動 AI、傷害數值仍需要遊戲邏輯接入，第一版不模擬。
- GIF 目前只作靜態畫布擷取，不提供原 GIF 的逐格控制。

## 更新檔案、截圖與回報

- PC 上替換素材後按「重新讀取」，再選同一個資料夾。v0.2 不會在背景監視檔案，也不記住資料夾權限。
- 「檢查」會以最多 512 像素縮圖抽查透明像素，不是保證去背品質通過；請搭配深淺背景看邊緣。
- 「截圖」下載目前預覽的 PNG。
- 在「記下待修項目」輸入問題並加入報告，再按右上角「匯出報告」。JSON 內包含檔名、穿搭、圖層位置、影格、提示及待辦，可直接傳回來讓我修正。
- 待修筆記僅存在本次開啟的頁面。關閉前請匯出；換資料夾不會清掉已寫的筆記，每筆會記錄它的來源。

## 這版先看外型與操作

已備妥四分頁和實際檔案預覽功能，並附資料解析與操作測試。完整的 Windows Edge 實機使用仍待你確認；這個執行環境沒有可用瀏覽器，下載測試瀏覽器也未成功，所以沒有把程式測試稱為實機驗收。

後續依你的使用回饋，優先改善素材分類、角色動作設定與每款遊戲的獨立入口。詳見 TODO.md。
