- [x] 隨附範例，未選資料夾也可以先操作。

- [x] 圖片瀏覽、搜尋、分頁；依路徑推測分類，保留「全部」入口。
- [x] 衣帽混搭，四層槽位開關、排序、位置與比例調整。

- [x] 等格影格播放器、幀率、單格、範圍、翻轉；非旋轉 TexturePacker 類 Atlas。

## 下一輪優先

1. 在你的 Windows Edge 實機試開：資料夾選取、實際圖片顯示、換帽、截圖及匯出報告。
2. 依你最新版 src 修正未辨識的檔名、裝備設定、動態生成目錄及自訂 Atlas。
3. 為各公仔／怪物建立明確的「待機、走路、攻擊、大招」影格設定，避免只靠檔名猜測。
4. 增加碰撞框、攻擊範圍與移動路線的遊戲專用接入模組。
5. 各款獨立遊戲逐一接入隔離試玩；需要攔截正式存檔、服務與場景切換，不能直接開啟主遊戲就聲稱隔離成功。
6. 在穩定的桌面容器或 localhost 版本記住資料夾、更新檔案與驗收設定，減少重新選取。
7. 新拆圖素材完成後，接入真正的前髮、後髮、後飾。槽位存在不等於美術已完成。

## 相容性邊界

- 載入來源程式僅讀靜態字串、陣列及物件；不執行函式、運算式或模板字串。
- 最多讀取 400 份符合條件的 JS 設定，總量 30 MB；單檔上限 2 MB。圖片不受該數量限制。
- 最多檢查 assets 內 120 份 JSON（單檔 5 MB）尋找 Atlas；超出的仍可手動等格預覽。
- 不自動辨識任意畫進圖片裡的棋盤格；透明抽查結果只是線索。
- GIF 動畫與旋轉 Atlas、非等格自訂圖集、外部引用 SVG 不列為 v0.2 完整支援項目。
