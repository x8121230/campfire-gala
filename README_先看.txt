森林小木屋衣櫃 v5.3｜帽子對位與服裝修正版

【適用版本】
請先確認遊戲已套用 v5.2 正式裝備美術版。本檔是 v5.3 增量更新，不會刪除舊素材或存檔。

【套用方法】
1. 先備份正式專案與遊戲存檔。
2. 打開 PATCH_ONLY。
3. 將裡面的 src、assets、docs 合併到遊戲根目錄。
4. 同名檔案選擇覆蓋；不要刪除遊戲中其他檔案。
5. 重新啟動遊戲。若仍顯示舊素材，請強制重新整理快取，但不要清除網站資料或遊戲存檔。

【本版內容】
- 六頂帽子改為完整公仔母版對位，衣櫃與大地圖共用位置。
- 探險遮陽帽移除下巴繩並加寬帽口。
- 野外小偵查、森林精靈服移除內建帽子。
- 新增可獨立穿戴的森林精靈冠。
- 多口袋背心、發光小背心、美味圍裙、銀河特工衣改成主題一致的鞋款。
- 母上的守護新增正式 Q 版穿戴公仔，原照片保留作收藏圖示。
- 保留點一下預覽、再點一次穿戴／脫下，以及獲得全道具測試功能。

【建議測試】
先用測試工具的「獲得全道具（測試用）」補齊道具，再依 PATCH_ONLY/ACCEPTANCE_CHECKLIST.md 驗收。
