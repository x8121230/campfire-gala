幻界・微光星芽谷 v3.17｜技能與手繪背包更新

安裝（以目前已安裝 v3.16 的遊戲為基礎）
1. 關閉遊戲。
2. 將本包的 src 與 assets 合併到遊戲根目錄，覆蓋同名檔案。
   根目錄是含 index.html、src、assets 的那層，不要放到 src 裡面。
3. 重新啟動遊戲；瀏覽器版可 Ctrl+F5 重新載入。
4. Preview_Inventory_v3_17.html 可直接雙擊，查看本版實際背包元件。
   這是獨立互動展示，可切換初始背包／道具展示，不讀寫遊戲存檔。

本次修改
- 武器頁只保留「魔法劍」，改用藍色魔力劍手繪圖示。
- 魔法劍：SP 0，J／空白鍵／畫面魔法劍按鈕。
- 魔法箭：SP 消耗 1，K／畫面魔法箭按鈕，沿面向射出。
  命中第一隻怪物造成 1 傷害後消散；最大射程 520 世界單位；被障礙物阻擋。
- 兩個技能共用既有攻擊冷卻，魔法箭施放硬直 0.45 秒；硬直期間不能移動或格擋。
- SP 上限 3，主動遊玩每 5 秒回復 1；營地／丘陵共用數值與回復進度。
  暫停、開背包、對話、倒地時不計時，離線不回復；復活回滿。
- 背包改為 4 欄大格（24 格容量不變，向下捲動）；短橫屏仍可捲動查看。
- 25 張新手繪圖示覆蓋技能、靈珠及目前常見掉落；快捷三格也換成美術圖。
- 左側移除防具穿戴欄，改成角色＋技能說明＋靈珠槽。
- 舊星光棒轉為魔法劍；盾牌、鞋子等防具不顯示、不佔背包格。
  舊防具數量保留於 retiredEquipment 欄供日後恢復；素材、金幣、容量、靈珠保留。
- 人物原有外觀、格擋與破防規則不變。本包不修改地圖與碰撞資料。
