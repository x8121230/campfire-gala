森林益智樂園 — 啟動與獨立遊戲入口更新包
日期：2026-09-12，累積更新 v2（包含上一包，不需先安裝舊包）

這是更新包，不能單獨執行。請保留你電腦原版的 assets！

安裝步驟
1. 先備份「森林益智樂園_v2_完整測試版」資料夾。
2. 解壓縮本包。
3. 開啟 UPDATE，將「裡面的所有檔案和資料夾」複製到原主程式資料夾。
   合併 src 資料夾；遇到同名檔案選擇取代。不要刪除原本的 src 或 assets。
   正確位置例：F:\森林益智樂園_v2_完整測試版\START_FOREST.cmd
4. 關閉原先執行中的預覽伺服器視窗。
5. 雙擊新的 START_FOREST.cmd。需要電腦已有 Python 3。
6. 瀏覽器會開啟主遊戲。保留命令列視窗，遊戲結束後可關閉它。
7. 主畫面左下角新增「天空・下樓梯・排球」，可選擇 12 款遊戲。
   玩完按上方「返回主系統」。

本次處理
- 新啟動器開啟 index.html。舊 START_WINDOWS.bat 會啟動 wardrobe-preview.html。
- 主入口移除重複的 main.js script 標籤。
- 加入 10 款天空遊戲、森林階梯探險隊及阿晨晨打排球，放在各自的 standalone 子目錄。
- 進入獨立遊戲時暫停當時運作中的主遊戲場景；離開時恢復。
- 這些是獨立遊戲的統一入口，尚未接入主系統獎勵、關卡解鎖或大地圖節點。
- 不需要把各款 game.js 手動貼進 main.js。

注意
- v0_1 / DEMO 是原檔案的版本標籤，接入選單不代表已升級成正式完整版。
- 主遊戲仍使用原本網路載入的 Phaser 3.70.0，需要可連線至 unpkg.com。
- 新啟動器使用 http://127.0.0.1:8771。請使用原本的瀏覽器及使用者設定檔。
  如果以前使用不同網址開啟遊戲，瀏覽器存檔可能不會顯示；本包不遷移存檔。
- 若提示連接埠被占用，先關閉舊啟動器的命令列視窗，再執行新版。
- 本次上傳沒有主系統 assets，因此尚未完成含素材的實機遊玩驗證。
- 排球列在「其他」區域。素材驗收台是工具，不列入遊戲數。
- 此處 12 款是新增入口的數量，不是整個主系統的遊戲總數。

回復方法
用備份恢復原 index.html 及 src/main.js；新增的 standalone、
src/integration/StandaloneLibrary.js、START_FOREST.cmd、START_FOREST.py 可移除。

檢查細節請看 DOCS/檢查報告.txt。

素材驗收台
雙擊 OPEN_ASSET_WORKBENCH.cmd 可獨立開啟，不需要 Python。
也可在新增遊戲選單右上角開啟，工具會另開分頁。
按「選取遊戲資料夾」，選你電腦上含 assets 的原主資料夾。
預覽調整不會寫回遊戲。關閉前請匯出報告，以保留待修筆記。

排球操作
左右鍵移動，↑ 或空白鍵跳躍，P 暫停；也有觸控與陪玩模式。
返回列表會結束當場比賽。原先以 file:// 遊玩的最佳接球紀錄不會自動搬到 localhost。
