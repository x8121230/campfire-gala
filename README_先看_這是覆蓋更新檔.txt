森林星航 v0.9.3｜直接覆蓋更新檔

這不是獨立遊戲，也不是另一份完整樂園。
請勿直接從這個更新資料夾啟動，否則會因缺少其他遊戲素材而停在黑色載入畫面。

正確使用方式：

1. 關閉目前執行中的森林益智樂園。
2. 打開你電腦上原本「有完整 assets」的森林益智樂園_v2_完整測試版資料夾。
3. 將本更新檔內的 index.html、starflight-play.html、src、assets 全部複製進去。
4. Windows 詢問時選擇「取代目的地中的檔案」。
5. 重新啟動森林益智樂園。

正常結果：

- 遊戲列表顯示「森林星航 v0.9.3・隨機連續航線」。
- 進場直接選擇 4 款鳥類機體與 1 款隱藏機械機體。
- 不會再看到紙娃娃搭乘森林芽翼的 v0.8.1 舊機艙。
- 每局隨機抽出 3 個不重複區域，中間以亂流無縫銜接，第三區後進入該區 Boss。

舊版清理：

- 新程式已不再引用 assets/forest-starflight/phase1/standalone.js。
- 該舊檔即使留在資料夾內也不會再執行。
- 若希望實體刪除，可在覆蓋完成後執行「清理森林星航舊版資料.bat」。
