# Moonlight Lake sprite atlas — 2026-09-10

Generated with the image-generation tool, using the existing project storybook atlas as a visual reference. Original generation retained as `moon-atlas.png` (1448×1086). New capybara, otter, frog, black/white swan, reeds, jellyfish, lily pad and willow illustrations.

The source contains a painted checkerboard. `AdventureWorld.load()` crops each sprite and applies the existing edge-connected matte at runtime; white feather interiors are preserved. Orange-on-head capybara detail is drawn in Canvas. Source image is retained unchanged.
