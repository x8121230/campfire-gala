# 草叢探險 6×6 v3.2 BUG 修正紀錄

更新日期：2026-09-09

## 問題

v3.1 的「不用旗也知道」只檢查玩家是否手動插旗，沒有檢查是否踩到危險。因此玩家未插旗、但途中踩到一個危險後仍可錯誤取得成就。

## 正確判定

「不用旗也知道」現在必須同時符合：

1. 本局手動插旗次數為 0。
2. 本局踩到危險次數為 0。
3. 成功翻開全部安全格並通關。

只要踩到一次危險，即使還有勇氣並最終通關，也不會取得此成就、不會增加免插旗完美通關次數，結算畫面也不會顯示「零插旗、零踩雷通關」。

系統在通關後自動標示剩餘危險格，仍不算玩家插旗。

## 判定表

| 手動插旗 | 踩到危險 | 能否取得成就 |
|---:|---:|---|
| 0 次 | 0 次 | 可以 |
| 0 次 | 1 次以上 | 不可以 |
| 1 次以上 | 0 次 | 不可以 |
| 1 次以上 | 1 次以上 | 不可以 |

## 相容性

- 不需要重置舊存檔。
- 第一次進入 v3.2 草叢探險時，會一次性移除 v3.1 的「不用旗也知道」與該項累積次數，避免錯誤成就留在存檔。
- 其他草叢成就、金草圖鑑、分數及關卡進度不會被清除。
- 校正後可用「零插旗＋零踩雷」重新取得成就。
- 6×6 棋盤、免強制插旗通關與草叢綠霧轉場均維持 v3.1 設計。
