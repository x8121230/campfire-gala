# 草叢轉場 v2｜直接覆蓋更新

## 本版重做項目

- 完全移除上一版帶有泥土、樹根與棋盤格背景的草堆圖片。
- 改用三張真正透明的獨立素材：右側草、左側草、前景小草。
- 不再把一張大圖硬切成兩半，因此沒有中央切口與浮島感。
- 動畫固定採清楚的三段順序：`右側草 → 左側草 → 前景小草`。
- 一般進場與重新進場都維持約 1.5 秒，不再刻意縮短重播時間。

## 動畫流程

1. 右側草先輕晃，接著向右撥開。
2. 左側草稍晚晃動，再向左撥開。
3. 畫面下方的小草最後抖動，向下壓開並淡出。
4. 關卡畫面藏在草葉後方，由 96% 平順放大到 100%。
5. 每一段搭配輕柔撥草聲、少量葉片及小星光。

## 操作與安全保護

- 轉場期間會鎖住滑鼠與觸控操作。
- 快速連按確認只會進入一次，不會重複扣除資源。
- 三張素材若有任何一張載入失敗，會自動直接進入關卡，不會卡在黑畫面。
- 系統開啟「減少動態效果」時，仍會改用簡短淡入以照顧容易暈動的玩家。

## 遊戲方式（草叢探險）

1. 在森林地圖選擇 `草叢探險`。
2. 閱讀關卡說明並按下確認。
3. 等待右、左、前景三層草葉依序撥開。
4. 畫面完全展開後，開始找危險、插旗與挖草。

## 覆蓋方式

將 ZIP 解壓後，把裡面的內容複製到：

`F:\森林益智樂園_v2_完整測試版\`

選擇「取代目的地中的檔案」。本包只包含本次新增或修改的檔案。

## 本包檔案

- `index.html`：載入草叢轉場補丁。
- `src/patches/GrassTransitionPatch.js`：保留現有進場規則，只攔截草叢關卡換場時機。
- `src/systems/SceneTransitionManager.js`：載入三張素材、鎖定操作與失敗保護。
- `src/scenes/GrassTransitionScene.js`：1.5 秒三段式動畫。
- `assets/transitions/grass_left.png`：左側透明草葉。
- `assets/transitions/grass_right.png`：右側透明草葉。
- `assets/transitions/grass_front.png`：底部透明前景草葉。

## 預留 GM 參數

- `gm_transition_enabled`：開啟或關閉轉場。
- `gm_transition_speed`：`0.5～2`，預設 `1` 即約 1.5 秒。
- `gm_transition_reduce_motion`：強制使用淡入簡化版。

## 建議測試

1. 確認畫面沒有灰白棋盤格、黑底或泥土樹根。
2. 確認順序是右側草先動、左側草後動、前景草最後向下。
3. 快速連按確認，確認只進場一次。
4. 返回地圖後再次進入，確認仍播放完整約 1.5 秒。
5. 進入其他小遊戲，確認不會播放草叢轉場。
