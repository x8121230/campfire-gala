# 草叢探險 6×6 v3.1 更新紀錄

更新日期：2026-09-09  
基準版本：本次提供的 `src.rar`  
套用方式：將更新檔內的 `src` 資料夾直接覆蓋到遊戲專案根目錄。

## 本版結論

- 保留並直接修改現有的 6×6 踩地雷玩法，沒有重新製作棋盤。
- 取消「安全格全部挖完後，還必須替危險格插旗」的強制流程。
- 全部安全格翻開時立即通關；尚未標記的危險格由系統在結算前依序亮相。
- 新增免插旗成就「不用旗也知道」。
- 舊版 5×5「挖掘＋答題」已從有效關卡資料移除；答題概念保留，未來另做獨立小遊戲。
- 草叢進場改成先完整停留 0.5 秒，再依序撥開右草、左草與前景草，並同步讓綠色霧氣漸散。

## 勝利判定修正

舊判定把「危險全部插旗」視為必要條件，所以玩家即使已經推理完所有安全格，仍會被迫補旗。

新判定只檢查：

1. 棋盤已生成。
2. 所有非危險格都已翻開。
3. 符合後立刻鎖定操作並進入勝利流程。

旗子現在只是協助記憶的工具。若先正確標出所有危險，但仍有安全格未翻開，遊戲會提示繼續挖開安全格，不會提早通關。

## 免插旗成就

| 項目 | 規則 |
|---|---|
| 成就 ID | `bush_no_flag` |
| 顯示名稱 | 不用旗也知道 |
| 達成條件 | 同一局從開始到通關，手動插旗次數為 0 |
| 拔旗處理 | 曾經插過旗，即使之後拔除，也不算免插旗 |
| 自動展示 | 結算時系統自動標示危險，不計入玩家插旗次數 |
| 存檔統計 | `minigame_stats.treasure.noFlagClearCount` |

草叢探險成就總數由 5 項調整為 6 項；世界地圖、GM 測試重置與黃金蟲解鎖檢查均已同步。

## 草叢進場時間軸

| 時間 | 畫面行為 |
|---:|---|
| 0–0.5 秒 | 左右與前景草幕完整出現，綠色霧氣覆蓋畫面，讓玩家先看清楚 |
| 0.5 秒 | 右側草先輕晃 |
| 0.6 秒 | 右側草向右撥開、關卡畫面出現、綠霧開始散去 |
| 0.85–0.95 秒 | 左側草輕晃後向左撥開 |
| 1.25–1.36 秒 | 前景草輕晃後向下退出 |
| 2.0 秒 | 轉場結束，畫面完全清晰並恢復操作 |

未使用相依性較高的即時模糊濾鏡，而是用多層綠色霧幕、透明度與鏡頭淡入模擬「霧化轉清晰」，可降低不同瀏覽器或裝置不支援特效的風險。

## 相容性與保留內容

- 舊存檔若沒有 `noFlagClearCount`，會自動以 0 讀取，不需重開存檔。
- 已經解鎖黃金蟲的舊存檔仍保持解鎖，不會因新增第 6 項成就而被收回。
- `src/scenes/BushExplore.js` 與 `src/data/BushExploreData.js` 屬舊版原始碼備份，現有入口不會載入；本版不覆蓋它們，也不把答題玩法重新接回主流程。
- 營火晚會、點點螢火、星空連線及其他遊戲的玩法與存檔沒有被本版改動。

- 規則測試已確認：安全格全開會通關、仍有安全格時不會通關、只插完危險旗也不能跳過安全格。
