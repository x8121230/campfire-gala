# 營火晚會＋點點螢火轉場 v1｜直接覆蓋更新

## 本版內容

### 營火晚會

- 點擊關卡確認後播放約1.5秒進場動畫。
- 中央營火由小變大，暖光向外擴散。
- 兩批火星向上飄散，再淡入遊戲畫面。
- 使用程式繪製圖形，不加入風格不一致的大型圖片。

### 點點螢火

- 點擊關卡確認後播放約1.5秒進場動畫。
- 左右兩側共18個螢光點陸續飛入。
- 螢光在中央周圍聚集，再由中央柔光揭開遊戲畫面。
- 螢光只使用黃白暖光，不會與遊戲內紅、藍、綠目標顏色混淆。

### 保留原功能

- 草叢轉場 v2 原樣保留。
- 星空連線與森林歷險仍維持原本進場方式。
- 不修改營火晚會或點點螢火的玩法、分數、音樂、獎勵與紀錄。
- 轉場失敗時會直接進入關卡，不會卡在黑畫面。

## 水關卡概念（本版未實作）

> 右側小泡泡浮起 → 左側中泡泡浮起 → 中央大泡泡浮到畫面中央 → 大泡泡破裂後進入水關卡。

水關卡玩法與場景ID尚未確定，因此本版只記錄概念，不加入程式。

## 覆蓋方式

1. 關閉遊戲。
2. 解壓縮更新檔。
3. 將解壓後的 src 與 更新說明 複製到遊戲主資料夾。
4. 選擇「取代目的地中的檔案」。
5. 重新開啟遊戲。

## GM預留設定

- gm_transition_enabled：所有進場轉場總開關。
- gm_transition_grass_enabled：草叢轉場開關。
- gm_transition_campfire_enabled：營火轉場開關。
- gm_transition_firefly_enabled：螢火轉場開關。
- gm_transition_speed：0.5～2，預設1約為1.5秒。
- gm_transition_reduce_motion：強制只使用淡入簡化版。

本版先預留設定鍵，後續再接入GM各遊戲分頁。

## 建議測試

1. 進入草叢探險，確認原本三段草叢動畫仍正常。
2. 進入營火晚會，確認火苗、暖光與火星完整播放。
3. 進入點點螢火，確認左右螢光聚集後順利顯示關卡。
4. 在確認按鈕快速連點，確認只會進入一次且不重複扣除資源。
5. 進入星空連線與森林歷險，確認不會誤播營火或螢火動畫。
