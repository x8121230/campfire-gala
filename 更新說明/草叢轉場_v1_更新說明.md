# 草叢轉場 v1｜直接覆蓋更新

## 這版做了什麼

- 在地圖確認進入 `草叢探險` 後，先鎖住滑鼠／觸控輸入，避免雙擊重複進場。
- 兩片草叢先輕輕晃動，再分別向左、向右倒開。
- 草叢撥開時加入葉片、柔和星光與撥草音效。
- 關卡畫面會在草叢後方由 96% 放大到 100%，減少生硬跳頁感。
- 一般進場約 0.9 秒；資料若帶有 `replay: true`，會自動使用較快版本。
- 支援系統「減少動態效果」設定：會改用約 0.15 秒的柔和淡入。
- 轉場素材第一次使用才載入，載入失敗時會直接進入關卡，不會卡死。

## 遊戲方式（草叢探險）

1. 在森林地圖點選 `草叢探險`。
2. 閱讀關卡說明後按下確認。
3. 等待左右草叢撥開，即可開始找危險、插旗與挖草。
4. 轉場期間不需要操作；連點也只會進入一次。

## 覆蓋路徑

請把本資料夾內的內容複製到：

`F:\森林益智樂園_v2_完整測試版\`

選擇「取代目的地中的檔案」。本包只包含本次新增或修改的檔案。

## 本包檔案

- `index.html`：載入草叢轉場補丁（只新增一行模組引用）。
- `src/patches/GrassTransitionPatch.js`：保留原關卡規則，只攔截草叢進場時機。
- `src/systems/SceneTransitionManager.js`：共用轉場入口、載入保護與 GM 設定接口。
- `src/scenes/GrassTransitionScene.js`：左右草叢、葉片、音效與淡入動畫。
- `assets/transitions/grass_part.png`：草叢轉場圖像。

## 預留 GM 參數

目前程式已支援下列 Registry 值，之後可接到 GM「共用」分頁：

- `gm_transition_enabled`：`true / false`，開關所有此類進場動畫。
- `gm_transition_speed`：`0.5 ~ 2`，數值越大播放越快。
- `gm_transition_reduce_motion`：`true / false`，強制使用淡入簡化版。

## 建議測試

1. 在地圖進入 `草叢探險①`，確認左右草叢方向正確。
2. 快速連按兩次確認，確認不會扣兩次資源或開兩個關卡。
3. 返回地圖再進入一次，確認轉場可重播。
4. 確認其他小遊戲仍維持原本直接進場方式。
5. 在作業系統開啟「減少動態效果」後重試，確認會改為快速淡入。
