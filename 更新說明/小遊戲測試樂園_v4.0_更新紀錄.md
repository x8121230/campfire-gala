# 小遊戲測試樂園 v4.0 更新紀錄

更新日期：2026-09-09

## 本版目的

把首頁原本只有六顆固定按鈕的「MINI」測試頁，改為可持續擴充的小遊戲總表。這個入口只用於快速測試，不取代正式世界地圖，也不會改寫正式獎勵與進度。

## 已完成內容

### 1. 首頁入口與總表畫面

- 首頁按鈕由「MINI」改為「小遊戲測試」。
- 總表標題改為「小遊戲測試樂園」。
- 採 3 欄 × 2 列卡片版面，每頁最多顯示 6 款遊戲。
- 「全部」目前有 8 款，因此分成 2 頁；支援畫面按鈕、滑鼠滾輪與鍵盤左右鍵換頁。
- 移除尚無內容的「遊戲 F（預留）」卡片，等遊戲確定後再加入目錄。

### 2. 分類分頁

| 分頁 | 收錄遊戲 |
|---|---|
| 全部 | 目前 8 款全部顯示 |
| 觀察推理 | 草叢探險①、星空連線① |
| 配對記憶 | 森林歷險①、記憶翻牌 |
| 反應節奏 | 點點螢火①、營火晚會① |
| 棋盤策略 | 形色棋、象棋暗棋 |

### 3. 單一遊戲目錄

- 新增 `src/data/MiniGameCatalog.js`。
- 遊戲名稱、分類、場景、說明、狀態、色彩與啟動參數集中管理。
- 後續新增遊戲時，只需新增一筆目錄資料，總表會自動產生卡片與分類數量。

### 4. 安全測試模式

- 從測試總表進入時，直接繞過正式關卡解鎖與消耗判定。
- 不消耗愛心，也不發放正式寶箱或其他正式資源。
- 進入遊戲前暫存 Registry；測試期間即使遊戲執行結算、圖鑑或成就邏輯，也不會寫入正式存檔。
- 回到測試樂園時，自動還原測試前資料。
- 正式地圖進入遊戲的流程完全不變，仍會正常保存紀錄與獎勵。

### 5. 返回行為統一

- 草叢探險①已移除硬編碼的「只能回世界地圖」。
- 五款主要幼童遊戲從測試總表進入時，左上按鈕顯示「回樂園」，結算按鈕顯示「回測試樂園」。
- 「再玩一次」會保留測試狀態，不會在重新開始後誤寫正式存檔。
