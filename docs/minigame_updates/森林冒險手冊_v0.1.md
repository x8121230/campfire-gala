# 森林冒險手冊 v0.1

累積整合更新，保留原 19 款遊戲、寶箱 v0.3 當場開啟與測試工具。將 ZIP 內 src、assets、docs、tests 覆蓋到原完整主遊戲，關閉舊分頁後重開。需要既有完整主專案與 v5.3 衣櫃，不是獨立試玩版。

## 入口與內容

遊戲列表上方「冒險手冊」可直接進入；寶箱小屋中間也新增「森林冒險手冊」。手冊返回按鈕會回到進入它的頁面。

- 裝備圖鑑：依原裝備資料顯示 20 項裝備，未取得以深色剪影表示；支援只看未取得、六格分頁及點擊詳情。秘密裝備未取得時以「神秘裝備」標示。
- 取得來源：初始、特殊事件與寶箱來源分開說明。寶箱共用裝備池，推薦來源不是限定來源；沒有對應偏好來源的裝備會標示五種皆可能取得，不保證一定抽中。
- 套裝收集：森林探險家、螢光精靈、森林料理家、星空旅人，每組使用現有帽子、服裝和全套公仔共三件。這是收集目標，不代表三件可以同時穿戴。
- 成就手冊：先整合草叢探險既有六項正式成就，顯示達成狀態、條件和計數。目標數讀取目前遊戲設定；已達成以原 achievements 存檔為準，手冊不自行授予成就或重複發獎。測試入口的舊通關統計會還原，正式成就請從地圖挑戰。
- 我的展示：集齊套裝後，進入手冊會一次解鎖對應稱號與背景，出現星光提示。可選擇並保存展示主題，搭配該套裝公仔。展示稱號目前只在手冊展示台使用，不影響換裝、數值或遊戲能力。

美術重用現有衣櫃公仔；新展示背景與星光以遊戲繪圖和動畫製作。套裝首次完整時在下次進入手冊解鎖，不必重抽已擁有裝備。測試工具取得的裝備也計入收集。

## 保存與驗證

原存檔新增 collection_goals_v1，保存已解鎖套裝與選定展示。既有愛心、寶箱、裝備、成就和不認識的欄位均保留。解鎖重複檢查不再發一次提示；不相容版本停止寫入。

368 項自動測試通過（原 356 加 12 項手冊規則）。另使用既有裝備資料與模擬顯示／輸入，驗證四組裝備 ID、首次解鎖、圖鑑／未取得篩選／詳情／成就／展示選擇與返回連結。真實瀏覽器、手機字體與點按仍待試玩。其他遊戲成就、金草及生物收藏圖鑑、冒險紀錄尚未接入這一版手冊。

後續入口：EquipmentJournal.js 為手冊場景；CollectionGoals.js 為套裝／来源／保存規則；AdventureAchievements.js 為既有成就對照。請以最新累積 ZIP 接續，避免舊更新覆蓋新遊戲。
