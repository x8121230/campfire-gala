# 企鵝冰塊推推樂 v0.1｜幼童試玩版

## 目標

移動小企鵝，把所有藍色冰塊推到發光圓圈，完成五個冰橋任務。

## 操作

- 鍵盤：方向鍵或 `W/A/S/D` 移動，`Z`／Backspace 復原，`R` 本關重來，`P`／Esc 暫停。
- 滑鼠與觸控：使用右側四個方向大按鈕。
- 也可以直接點企鵝旁邊相鄰的冰格。

## 幼童友善規則

- 沒有倒數、生命與失敗結算。
- 每一步都能復原，也能隨時重來本關。
- 「提示下一步」會計算目前局面可完成的路徑，亮出建議方向。
- 如果冰塊真的卡住，提示會請玩家復原或重來，不會提供錯誤方向。
- 第一關只需推動一次；後面逐步加入轉彎與兩塊冰。
- 切到背景或視窗失焦會自動暫停。
- 不扣主畫面愛心、不發寶箱、不解鎖成就、不修改正式存檔。

## v0.1 驗收重點

1. 棋盤、企鵝、冰塊是否夠大且容易辨認。
2. 點擊相鄰冰格與方向按鈕是否容易操作。
3. 五關難度是否適合孩子。
4. 復原、重來與提示是否直覺。
5. 完成一關後是否能正常進入下一關。
