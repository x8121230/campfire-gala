# 森林快遞調度站 v0.1

2026-09-09。使用者希望繼續新增小學生程度、有深度與變化性的遊戲，並延續「直接合併森林益智樂園，不做獨立試玩版」的交付方式。本次新增路網配送規劃遊戲，主列表增至 14 款，分類為「棋盤策略」（4 款）。

## 玩法與設計

玩家帶領浣熊快遞員，在六站森林路網間安排裝貨與送件。每站可以選擇前往直接相連的站點；包裹必須在原站手動裝入，送到目的地自動交件。孩子需要一起考慮「先送誰、一次帶多少、走哪一條路」，並比較輕裝捷徑與重貨繞行的取捨。

主線 18 關，另有 12 組固定變化委託，合計 30 份可自由選擇的任務。變化委託會改變出發站、部分收件站與道路路程，並調整鮮度上限。它們有可重現的固定配置，並非每次重玩無限隨機生成；30 份配置都經過可解性驗證。

主線前六關介紹基本規則，第 7–12 關加入橋樑、解鎖、前置順序，第 13–18 關加入保鮮與多項限制。第 17 關需要先送齊食材及許可才能領慶典點心；第 18 關要在限重、鮮貨、前置與回件間安排順序。熟悉裝貨後可直接跳至後段或變化委託。

## 明確規則

- 背包容量以「重量格數」計算，不是包裹件數；送出後即釋放容量。
- 道路兩向皆可行，數字表示一次通過所花路程。不能點沒有直連道路的遠站跳過中間站。
- 「限 N」檢查整個背包的總重量；空背包也算 0 格。
- 「橋 N」須到帶相同編號扳手的站點操作後才能通行；可再次收起。兩座橋各自獨立。
- 「先 A」道路要在 A 包裹實際送達後才開放；僅裝在背包中不算。
- 有前置條件的包裹，要先將指定包裹全部送達才能領取。不是只要到過相關站點。
- 鮮貨的上限是載貨後可移動的路程；走路才消耗，思考、提示、裝卸與操作橋樑都不消耗。
- 恰好用完保鮮路程到達可成功。超過上限則先判定失敗，不會交件；可以撤回，不會扣愛心。
- 已載貨包裹只能在原取貨站放回；已消耗的鮮度不會重置。放在原站時暫停消耗，重新領取會接續原剩餘值。
- 有「須返站」的委託，所有包裹送達後還要回到標「起」的出發站才完成。變化委託的起點可能不是郵站。
- 地圖上的快遞員移動有短動畫，期間忽略連點及其他遊戲操作。每次合法操作按完整一步處理，動畫只呈現已確定的移動。

## 操作、提示與星星

| 操作 | 方式 |
| --- | --- |
| 前往下一站 | 點地圖站點，或 1–6 |
| 裝入／放回包裹 | 右側按鈕，或 A–D |
| 操作橋樑 | 目前站的扳手按鈕，或 T |
| 撤回 | Z／Backspace／畫面按鈕 |
| 分段提示 | H／畫面按鈕 |
| 重來 | R／畫面按鈕，先顯示確認 |
| 暫停 | P／Esc／畫面按鈕；離開視窗也會自動暫停 |
| 查看規則 | 右下角「規則」 |

撤回完整還原位置、載貨、送達、橋樑、路程及鮮度；已使用提示的次數保留。前兩次提示提供思路，第三次起以目前狀態計算下一個可完成的動作，不自動幫玩家操作。鮮貨已超程時，先提示撤回，該提醒不算使用解題提示。

三星分別為全部完成、在精準路程目標內完成、不使用提示。第 1–6 關的精準目標比最短解寬一個路程，第 7 關以後與變化委託採最短路程。路程目標只影響星星，超出仍可通關，沒有總路程失敗上限。

暫停會凍結移動動畫及提示計算，回到視窗後需手動繼續。移動途中返回選關，保留該次已確定的移動；若該步完成任務，記錄星星後返回，不讓舊動畫干擾下一關。

返回選關可保留當前未完成委託，點同一份委託即可接續；開始其他委託會開新局。每份委託保留本次開啟中最高星數，重玩不會降低已獲得星數。返回主遊戲再進來可保留本次場景記錄，關閉或重新載入頁面後清空。

## 程式整合

新增：

- `src/data/CourierRules.js`：純規則、載貨與橋樑狀態、撤回、星星及分批 Dijkstra 最短路程搜尋。
- `src/data/CourierLevels.js`：18 關主線、12 組可重現變化委託與校準後目標。
- `src/scenes/ForestCourierGame.js`：選關、圖像路網、移動動畫、任務卡、裝卸、暫停及結算。
- `assets/forest-courier/`：兩份新生成美術。
- `tests/courier_rules.test.mjs`、`tests/courier_scene.test.mjs`：本次規則及場景模擬測試。

修改 `src/main.js` 加入場景註冊、`src/data/MiniGameCatalog.js` 加入第一張入口卡。舊測試僅更新總表數量和入口位置預期。舊遊戲場景、規則及素材保持原檔內容；本包累積保留前五款新增遊戲。

場景沿用 AnimalSnackGame 的文字、面板、按鈕與音效工具，遊戲規則獨立。沿用既有分類總表 v4.0 的分頁與返回入口；不更動衣櫥、地圖、正式獎勵與存檔機制。

## 驗證與限制

98 項自動測試通過：本次規則 19 項、場景模擬 14 項、森林光路工坊／森林機關探險／海洋清理隊既有回歸 65 項。

30 份委託均可解，皆可在目標內取得三星。規則測試額外驗證容量、總載重限路、雙橋獨立控制、送件通行證、多前置、鮮度邊界與超程、放回不刷新鮮度、完整撤回、返站、最短路程搜尋與不可解結果。

場景模擬逐一操作 30 份委託到完成，覆蓋快速連點、鍵盤、途中暫停、最後一步返回選關、提示、重來、切換主線／變化及離開清理。中文長句啟用逐字換行，並檢查底部站名與道路圖例的間距。

自動測試使用 Phaser API 模擬，不代表完整瀏覽器畫面或真實觸控已測。仍需在使用者完整專案內確認 Game Viewer 實際畫面、觸控與音量。

測試輸出見 `森林快遞調度站_測試結果.txt`。開發時可在包根目錄執行：


## 後續延續

持續以小學生能力、推理深度、規則組合與玩法差異為優先。交付維持一份直接覆蓋的整合 ZIP；不要恢復 UPDATE／DEMO 分層。下次若調整本遊戲，先依實玩回饋處理路網可讀性、鮮貨難度與精準星門檻，再考慮多快遞員協作等新機制。
