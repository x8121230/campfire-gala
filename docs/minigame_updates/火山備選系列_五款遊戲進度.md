# 火山備選系列・五款遊戲進度

| 順序 | 遊戲 | 狀態 | 核心能力 |
| --- | --- | --- | --- |
| 1 | 啵啵彩色岩漿泡泡 | v0.1 完成 | 因果關係、手眼協調、動態追蹤 |
| 2 | 彈果翼龍的化石拼圖 | v0.2 完成 | 形狀認知、空間拖曳 |
| 3 | 火山寶石分類車 | v0.3 完成 | 色彩辨識、分類邏輯 |
| 4 | 溫泉水豚躲貓貓 | v0.4 完成 | 短期記憶、專注力 |
| 5 | 造橋過果凍海 | v0.5 完成 | 大小排序、基礎邏輯 |

## 第 1 款：啵啵彩色岩漿泡泡 v0.1

- 新增獨立「火山備選小島」地圖，第一款開放，其餘四款保留清楚位置。
- 火山主地圖右上角新增「備選小島」入口，首批五款的位置不改動。
- 果凍岩漿會持續冒出五種彩色大泡泡；直接點擊即可變成星星和彩帶。
- 點空白處會在該處長出新泡泡，提供一歲半幼兒清楚的因果回饋。
- 每第六顆產生彩虹大泡泡；完成 24 顆後觸發滿版火山彩帶派對。
- 寶寶模式預設開啟：泡泡更大、更慢、同時數量較少。
- 泡泡飄出畫面不算失敗，會從岩漿底部重新回來。
- 支援觸控與滑鼠，空白鍵可啵掉最接近上方的泡泡，B 切換模式。
- 測試版不寫入正式存檔、裝備、寶箱或成就。

## 第 2 款：彈果翼龍的化石拼圖 v0.2

- 五面化石牆由三塊逐步增加至七塊大型化石。
- 支援拖曳到相同輪廓，也支援點一下自動吸附，兼顧不同年齡操作。
- 放錯會自動回到化石盒，不扣分、不會造成關卡無法完成。
- 新增發光提示、本關重來、完成星光及五關結算。
- 化石包含身體、頭、左右翼、尾巴，以及彈果翼龍專屬的硬果護甲與岩石背甲。
- 完成後復活為固定飛行夥伴造型：青綠翼膜、橘金護甲、硬果與岩石裝飾；不套用紙娃娃換裝。
- 復活翼龍會拍翼飛過火山洞穴，保留未來替換正式角色圖的接口。

## 第 3 款：火山寶石分類車 v0.3

- 五車寶石由單一紅色開始，再加入紅黃雙色，最後進入紅、黃、藍三色分類。
- 每關寶石數量由三顆逐步增加至七顆，保持短回合與清楚進度。
- 支援先點寶石再點桶子，也能直接把寶石拖入相同顏色的礦車桶。
- 提示光圈預設開啟；選取寶石後會亮出正確桶子，也可切換關閉挑戰。
- 分錯不扣分，寶石會彈回原位並亮出正確顏色；漏接則從火山口重新出現。
- 新增顏色提示、金屬叮噹回饋、寶石星光與五關完成結算。
- 支援鍵盤 1／2／3 分類、H 提示、B 切換提示光圈。
- 火山、寶石、礦車桶及特效全部由 Phaser 程式繪製；不寫入正式存檔與獎勵。

## 第 4 款：溫泉水豚躲貓貓 v0.4

- 五關由三座溫泉、一隻水豚開始，逐步增加到六座溫泉與五種水豚造型。
- 每輪水豚先一起探頭，玩家記住位置後，再依題目找出指定裝飾的水豚。
- 造型包含頭頂橘子、小花、小毛巾、葉子，以及沒有戴東西的普通水豚。
- 前兩關保留空溫泉降低難度；後三關逐步增加角色與干擾選項。
- 找錯不扣分，點到的溫泉會先揭曉，接著全部水豚再次露臉供玩家重新記憶。
- 新增「再看一次」與預設開啟的慢速觀察模式，無倒數、無生命失敗。
- 支援直接點溫泉、鍵盤 1～6、H／空白鍵重看，以及 S 切換速度。
- 水豚、裝飾、溫泉、熱氣及星光全部由 Phaser 程式繪製；不寫入正式存檔與獎勵。

## 第 5 款：造橋過果凍海 v0.5

- 五關從兩塊浮石開始，逐步增加為最大、大、中、小、最小五種尺寸。
- 浮石每關會打亂排列，玩家必須依照從大到小的順序鋪成階梯橋。
- 支援點一下自動放置，也能直接拖曳到海面上下一個發光位置。
- 順序錯誤不扣分，浮石會回到岸邊，防風鏡小熊會搖頭並提示下一塊。
- 小熊提示預設開啟，可關閉金色位置光圈進行純大小排序挑戰。
- 新增下一塊提示、本關重來、星光回饋及小熊逐階跳過果凍海動畫。
- 支援鍵盤 1～5 選石、H 提示、R 重來，以及 B 切換小熊提示。
- 小熊、浮石、群島、果凍海及特效全部由 Phaser 程式繪製；不寫入正式存檔與獎勵。

## 火山備選系列完成狀態

- 啵啵彩色岩漿泡泡、彈果翼龍的化石拼圖、火山寶石分類車、溫泉水豚躲貓貓、造橋過果凍海均已完成可測版本。
- 五款遊戲共用「火山備選小島」入口，五座島嶼目前已全部點亮開放。
- 難度涵蓋因果點擊、形狀拼圖、顏色分類、短期記憶及大小排序。
