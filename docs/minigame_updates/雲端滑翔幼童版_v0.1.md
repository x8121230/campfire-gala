# 雲端滑翔・幼童版 v0.1

## 核心玩法

- 小探險家自動向前滑翔，按住畫面上升、放開後緩慢下降。
- 穿過 12 個大型順風圈完成旅程，每個順風圈會點亮一顆天空星星。
- 共分三段：先練習升降，再加入軟雲，最後擴大順風圈的高度變化。

## 幼童友善設計

- 慢速飛行預設開啟，並提供可關閉的金色方向箭頭。
- 漏過順風圈不扣分，下一個順風圈會繼續出現，直到完成 12 個。
- 碰到雲朵不會墜落或失敗，只會播放柔軟彈開效果並繼續飛行。
- 飛到畫面上、下邊界會安全回彈，沒有生命、倒數或強制結束。
- 支援觸控、滑鼠、空白鍵、方向鍵上／W；H 顯示提示，S 切換速度，A 切換箭頭。

## 整合範圍

- 首頁「反應節奏」新增「雲端滑翔」入口卡。
- 場景、規則與測試分離，方便後續加入雲端島嶼大地圖與正式紙娃娃顯示層。
- 本版使用程式繪製的 Q 版小探險家替代顯示，不寫入正式裝備、獎勵或成就。
