# 星之森 v0.5：場景與任務演出優化

本版依實際試玩畫面修正 2.5D 手繪繪本版。原 3D 版、其他遊戲及兩版既有進度均保留；仍是一份可直接合併覆蓋的累積整合包。

## 安裝

關閉遊戲，解壓 `Star_Forest_v0_5_Storybook_Polish_Integrated.zip`，把包內內容貼入原「森林益智樂園_v2_完整測試版」，合併資料夾並取代同名檔案。沿用原啟動方式，不要清除網站資料。

## 本次調整

- 移除草地中央交叉的棕色裂縫，恢復完整連續森林；土層厚度只顯示在整座地圖外圍。
- 小路縮窄約兩成，以不規則草邊與柔和色階融入場景。
- 發光蘑菇分成大小地標，降低滿畫面重複大型素材的感覺。
- 主角、NPC 與動物加入接觸柔影；主角增加淡色輪廓、待機呼吸與微幅浮動。
- 生氣條換成三個可愛的小烏雲，泡泡命中後逐一消失；蜂蜜定身時改成小花提示。
- 左上資訊卡縮小，讓手機橫向畫面保留更多森林視野。
- 靠近 NPC 後先暫停操作、播放提示音、出現星光提示，再讓鏡頭看向雙方並彈出對話框。
- 對話框加入 NPC 頭像、果凍式彈出動畫、大字體、較寬行距及逐字顯示。點一下文字可立即顯示全文。
- 對話結束後恢復鏡頭與操作；離開感應範圍再靠近才會重新觸發。

## 操作與存檔

手機橫放：左搖桿移動，右側使用泡泡、蜂蜜、蒲公英與大象魔法。鍵盤使用 WASD／方向鍵、J、Q、空白鍵、R；E 操作風鈴與路牌，M 地圖，Esc 暫停。

3D 原版使用 `forest_star_forest_ch1_v1`；2.5D 手繪繪本版使用 `forest_paper_forest_ch1_v1`，重玩其中一版不會清除另一版。

## 驗證範圍

規則測試涵蓋主線完整行走、魔法、護送、事件、存檔及 NPC 防重複觸發。瀏覽器測試涵蓋鍵盤、觸控、多指操作、橫直向切換、兩版切換與獨立存檔；另檢查任務停頓、延遲開窗、逐字顯示與點擊跳過。實體手機與原完整 Game Viewer 仍需安裝後試玩。
