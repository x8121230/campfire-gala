# 水果數數・幼童版 v0.1

## 核心玩法

- 看左側指定的水果與數量，在果園裡點選正確水果。
- 正確水果會飛進右側果籃，畫面逐顆顯示目前數字與剩餘數量。
- 共五關，依序練習數 1、2、3、4、5 顆水果。
- 水果包含蘋果、橘子、水梨與草莓；每關混入 2～3 種大型干擾水果。

## 幼童友善規則

- 點到別種水果不扣分、不清空已收集數量，只會說明水果名稱並提醒目標。
- 「水果提示」可不限次數使用，會讓下一顆正確水果發光。
- 沒有倒數、生命、步數限制或失敗結算。
- 每一關只有一個目標，完成指定數量就進入短結算。
- 支援直接點擊；鍵盤 1～8 選擇水果、H 顯示提示。

## 整合範圍

- 首頁「觀察推理」新增「水果數數」入口。
- 獨立場景：`FruitCountingGame`。
- 純資料規則：`FruitCountingData.js`。
- 先保留為獨立候選，不綁正式大地圖、裝備、寶箱、愛心或成就。

## 回家後建議驗收

1. 果樹上的水果是否夠大，彼此不容易誤觸。
2. 蘋果、橘子、水梨與草莓是否一眼可辨認。
3. 水果飛進果籃後，孩子是否會跟著畫面一起數。
4. 妍妍能否使用提示自由點水果，阿晨晨是否能自己完成 1～5。
5. 第五關八個選項在平板與 Game Viewer 是否仍保持清楚。
