## 架構

沿用 `StarflightSession` 固定步長純 JavaScript 運算與 `ForestStarflightGame` Phaser 畫面層。未把附件裡多個互相重複的 Player / Scene 類別直接貼入。

- `phase`：combat / ultimate / falling。
- `paused`：停止全部運算，包括演出時間；武器艙僅能在 combat 開啟。
- `specialCooldowns`：每個武器獨立持有，未裝備時也隨戰鬥時間倒數，進艙時凍結。
- `charging`：保存武器 ID 及進度；釋放觸控不影響。換不同武器、大招、墜落取消尚未完成集氣。
- `invuln`：由同一戰鬥倒數管理，不依靠即將關閉的 UI 場景計時器。
- 子彈碰撞由 session 的數學判定管理；畫面圖片不擁有 Arcade 物理體，消失的子彈不留碰撞體。
- 大招用現有精靈美術做位移／淡入／進度演出，連續 3 秒，全局戰鬥凍結；不是紙娃娃演出的完成版。
- 武器艙返回 0.8 秒是重看戰場的提醒，不宣稱倒數本身能保證不受傷。
- 普攻固定種子直射，各機體普攻差異留後續機體階段。
- 一次施放不觸發第二輪；不自動排隊，不用放開鍵當作發射指令。

## 驗證

執行 `node --test tests/starflight_rules.test.mjs tests/starflight_phase1.test.mjs`。
19 項通過：2 秒集氣、CD 起算、連點、暂停、換裝、穿透／地形、每 0.5 秒一發、2 HP、時停、回能上限、觸控多指、重試狀態，以及保留的航線／地形測試。
三組種子使用同一自動測試駕駛可完成到 BOSS 通關，模擬戰鬥時間約 168～169 秒。這只驗證可完成路徑，不代表真人難度或完整手機體驗；3～5 分鐘目標將於長關卡階段調整。

瀏覽器實際畫面與手機實機操作尚未完成驗證：目前環境沒有可啟動的瀏覽器，安裝未成功。上述通過結果僅包含運算邏輯與語法／資源檢查，不能當作實機測試通過。

## 實際試玩重點

1. 點一下雷射後移動、放開，應從 0.5 秒後的位置射出。
2. 集氣時開艙，等 3 秒返回，集氣應只繼續原本剩餘時間。
3. 發射雷射後切散彈再切回，雷射 CD 不得變成零。
4. 炸裂彈應波及附近敵人；散彈應扇形分散。
5. 大招滿能時有 3 秒完整演出，敵人位置凍結；恢復後保護會結束。
6. 受傷兩次要播放墜落；新一局重新回到 2 HP。
7. 手機左指移動、右指點特殊技應可同時使用；離開瀏覽器會暫停。

## 範圍與相容性

只覆蓋星航自身的場景、規則與測試，不覆蓋平台首頁、main.js、衣櫃資料、存檔模組或其他遊戲。原平台需已具備星航入口與 AnimalSnackGame / AdventurePreferences 依賴。
另提供由相同來源打包的 `starflight-play.html`，只載入星航自身附帶的素材與獨立 runtime；可在 HTTP 下獨立測試，不必依賴平台其餘模組。它的「返回遊戲列表」會回到星航準備畫面。
