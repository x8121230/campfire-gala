# 衣櫃互動 v5.4

依使用者提供的 IMG_0160.mp4 調整目前 v5.3 衣櫃互動，保留現有排版、裝備資料、帽子對位及寶箱測試工具整合。

- 已穿戴卡片：淡綠底、加粗綠框、右上「已裝備」標籤。
- 點一下直接裝備，再點一次卸下；移除原本先預覽、再次確認的流程。
- 帽子與飾品可卸下；服裝／全身裝卸下後回到基本服裝。基本服裝不會被卸成空白。
- 同部位替換、服裝與全身裝互斥、加成計算、存檔沿用原有方法。
- 滑鼠移入卡片放大至 1.035 倍，移出恢復，約 140ms；手機使用點擊穿卸與換裝回饋，不依賴 hover。
- 左側人物播放約 0.8 秒的腳下光圈、星光與輕微縮放。卸下的效果較柔和。
- 沿用衣櫃 equip 音效與原音效開關，首次點擊會嘗試解鎖音訊。不是從影片擷取音效。
- 連續點擊、換頁和離開時清理舊動畫，不累積放大比例或粒子。

來源檔：src/scenes/Collection.js。此檔以已知 v5.3 原版為基礎更新，主程式原有 ChestIntegration 等擴充仍沿用。
測試：實際 Phaser 瀏覽器確認卡片、穿脫、放大還原、人物特效與連續點擊後清理；規則檢查涵蓋部位互斥、基礎服裝保留、未擁有／無效項目與彈窗狀態。瀏覽器自動測試關閉音訊，音色與音量仍待實機聆聽。
本包保留幻界、森林守夜隊及其他累積遊戲；仍需原完整森林益智樂園與既有 v5.3 衣櫃。覆蓋後由原衣櫃入口進入。
