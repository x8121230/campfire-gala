# 形狀雪人拼拼樂 v0.1｜備用幼童試玩版

## 目標

把右側的幾何零件放入中央相同的雪人輪廓，完成五位逐步增加裝飾的雪人朋友。

## 操作

- 拖曳玩法：把形狀零件拖到中央對應輪廓。
- 點放玩法：直接點一下零件，自動吸附到正確位置，適合年齡較小的孩子。
- `H` 或「小雪花提示」亮出一個零件與它的目標輪廓。
- `R` 或「本關重來」重新開始；`P`／Esc 暫停。

## 認知與幼童友善設計

- 使用大圓形身體、小圓形頭、三角形鼻子、長方形圍巾與帽子、圓形鈕扣、星形徽章。
- 拖到錯誤位置時零件會回到原位，不扣分，可以立刻再試。
- 點一下零件必定正確吸附，讓較小的孩子也能完成並獲得回饋。
- 五關依序從三個零件增加到七個零件。
- 每次放對都有小雪花與音效；完成後雪人會跳舞並飄下星光雪花。
- 沒有倒數、生命與失敗結算。
- 切到背景或視窗失焦時自動暫停。
- 不扣主畫面愛心、不發寶箱、不解鎖成就、不修改正式存檔。

## v0.1 驗收重點

1. 右側零件大小與間距是否適合觸控。
2. 拖曳時零件是否跟手，吸附範圍是否合適。
3. 點一下自動放置是否會與拖曳互相干擾。
4. 雪人輪廓及各種形狀是否清楚。
5. 完成飄雪與跳舞回饋是否自然。
