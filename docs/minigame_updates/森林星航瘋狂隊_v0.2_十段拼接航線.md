# 森林星航瘋狂隊 v0.2｜十段拼接航線

## 這版解決什麼

舊版長時間重複同一張背景與同一種戰鬥節奏，五分鐘後仍缺乏前進感。本版把一局改造成「十張短地圖組成的一次航行」，每張圖都有自己的接點、景色、敵人波次與干擾事件，約五分鐘進入熊船長決戰。

## 十段相容接點

每張地圖都有入口與出口字母。上一張的出口必須等於下一張的入口，例如 A→B 後只能接 B→A 或 B→C。每局會依下列骨架，從 18 張一般地圖中抽出 10 張不重複地圖：

`A→B → B→A → A→B → B→A → A→B → B→C → C→D → D→C → C→D → D→E`

- 每段 20 秒，十段共 200 秒。
- 每次開始以新種子重新抽圖；同一種子可重現同一路線，方便除錯。
- 五種場景主題：雲海、熱氣球市集、蜂蜜風車谷、月光水晶航道、暮色飛行港。
- 路線上方顯示目前地圖名稱、段數、接點與十格進度。

## 隨機波次與關卡干擾

每張圖會抽出 1～3 波敵人，越後段越容易出現多波。地圖也能各自指定編隊與干擾：

- 翼形、蛇形、雙排、俯衝、側翼與護航等編隊。
- 雲門：必須穿過安全缺口。
- 側襲：敵人從畫面兩側切入。
- 強風：短時間推動飛船，要求修正走位。
- 每三張圖補回 1 點生命及 1 顆炸彈，降低長局挫折。

敵人波數與編隊採可重現亂數；日後增加地圖只需補上接點、主題、編隊池與干擾，不必改寫整個流程。

## 武器箱三選一

武器不再塞進六格循環強化。第 3、7 張圖會出現武器箱：

1. 玩家碰到武器箱，畫面立即定格並清除敵方子彈。
2. 開啟三張大型武器卡，可用觸控或鍵盤 1／2／3 選擇。
3. 選新武器會直接換裝；重選目前武器則提升等級，最高 Lv.3。
4. 確認後自動回到戰鬥，並給短暫無敵時間。

本版武器：青葉連射、雙芽散射、星露雷射、蒲公英追蹤。六格強化保留加速、飛彈、威力、射速、精靈與護盾，不再暗中切換武器。

## 隱藏地圖預留

規則內已放入「月影秘密花園」原型與 `allowHidden` 開關。目前正式遊玩預設關閉，避免尚未設定解鎖條件就隨機闖入；未來可由無傷、特殊武器、收集品或路線事件開啟。

## 美術更新

保留原本的雲海基調，新增四張同風格繪本背景：熱氣球市集、蜂蜜風車谷、月光水晶航道、暮色飛行港。場景切換時另疊加氣球、風車、水晶與燈籠等前景，使十段路線有清楚的地區辨識。

## 驗收結果

- 規則與全遊戲回歸測試：461／461 通過。
- 三組自動完整航行約 301～315 秒結束，落在約 5.0～5.3 分鐘。
- 真實 Chromium 驗收通過：標題、開始、暫停、十段接點、武器箱、鍵盤選擇、背景切換及手機尺寸載入。
- 預覽圖位於 `docs/starflight_v02_previews/`。

## 尚待真人試玩調整

- 手機上的飛船移動速度、強風推力與武器卡觸控尺寸。
- 各地圖 1～3 波的密度與五分鐘整體難度。
- 武器永久解鎖、圖鑑及隱藏路線的正式條件尚未加入。
