# 小海豹冰河救援 v0.1｜幼童試玩版

## 目標

選擇前方浮冰自動跳躍，找到五隻受困的小海豹。

## 操作

- 滑鼠與觸控：直接點擊左、中、右任一塊浮冰。
- 鍵盤：`1`、`2`、`3` 選擇左、中、右浮冰。
- `H` 或「小鯨魚提示」指出有海豹的浮冰；沒有海豹時會指出安全浮冰。
- `P`／Esc 暫停。

## 幼童友善規則

- 點選後角色自動完成跳躍，不需要控制起跳時間或距離。
- 前兩次渡河沒有裂冰，先熟悉選擇與跳躍。
- 裂冰踩上後會落水，但不會死亡或扣進度。
- 落水時小鯨魚會出現，把角色送回最近的安全浮冰。
- 小海豹會持續在後續浮冰出現，不會因為選錯而永遠漏掉。
- 沒有倒數、生命與失敗結算。
- 切到背景或視窗失焦時自動暫停。
- 不扣主畫面愛心、不發寶箱、不解鎖成就、不修改正式存檔。

## v0.1 驗收重點

1. 浮冰、小海豹和裂痕是否容易辨認。
2. 點擊範圍與鍵盤 1／2／3 是否正常。
3. 跳躍速度、高度與落點是否自然。
4. 落水、鯨魚救援及回到安全點是否連貫。
5. 找到五隻海豹後是否正常結算。
