# 森林星航瘋狂隊 v0.4｜兩格生命與魔法素材

## 安裝

本包是修正檔，需套用在已包含星航 v0.2 或 v0.3 的完整遊戲上，不能單獨執行。
先備份原遊戲，將本包的 `src`、`assets`、`tests`、`docs` 合併至原遊戲根目錄，同名檔案選取代。
請勿刪除原資料夾，也不要將整個 ZIP 或外層資料夾當成網頁入口。
保留原有的五種背景、人物素材及其他遊戲；本包不修改衣櫃、裝備表、存檔或遊戲列表。
開始畫面顯示「v0.4 · 兩格生命・魔法新裝」即可確認更新成功。

## 生命規則

- 標準與挑戰難度皆為 **2 格 HP 上限**。這裡的「2 命」採兩次未回血的受傷即失敗，並非另有兩次復活存量。
- 每次受傷扣 1 格，受傷無敵維持 1.7 秒，避免同時被多顆子彈扣光。
- 愛心補 1 格，上限仍為 2；失敗後使用既有接續功能，以 2 格重新開始該段。
- 修正致命受傷當幀碰到愛心造成「已失敗但 HP 回升」的矛盾狀態。
- 原有聖爆、閃避與檢查點保留；敵人及 Boss 血量不在此次下修範圍。

## 五種 2D 橫向素材

所有圖片均使用內建圖片生成功能製作，為真實 RGBA 透明 PNG；不是白底、黑底或假棋盤格。
原始大圖保留於 `assets/forest-starflight/magic-v04/`；生成咒語完整收錄在同目錄說明區的 `Starflight_v04_asset_prompts.json`。

| 圖檔 | 遊戲用途 |
| --- | --- |
| clover.png | 四葉幸運草散彈，Lv.1～3 使用雙／三／五向排列 |
| beam.png | 彩虹水柱穿透彈，以整張橫向光束縮放，尚未拆分頭、中、尾 |
| dandelion.png | 蒲公英追蹤彈，隨飛行速度方向旋轉 |
| option.png | 金色星星小精靈，同時用於子機與子機掉落物 |
| bubble.png | 泡泡星星道具，程式補上變色星核、色環及武器圖案 |

道具延續 v0.3 的綠／藍／金循環，沒有改成紅色，以免與紅帽補給敵人混淆。
同款道具升級，異款即時切換，不會暫停或開武器選單。
Canvas 與 WebGL 使用相同的程式色環／星核標示，不依賴 Canvas 不支援的圖片 tint。

## 手感與效能

- 小型子彈、短拖尾、子機彈降低透明度；敵方子彈畫在魔法素材上方，維持辨識度。
- 敵彈本體視覺半徑 8，受傷碰撞半徑 3；主角受傷半徑維持 5 世界單位。
- 幸運草命中半徑 Lv.1～3 為 6／7／8，給予比葉片核心略寬容的命中範圍；光暈與拖尾不代表碰撞範圍。
- 素材載入後只計算一次透明留白界線，重用圖片物件池，不逐幀建立新圖片。
- 柔和效果選項可關閉額外拖尾與部分震動；圖檔本身的淡光暈仍保留。
- v0.3 的連續視差卷軸、時間軸波次、150 秒 Boss 與約 3～4 分鐘流程完整保留。

## 驗證

- 全套 Node 測試：474／474 通過，其中星航專項 24 項。
- 三個自動試玩種子皆以 2 HP 完成，約 181、178、186 秒；不是真人難度平衡結論。
- Chromium 桌機與手機模擬：透明素材載入、即時換武器、無縫接點、三武器圖片、圖片池隱藏、暫停、聖爆及雙指操作通過。
- 沒有實體手機效能測量；請以你手機上的觸感與可讀性回饋為準。
