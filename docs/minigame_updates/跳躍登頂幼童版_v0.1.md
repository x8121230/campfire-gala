# 跳躍登頂・幼童版 v0.1

## 核心玩法

- 按住畫面、空白鍵、方向鍵上或 W 蓄力，進入安全力量範圍後放開跳躍。
- 五條登頂路線包含 2、3、3、4、4 次跳躍，平台始終保持寬大固定。
- 每一階需要的力量不同；成功落地後才前往下一階，最後抵達星光旗幟。

## 幼童友善設計

- 第一關安全範圍最寬，後續才逐步縮小，但不加入精準判定、移動平台或風力。
- 綠色安全力量範圍預設開啟，也能關閉後自行掌握蓄力時機。
- 力量太少或太多都不扣分、不墜落，由彈力葉接住並送回目前平台。
- 提供力量提示及本關重來；支援 H、G、R、P 鍵盤操作。

## 整合範圍

- 首頁「反應節奏」新增「跳躍登頂」入口。
- 大地圖歸屬與正式主題名稱尚未定案，本版維持獨立測試入口。
- 山峰、平台、角色、旗幟、彈力葉與特效全部使用 Phaser 程式繪製。
- 本版不寫入正式獎勵、裝備、愛心或成就。
