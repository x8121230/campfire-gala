# 幻界・草地波波鼠 v1

## 定位

草地波波鼠是玩家離開星芽營地後遇見的第一種怪物，也是星芽谷「可愛、可讀、沒有殘酷感」戰鬥語言的示範角色。新版保留胖鼠、半顆橡果帽與受驚逃跑的辨識特徵，並把原本偏寫實 3D 的表現統一為深棕色鉛筆線、水彩疊色與紙張顆粒。

## 正式外觀

- 蜂蜜棕短毛、奶油白肚皮與粉色圓耳。
- 橡果帽採手工拼片感，帽側保留一片小綠葉。
- 大眼但不使用塑膠般高反光，輪廓與蒲公英丘陵背景一致。
- 所有動作皆使用透明背景，不帶文字、格線或殘留色邊。

## 八格動作

1. 安靜待機：坐姿呼吸。
2. 好奇觀察：抬頭看向周圍。
3. 滾動逃跑 A：縮成圓球起滾。
4. 滾動逃跑 B：翻轉形成循環。
5. 抱頭受擊：星光彈命中時的立即反饋。
6. 驚嚇彈跳：受擊後離地約半個身位。
7. 撞牆暈眩：停止逃跑並短暫出現星星。
8. 柔光消散：被驅趕完成時化為星芽光塵，不使用死亡或叉眼表現。

## 遊戲行為

- 平常以雙待機格低頻切換，避免畫面過度躁動。
- 受擊先抱頭，再驚跳並切換雙格滾動逃跑。
- 逃跑路徑撞上阻擋區時，不會穿牆；會原地暈眩 0.85 秒。
- 驅趕完成後播放專屬柔光消散格，同時依既有規則拋出光團。
- 顯示尺寸調整為 160 像素高的透明畫布，實際角色體量仍符合 Lv.1 新手怪比例。
