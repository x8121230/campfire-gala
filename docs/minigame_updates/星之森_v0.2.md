# 星之森：動物童話歷險 v0.2

這是從「幻界・星芽谷」延伸的第一區域可玩版本，沿用真正的 3D 場景、固定斜角鏡頭與阿晨晨四方向紙片人物。首頁遊戲列表原「幻界・星芽谷」入口已改為「星之森・動物童話歷險」，scene key 與分類保留，其他遊戲與衣櫃不變。

## 安裝

1. 關閉遊戲，先備份原本的完整森林益智樂園資料夾。
2. 解壓 `Star_Forest_v0_2_Integrated.zip`，把裡面的 `src`、`assets`、`docs`、`tests`、`tools` 與說明檔，直接貼進原完整森林益智樂園資料夾，選擇合併資料夾／取代同名檔案。
3. 保留原資料夾中未被覆蓋的其他檔案；不要先刪除原資料夾。
4. 沿用原本啟動方式、網址與連接埠，從「遊戲列表」第一張卡片進入。如果仍顯示舊標題，在瀏覽器重新整理（必要時 Ctrl+F5）。不要清除網站資料。

這一包只有一種整合安裝方式，不分 UPDATE / DEMO。它包含附件 v5.4 累積整合包的原有檔案；附件本身沒有完整主遊戲啟動頁、Phaser 與 PlatformStorage 等基礎檔，故仍要覆蓋到既有完整遊戲，不能把此包當全新完整安裝。

## 第一區域

74 × 54 世界單位的連續森林，以一條東西向主路和南北支路形成環狀探索路線。參考使用者附圖的森林步道、聚落、湖岸與區域銜接關係，使用原創地形和童話地名，未直接貼用 WOW 地圖圖像。

- 橡果樹屋村：安全樞紐、巨橡樹屋外觀、螺旋木梯造景、發光路燈、村長與刺蝟攤位。刺蝟太太可補滿星光；本版未做以物易物、樹屋室內與樓梯攀登。
- 迷亂蘑菇林：大型彩色蘑菇、8 隻暈眩小兔／調皮松鼠、路口風鈴與小鴨起點。
- 陽光蘋果坡：真實連續坡度；5 顆金色蘋果位於高處，可沿路上坡採集。
- 螢光小池塘：水面不能通行，繞北側小路可找到鴨媽媽。
- 泡泡泥沼、沉睡月亮湖：旅行圖與實景路牌已有預留方向，標示「待開放」，本版沒有泥沼戰鬥、荷葉跳躍或黑熊頭目。

主角為原包的阿晨晨 Q 版暫代形象，配上星光標記；尚未新增魔仙服裝或接入衣櫃紙娃娃。動物與技能圖示是程式繪製的原創紙片／向量美術；環境仍屬低多邊形 3D 第一版。

## 操作

手機橫放：左搖桿移動，右側四個魔法，走近 NPC 自動對話；靠近蘋果、風鈴與路牌時畫面下方出現互動鍵。可同時按住搖桿與泡泡，使用多點觸控。

| 動作 | 手機 | 鍵盤 | 規則 |
|---|---|---|---|
| 移動 | 拖曳左搖桿 | WASD／方向鍵 | 搖桿拖得較少可慢走 |
| 星光泡泡 | 按住大泡泡鍵 | 按住 J | 自動鎖定 9 單位內最近動物，每 0.32 秒一發；3 發洗掉壞脾氣 |
| 蜂蜜糖罐 | 點按／從按鍵拖曳選落點後放開 | Q 自動投擲 | 最遠 7 單位、半徑 3.4、定身 3 秒、冷卻 8 秒 |
| 蒲公英滑步 | 點按蒲公英 | 空白鍵 | 朝目前移動／最後面朝方向滑步，不能穿樹或越水；冷卻 4 秒 |
| 大象水車 | 點按大象 | R | 半透明大象＋前方扇形彩虹，範圍 11 單位；冷卻 20 秒 |
| NPC 對話 | 走到居民旁邊 | 走到居民旁邊 | 村長、刺蝟太太、小鴨與鴨媽媽均自動觸發，不用按鍵 |
| 物件互動 | 點下方情境按鍵 | E | 採蘋果、敲風鈴、查看路牌 |
| 地圖 | 地圖鍵／小地圖 | M | 顯示人物、動物與剩餘蘋果；開啟時暫停 |
| 暫停 | 暫停鍵 | Esc | 繼續或返回遊戲列表 |

蜂蜜出現圓形落點預覽；點按時優先選附近動物，沒有動物時投向前方。滑步留下一片絨毛，動物暫時停止追蹤；技能的冷卻倒數會直接顯示在按鍵上。

動物出手前有地面提示圈。主角有 5 格星光，受到搗蛋碰撞會少一格，耗盡會回村休息，已採蘋果與已安撫動物均保留；村內不受搗蛋攻擊。動物安撫後會被泡泡包住、冒愛心、短暫跑開消失，沒有流血或擊殺。

## 任務流程

1. 走到貓頭鷹村長旁邊，自動觸發對話並接受委託。四個魔法一次解鎖，蘋果採集也同時開啟。
2. 安撫蘑菇林的 8 隻動物，去東方高坡採 5 顆陽光蘋果；兩項順序不限。
3. 回村走近村長，自動觸發對話交任務，取得本章「森林好朋友」紀念章，可繼續探索。
4. 支線：走近小路上的三隻小鴨，自動對話接下護送後慢慢走到東邊鴨媽媽旁。走太遠牠們會等你，附近有生氣動物時會停下來。三隻都到達才算完成，獲得「溫柔領隊」紀念章。
5. 活動：互動「金橡果風鈴」，啟動 30 秒挑戰。金橡果從上方陸續掉落，落地後走近收集；友善松鼠也會來收集。結束顯示雙方數量與個人最佳，可再次挑戰。

本版限時活動由風鈴啟動，方便小朋友準備後再開始，尚未改成隨機突發。紀念章只記錄本章完成狀態，未連動正式寶箱或裝備獎勵。

NPC 對話觸發距離為 2.4 單位；關閉後在原地不會再次跳出，必須走到 4.2 單位以外再靠近才重新觸發，避免站在邊緣反覆開關。自動對話時會暫停遊戲並放開移動／施法輸入。

## 存檔與暫停

使用獨立 `forest_star_forest_ch1_v1` 鍵，只保存已接委託、已安撫動物 ID、已採蘋果 ID、主線完成、小鴨護送完成與橡果最高分。舊星芽谷 `forest_phantom_realm_v1` 存檔保留，不轉換或刪除。

再次進入會在安全村出生，未安撫動物恢復完整生氣條；未完成的護送與限時活動重新開始，不保存戰鬥瞬間。手帳的「重玩第一章」有第二次確認，只重設本章。

失焦、切換分頁、開手帳／地圖與手機直放會暫停，同時清除搖桿與按住技能的輸入。轉回橫向後需手動繼續。若裝置禁止保存，畫面會提示；返回前不要清除瀏覽器資料。
