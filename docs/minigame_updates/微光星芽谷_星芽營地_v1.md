# 幻界・微光星芽谷｜星芽營地 v1

本版已直接取代舊「修復水車」幻界原型。世界地圖點擊「幻界」後，經漩渦轉場直接進入 2.5D 俯視繪本場景「星芽營地」。

世界冒險地圖上的入口現已更名為「幻界・星芽谷」並永久開放，不再要求 60 顆星或清除迷霧。舊存檔內即使保留鎖定紀錄，也會在開啟世界地圖時自動修正。入口持續播放幻紫雙環、星藍星塵與核心脈衝，點擊後再播放全畫面的星核漩渦穿越動畫。

## 完成內容

- 1672 × 941 星芽營地完整背景：雲海斷崖、發光木柵欄、晨露噴水池、母樹發條鐘、裁縫鋪、星核工房、公告欄與北門木橋。
- 三位透明背景 NPC：守護者長老・奧爾登、裁縫師・布隆克、奇物少女・菲比。
- NPC 待機浮動、腳下陰影、靠近光圈、姓名牌與主線驚嘆號／問號。
- 鍵盤與手機橫向操作：WASD／方向鍵、左搖桿、E／空白鍵互動、Shift／快走、鳥瞰／跟隨切換。
- 場景碰撞：懸崖、母樹、左右工房、噴水池與晨露池不可穿越；所有任務點均可從出生點步行抵達。
- MAIN_01「跌進畫卷的第一步」：奧爾登接取 → 晨露池清洗 → 布隆克領取初心者布織長袍與甜蘋果 ×10 → 北門開放。
- 菲比前導對話、營地公告欄預告、噴水池環境互動、獨立 v2 自動存檔與序章重玩。
