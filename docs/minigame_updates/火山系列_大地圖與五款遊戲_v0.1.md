# 岩漿海・火山群島 v0.1

## 大地圖

- 新增可互動火焰屬性大地圖「岩漿海・火山群島」。
- 五座圓形島嶼入口以發光路線串連，可直接點擊進入遊戲。
- 火山、熔岩河、火星與島嶼全部由 Phaser 即時繪製，不依賴新增圖片素材。
- 從五款遊戲返回時會回到火山大地圖；從大地圖返回時回到小遊戲列表。

## 五款小遊戲

1. **熔岩踏石大冒險**：依金色光圈的順序踏過 3～6 塊石頭，練習視覺追蹤與次序。
2. **火山冷卻工坊**：投入 1、2、3 顆冰晶，湊出 3～7 的目標數量。
3. **熔岩水管接接樂**：旋轉水管，對齊金色方向影子，接通冷卻水。
4. **火山洞穴回聲**：觀看 2～6 個圖案依序亮起，再照順序重複。
5. **熔岩河搭橋隊**：用 1～3 格木板拼出 2～6 格的橋長。

## 幼童規則

- 大按鈕、短關卡、立即聲光回饋。
- 無倒數、無生命、答錯不扣分；錯誤後提供明確提示並可繼續。
- 測試入口不寫入正式存檔，不發正式寶箱、裝備或成就。
- 首頁目前只新增一張「火山群島」入口卡，避免五款遊戲洗版。

### v0.2 補充：火山冷卻工坊完整化

- 五關採漸進開放冰晶箱，加入逐格量表與「還差幾顆」提示。
- 冰晶投入火山爐時具有飛行、降溫與雪花慶祝效果。
- 可拿回上一份，也可請小火龍指出一個不會超量的選項。

### v0.3 補充：熔岩水管接接樂完整化

- 五關由三段增加至七段，加入直管、彎管與三岔管。
- 藍色水管與淡金色答案影子直接重疊比對，點一下旋轉四分之一圈。
- 完成後播放冷卻水逐段流向火山及白煙降溫動畫。
- 新增水滴提示、本關重來與鍵盤操作。

### v0.4 補充：火山洞穴回聲完整化

- 五關由兩個圖騰回聲增加至六個，圖騰種類由兩種逐步增加至四種。
- 預設慢速播放，可重新聽一次；答錯後自動重播且不扣分。
- 新增大型圖騰、發光火星、進度圓點與完成慶祝動畫。

### v0.5 補充：熔岩河搭橋隊完整化

- 五關橋長由兩格逐步增加至六格，木板為 1、2、3 格。
- 木板自動飛到下一段位置，顯示已搭長度與剩餘格數。
- 超長不放置、不扣分；提供拿回、重來與小火龍提示。
- 完成後小火龍會走過橋抵達安全岩地。

## 首批五款完成

火山大地圖與五款幼童小遊戲均已具備可操作關卡、說明、提示、重玩、返回及完成流程，可進入整體實機測試階段。
