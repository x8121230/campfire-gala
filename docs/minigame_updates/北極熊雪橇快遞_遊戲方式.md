# 北極熊雪橇快遞 v0.1｜幼童試玩版

## 目標

控制雪橇的移動速度，等雪屋進入綠色配送區時送出禮物，完成五個冰原地點的快遞任務。

## 操作

- 畫面按鈕：「慢」、「中」、「快」切換雪橇速度；「送禮物」進行配送。
- 鍵盤：`1`、`2`、`3` 切換慢、中、快速；空白鍵／Enter 送禮物。
- `P`／Esc 暫停。

## 幼童友善規則

- 雪橇自動前進，孩子只需控制速度與送禮時機。
- 雪屋中心進入綠色配送區即可成功。
- 太早送出時禮物會自動飛回雪橇，可以立刻再試。
- 錯過雪屋時，雪屋會從前方重新繞回來，不會永久漏掉。
- 快速通過顛簸雪地時禮物可能跳起，但北極熊會接住，不會遺失。
- 完成地點：企鵝郵局、海豹小屋、雪兔糖果屋、狐狸暖爐屋、冰晶圖書館。
- 沒有倒數、生命與失敗結算。
- 切到背景或視窗失焦時自動暫停。
- 不扣主畫面愛心、不發寶箱、不解鎖成就、不修改正式存檔。

## v0.1 驗收重點

1. 三段速度的差異是否明顯又容易控制。
2. 綠色配送區和雪屋中心是否容易判斷。
3. 送禮按鈕、空白鍵及 Enter 是否正常。
4. 太早送、錯過重來與成功配送動畫是否清楚。
5. 五份貨物是否隨配送進度逐份減少。
