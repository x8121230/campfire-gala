# 冰窟釣魚對對碰｜遊戲方式

版本：v0.1 幼童試玩版  
更新日期：2026-09-12

## 遊戲目標

看左邊小熊泡泡中的魚色與數量，從冰窟裡點選符合條件的小魚。全程沒有倒數、扣分或失敗畫面，點錯會說出魚的顏色並讓孩子繼續嘗試。

## 九個任務

- 第 1 段「認識顏色」：紅、藍、黃各釣一條。
- 第 2 段「釣兩條魚」：紅、藍、黃各完成一次兩條配對。
- 第 3 段「顏色加數量」：依序完成一條紅魚、三條藍魚與兩條黃魚。

每一輪都有六條緩慢游動的小魚，而且一定會提供足夠數量的正確答案，不會出現無法完成的任務。

## 操作方式

- 滑鼠或觸控：直接點小魚。
- 鍵盤：按 `1`～`6` 選擇畫面上的魚。
- `H`：顯示一條正確顏色的小魚。
- `P` 或 `Esc`：暫停／繼續。
- 「慢慢游」：把游動速度降到原本約 45%。

## 幼童友善設計

- 魚的點擊範圍大於圖案本身。
- 點錯不扣愛心、不重置進度，只提供顏色提示。
- 每釣到一條魚，泡泡會更新目前數量。
- 提示會用金色光圈跟著正確的小魚移動。
- 切到背景或視窗失焦時自動暫停。
- 本原型不寫入正式存檔，也不發放正式獎勵。

## 回家後建議測試

1. 手機或平板是否容易點到游動中的魚。
2. 「慢慢游」開啟後，一歲半孩子是否更容易操作。
3. 三條魚的任務對四歲半孩子是否太長。
4. 點錯後的文字提示與搖動回饋是否容易理解。
5. 暫停、重新開始與返回遊戲列表是否正常。
