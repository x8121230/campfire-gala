## 存檔與獎勵

在同一主存檔新增 `starlight_lake_v1`：version、seals、visited、collectibles、moonClears。
使用既有寶箱儲存服務的持久化寫入檢查；先成功保存，再演出星印／收藏結果。
新欄位保留其他裝備、寶箱、錢包及未知欄位；舊 SaveSystem 後續保存也保留本欄位。
星印以地點 ID 去重；月光石 ID `moonstone` 只保存一次。失敗寫入不顯示成功。
月光石只在湖畔探索手帳展示，不加入可穿戴裝備、不授予能力、不轉成水晶。
湖畔本身不發寶箱；五款基礎遊戲的既有首勝與保底規則未修改。
星空連線、點點螢火仍使用原正式進度；快遞／光路工坊保留既有局內紀錄方式。

## 畫面與返回

橫向：1280×720 全景地標，六個大按鈕，地標圖像亦可點擊。
直向：720×1280 全景＋2×3 場所卡片，主要按鈕高度 82 或更大。
依 Phaser FIT 模式使用 `setGameSize`，離開湖畔／世界地圖恢復 1280×720。
舊遊戲、設定、寶箱及裝備手冊仍採橫向，手機使用時建議轉橫。
從湖畔開啟設定會暫停地圖；返回恢復直／橫向。跳去其他頁面不遺留暫停地圖。
返回遊戲採既有 `returnScene: StarlightLake`，不改全域 scene.start。
旋轉裝置會關閉湖畔彈窗；未完成的一組謎題需重做，已保存星印保留。
