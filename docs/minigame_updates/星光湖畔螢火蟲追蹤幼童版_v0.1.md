# 星光湖畔：螢火蟲追蹤・幼童版 v0.1

## 核心玩法

- 先觀看四隻螢火蟲依序閃亮，再點擊螢火蟲回答。
- 共五關，序列長度由 2 次逐步增加到 5 次。
- 第 1、2、4 關照原順序點；第 3、5 關從最後一隻倒著點。
- 點錯不扣分、不失去進度，會清空本輪答案並重新慢速示範。

## 幼童輔助

- 預設開啟慢速閃光，可切換一般速度。
- 「再看一次」可不限次數重播完整順序。
- 「下一隻提示」會讓正確的螢火蟲連續發光。
- 沒有倒數、生命、追趕者或失敗結算。
- 支援直接點擊與數字鍵 1～4；空白鍵重播、H 提示、S 切換速度。

## 整合範圍

- 首頁「配對記憶」新增「星光湖畔」入口。
- 獨立場景：`StarlightFireflyGame`。
- 純資料規則：`StarlightFireflyData.js`。
- 本候選暫不綁正式大地圖、裝備、寶箱、愛心或成就。

## 回家後建議驗收

1. 四隻螢火蟲與閃光是否夠大、夠亮。
2. 慢速與一般速度在平板／Game Viewer 是否容易分辨。
3. 第 3、5 關的倒序說明，四歲半孩子是否能理解。
4. 一歲半孩子能否把它當作自由點亮遊戲操作，不因點錯受挫。
5. 暫停後是否會從頭重新播放，避免漏看半段順序。
