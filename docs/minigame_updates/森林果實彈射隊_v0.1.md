# 森林果實彈射隊 v0.1

2026-09-09。接續森林變形大冒險，新增以瞄準射擊、反彈與支點連鎖為核心的小學生遊戲，直接整合到森林益智樂園。主遊戲總表共 16 款，新卡位於全部列表第一張與「反應節奏」。

## 玩法

每球先觀察目前顏色、下一球、風向與目標，再決定角度。果實沿著實際彈道飛行，碰左右牆反彈，碰到果陣後黏在相鄰空位；同色普通果實連成至少三顆就會消除。

仍與頂端相連的果實會留在場上；失去支點的整串果實不論顏色都會掉落。小鳥裝在救援泡泡中，需要讓它掉落或被松果爆炸解救。連鎖數計入這一球離開果陣的所有果實與救援泡泡，包括參與消除的發射球。

沒有瞄準倒數。球數有限；下降關卡在指定發射回合後下降，不會因為停下思考而加速。移動果陣以整個升降週期的最低位置判定警戒區，淡紅區域提示這段移動範圍。最後一球完成目標可直接過關。

| 元素 | 規則 | 可思考的選擇 |
| --- | --- | --- |
| 紅心、金陽、藍晶、紫花 | 顏色搭配 ♥ ● ◆ ✿ 圖案 | 對同色連消，或先留一顆鋪下一球 |
| 綠色藤圈 | 直接命中一次解鎖，解鎖後可配色 | 打同色球可同時解鎖並連消 |
| 數字硬殼 | 直接命中兩次，數字顯示剩餘次數 | 正面敲開、炸掉，或拆上方支點 |
| 彩虹花粉 | 命中後，自己與鄰近普通果實變成射來的顏色 | 先換球決定要染的顏色；不染藤圈、硬殼或小鳥 |
| 松果 | 直接命中或旁邊連消，炸掉自己與相鄰一圈 | 也能引爆相鄰松果、炸開硬殼並救小鳥 |
| 救援泡泡 | 不參與同色配對 | 拆支點使其掉落，或用松果爆炸 |
| 風 | 每射一球依關卡順序換風向 | 瞄準線已計入彎曲及反彈 |
| 升降枝葉 | 果陣上下緩緩移動 | 瞄準線預測飛行期間的果陣位置 |
| 雙發射台 | 左右發射位置可自由切換 | 從另一側找支點或減少反彈 |

每球結束後，已不存在於果陣的顏色會從待發射隊列替換掉。換球只交換目前與下一球，不會循環抽取整個隊列。空位不足時瞄準終點顯示紅叉；射出後沒有可黏附空位且未引發消除，會結束本局。

## 每日挑戰

以裝置的本地日期 YYYY-MM-DD 產生固定種子，從第 6、8、10、11 關的四個模板挑選一個，再做四種循環配色與左右鏡射，共 32 種組合。風向與雙台位置會隨鏡射對應調整。

這是已驗證模板的變化，不是每天生成完全全新的地形。相同日期相同配置，不同日期可能重複組合；全部 32 種組合都保留三星可達的射擊路徑。當天可重試；跨日後重新從選關進入每日挑戰才使用新日期，當局重試保留原配置。無網路請求、排行榜或每日推送。

## 操作與流程

- 滑鼠：移動瞄準，點一下果陣區域發射；右側也有發射按鈕。
- 觸控：在果陣按住瞄準，放開發射；移出果陣再放開取消。第二根手指不會搶走瞄準。
- ← → 微調角度；空白鍵 / Enter 發射；X 換球；Tab 切換雙發射台。
- P / Esc 暫停。切離視窗或隱藏分頁時自動暫停，需手動繼續；飛行與掉落效果一起凍結。
- 飛行、消除動畫、暫停或結算中禁止額外發射、換球及換台。
- 重試會重置當局，保留本次最佳星數；返回選關後可自由重選。

## 新增與整合檔案

- `src/scenes/ForestFruitGame.js`：選關、完整遊戲、彈道預覽、動畫、輸入與結算。
- `src/data/FruitRules.js`：固定步長掃掠碰撞、六角相鄰、連消、解鎖、爆炸、失去支點、計分。
- `src/data/FruitLevels.js`：15 關、樹靈三幕、日期種子及每日模板變換。
- `assets/forest-fruit/orchard.png`：新生成果園背景，1672 × 941。
- `assets/forest-fruit/sprites.png`：新生成六格透明角色圖集，1536 × 1024，每格 512 × 512。
- 更新 `src/main.js` 註冊新場景，更新 `src/data/MiniGameCatalog.js` 加入入口。
- `tests/fruit_rules.test.mjs`、`tests/fruit_scene.test.mjs` 與 `tests/fixtures/fruit_routes.mjs`：規則、流程與三星操作路徑。

素材以內建 image_gen 生成；完整提示詞、六格順序與使用位置見「森林果實彈射隊_素材生成紀錄.json」。果實顏色、圖案、藤圈、硬殼數字、警戒線及彈道由程式繪製，以維持判讀與碰撞一致。

## 驗證範圍

170 項自動測試全數通過，其中本款新增 24 項規則測試及 14 項場景流程測試，另含既有 132 項回歸檢查。覆蓋 15 關三星操作路徑、全部 32 種每日組合、三幕連續救援、飛行／預覽一致、反彈、風、硬殼、花粉、連爆、掉落、暫停、觸控取消、第二指防誤射、重試與入口註冊。

場景測試使用 Phaser 顯示與輸入模擬，不等於真實瀏覽器或平板驗收。目前預覽連線無法載入本地遊戲；實際 Game Viewer 畫面、觸控手感與音量仍待實機確認。測試結果附於同目錄文字檔；可在具有 Node.js 的環境執行 `node --test tests/*.test.mjs` 重跑。

## 安裝

將整合 ZIP 根目錄的 `src`、`assets`、`docs`、`tests` 與使用方法複製到「森林益智樂園_v2_完整測試版」，取代同名檔案，再用原本方式啟動主遊戲。本包保留所有前輪遊戲更新，需搭配既有完整主遊戲。
