# 《森林星航瘋狂隊》新版開發規格書 v1.1

> 遊戲類型：童話繪本風 2D 橫向捲軸射擊  
> 玩法參考：FC《沙羅曼蛇》、SFC《極上瘋狂大射擊》  
> 目標平台：電腦瀏覽器、手機橫向操作  
> 單局目標時間：3～5 分鐘

---

## 1. 專案目標

把目前的射擊原型升級成具有完整流程、機體差異、武器配置、角色裝備能力及隨機分岔關卡的童話風 STG。

玩家每次進入遊戲時，先在機艙選擇飛行器、特殊武器及大招，再觀看約 3 秒的森林彈射動畫進入戰鬥。戰鬥採自動普攻，玩家負責走位、特殊攻擊、大招、武器艙切換及套裝主動技能。途中經過 3～4 個長區域後進入 BOSS 戰並通關。

### 核心體驗

- 像經典橫向 STG 一樣持續向右推進，不頻繁中斷。
- 每台飛行器有不同普攻、速度、回撤及回能手感。
- 特殊武器可在戰鬥中打開武器艙切換。
- 衣櫃紙娃娃決定能力與角色演出，不改變飛行器外觀。
- 每局路線及區域組合不同，維持重玩價值。
- 無血腥；敵人被擊敗後以淨化、愛心、白雲或撤退動畫呈現。

---

## 2. 一局完整流程

1. 進入飛行機艙。
2. 選擇飛行器。
3. 選擇特殊武器及大招。
4. 顯示目前服裝、套裝能力及本局生效效果。
5. 播放約 3 秒森林彈射出擊動畫。
6. 進入第一個長區域並持續橫向卷軸戰鬥。
7. 區域末端出現上下兩條分支，玩家以飛行位置或點選選擇下一區。
8. 經過約 3～4 個區域後進入 BOSS 戰。
9. 擊敗 BOSS 通關；HP 歸零且無復活效果則墜落敗北。

---

## 3. 戰鬥操作

### 3.1 左側

- 虛擬搖桿：控制上下左右移動。
- 往右移動是前進，往左移動是回撤。
- 操作要即時，只有動畫表現可帶慣性；角色放開搖桿後不可持續滑行很遠。
- 往左回撤時仍面朝右方並繼續射擊。

### 3.2 右側按鍵

| 按鍵 | 功能 | 顯示規則 |
| --- | --- | --- |
| 特殊攻擊 | 使用目前裝備的特殊武器 | 永久顯示，圖示隨武器更換 |
| 大招 | 能量滿後施放目前裝備的大招 | 永久顯示，顯示能量進度 |
| 武器艙 | 暫停戰鬥並切換特殊武器或大招 | 永久顯示 |
| 套裝技能 | 使用衣服提供的主動技能 | 沒有主動技能時完全隱藏 |

### 3.3 自動普攻

- 普攻固定自動射擊，不設手動普攻鍵。
- 每台飛行器的普攻型態與射擊間隔不同。
- 普攻必須有 CD 或射擊節奏，不可形成完全無縫的連續彈幕。
- 建議初始森林機採「三發短連射＋短暫停頓」：
  - 每發間隔：暫定 0.10 秒。
  - 每輪三發後停頓：暫定 0.40 秒。
- 普攻數值屬於測試值，需依實際手機手感調整。

## 4. 武器艙系統

### 4.1 開啟規則

- 按下武器艙後，敵人、敵彈、場景卷軸、環境機關、回能及所有技能 CD 全部暫停。
- 玩家可以查看及切換已取得的特殊武器與大招。
- 切換裝備不得重置原有 CD、大招能量或持續效果；尚未完成的雷射集氣依下述換裝規則處理。
- 關閉武器艙後，先給極短的視覺倒數或淡入，再恢復戰鬥，避免瞬間遭到子彈命中。
- 武器掉落物改為「取得／升級武器」，不再碰到後強制切換。

### 4.2 第一階段特殊武器

第一個可玩版本先完成三種，確保操作手感真的不同。

| 武器 | 操作 | 作用 | 暫定 CD |
| --- | --- | --- | --- |
| 炸裂彈 | 點按 | 命中後造成小範圍爆炸 | 4 秒 |
| 聚氣雷射 | 點一下 | 集氣滿 0.5 秒後，從機體前方發射高傷害貫穿雷射 | 5 秒 |
| 散彈 | 點按 | 向前方扇形發射一次密集彈幕 | 3 秒 |

### 4.3 後續武器

| 武器 | 預定特性 |
| --- | --- |
| 冰霰 | 扇形冰晶，造成短暫緩速 |
| 噴火炮 | 按住持續噴火，適合近距離範圍輸出 |
| 黏著彈 | 黏住目標，造成緩速並延遲爆炸 |
| 追蹤彈 | 自動尋找目標，適合複雜地形 |
| 彈跳彈 | 碰撞地形或擊敗敵人後反彈；限制反彈次數及存活時間 |

### 4.4 聚氣雷射防呆

- 點一下特殊攻擊鍵開始自動集氣；手指放開或滑離按鍵都不取消。
- 集氣期間出現機體前方光圈、粒子集中及逐漸升高的音效。
- 集氣滿 0.5 秒後自動發射，從機體當下位置向右發射；發射後才進入 5 秒 CD。
- 集氣中與 CD 中的重複點擊均忽略，不排隊追加下一次攻擊。
- 每次點擊只發射一次，CD 結束後需重新點擊。
- 武器艙開啟時凍結集氣與各武器 CD；切回同一武器保留集氣進度，改裝其他武器則取消未完成集氣、不扣 CD。
- 墜落或發動大招時取消未完成集氣，避免恢復後突然補射。

## 5. 大招系統

### 5.1 能量取得

- 命中敵人可獲得少量大招能量。
- 擊敗敵人可獲得較多能量。
- 攻擊 BOSS 時，即使沒有小怪，也能靠持續命中回能。
- 多發散彈不可因彈數多而獲得不成比例的能量；應設定單次攻擊或單一目標的回能上限。
- 大招本身造成的傷害不回充大招能量。
- 平衡目標：普通玩家一場約可使用 1～2 次，表現好時最多接近 3 次。

### 5.2 大招演出

固定流程：

1. 玩家按下大招。
2. 戰鬥與畫面時間完全停止，玩家無敵。
3. 播放 3 秒內的完整角色特寫動畫。
4. 發動大招效果。
5. 畫面淡回並恢復戰鬥。

每次施放都完整播放，不縮短動畫。

### 5.3 第一批大招

| 大招 | 效果 |
| --- | --- |
| 妍妍／妹妹魔法爆發 | 清除畫面敵彈，對全場敵人造成大量傷害 |
| 子彈時間 | 敵人、敵彈、場景障礙及環境機關一起減速，玩家保持正常移動 |

子彈時間發動時，背景稍微變暗，畫面邊緣顯示魔法光暈或時間波紋，讓玩家清楚知道效果仍在持續。

## 6. 飛行器系統

### 6.1 系統定位

飛行器決定：

- 普攻型態。
- 移動速度。
- 回撤速度。
- 大招回能效率。
- 操作與戰鬥風格。

飛行器外觀固定，不製作紙娃娃換裝。衣服只影響角色能力及大招／復活動畫。

### 6.2 初步機體設計

| 代號 | 暫定名稱與外觀 | 普攻／特色 | 明確弱點 |
| --- | --- | --- | --- |
| M | 森林芽翼：沿用現有模組，加入葉片、藤蔓與橡果裝飾 | 均衡直射、三連發種子彈，初始機體 | 需要對準敵人，沒有特別突出的能力 |
| A | 旋羽貓頭鷹：童話風貓頭鷹飛行夥伴 | 羽毛魔法球環繞近身攻擊；回撤靈活 | 射程短，必須接近敵人 |
| B | 彈果翼龍：可愛翼龍與硬果裝飾 | 子彈碰地形或擊敗敵人後反彈 | 空曠地圖較難發揮、射速較慢 |
| S | 星翼機巧隼：機械風隱藏機 | 前方半圓掃描、多目標鎖定齊射 | 需要鎖定時間，齊射後空檔較長 |

代號只供內部分類，正式介面不顯示強弱階級，避免玩家誤以為 S 必定高於其他機體。

### 6.3 S 型鎖定規則

- 自動普攻仍然保留。
- 專屬特殊攻擊為前方半圓掃描雷達。
- 敵人在扇形範圍內停留超過 0.5 秒後出現鎖定框。
- 第一版最多同時鎖定 4 個目標。
- 放開特殊攻擊鍵後，向所有已鎖定目標發射追蹤雷射。
- 沒有鎖到敵人時放開，取消攻擊且不進完整 CD。

## 7. 飛行動畫與回饋

| 狀態 | 動畫表現 |
| --- | --- |
| 往前移動 | 身體或機體前傾，尾流拉長 |
| 往後移動 | 機體抬頭煞車，尾流縮短 |
| 上下移動 | 機體輕微傾斜，披風、翅膀或葉片跟隨擺動 |
| 停止操作 | 小幅上下浮動，位置迅速穩定 |
| 武器升級 | 武器部位亮起、短音效、彈型立即改變 |
| 受到傷害 | 短暫閃爍、震動及受擊音效 |
| HP 歸零 | 失控、冒煙或星光散落，進入墜落動畫 |

不同武器必須有不同的命中聲與擊中回饋：

- 散彈：清脆、多點命中。
- 雷射：集中、持續或重擊感。
- 彈跳彈：有節奏的碰撞聲。
- 冰霰：碎冰及結霜。
- 火焰：持續燃燒與熱浪。
- 黏著彈：黏附音後延遲爆炸。

## 8. 衣櫃、套裝與紙娃娃

### 8.1 系統切割

- 飛行器決定戰鬥手感與普攻。
- 衣服決定套裝能力、角色外觀、大招特寫及復活演出。
- 紙娃娃不套在飛行器上。
- 機艙必須顯示本場實際生效的裝備能力。
- 尚未實作的能力標示「效果待開放」，不可讓玩家誤以為已生效。

### 8.2 能力分類

| 類型 | 例子 |
| --- | --- |
| 防護型 | 防止一次致命傷害 |
| 火力型 | 依武器特性換算合理幅度的輸出提升 |
| 機動型 | 提升移動、回撤或煞車反應 |
| 必殺型 | 增加回能、延長效果或改變大招 |
| 主動型 | 佔用右側套裝技能鍵，由玩家主動施放 |

武器增傷不可全部直接使用固定「傷害＋1」。快速多發武器與慢速重擊武器必須分別換算，等雛型完成後再用實際輸出測試調整。

### 8.3 母上的守護

被動效果，每場限用一次，不占用套裝技能鍵。

觸發流程：

1. 玩家第二次受傷，HP 歸零。
2. 播放墜落動畫。
3. 戰鬥停止並播放「母上守護」動畫。
4. 系統掃描畫面左側，尋找不會被目前或即將到達的地形、砲台占據的位置。
5. 玩家在安全位置復活，回復 1 HP。
6. 清除復活點附近少量敵彈，給予 1 秒無敵。
7. 本場守護標記為已使用。

若左側沒有安全位置，維持守護演出或等待狀態，直到能安全交回操作。再次 HP 歸零則正式敗北。

## 9. 出擊動畫與機艙畫面

### 9.1 機艙內容

同一畫面顯示：

- 可選飛行器與外觀預覽。
- 普攻示範。
- 攻擊、移動、回能、回撤速度。
- 已裝備特殊武器。
- 已裝備大招。
- 目前衣服及本場生效能力。
- 「出擊」按鈕。

### 9.2 森林彈射演出

整段約 3 秒：

1. 選定裝備後背景暗下。
2. 葉片機艙閘門向上開啟。
3. 螢光藤蔓導軌依序亮起。
4. 飛行器展開翅膀或飛行部件。
5. 鏡頭快速拉近，畫面出現速度線。
6. 飛行器衝出樹冠，無縫接入第一個卷軸區域。

演出只借鑑「整備完成後高速彈射出擊」的節奏感，視覺、角色、鏡頭與素材需保持本作原創的森林童話風格。

## 10. 關卡結構與分岔

### 10.1 新結構

- 取消原本十張短圖的流程。
- 每個地區改成一個約 45～55 秒的長區域。
- 每局隨機經過約 3～4 個區域，再接 BOSS。
- 加上出擊及 BOSS 戰後，單局目標總長為 3～5 分鐘。
- 敵人波次以時間軸生成，不必清光才能前進。

### 10.2 無縫分岔

- 區域約 40 秒時，提前出現上、下兩條下一區域提示。
- 使用大型樹幹、岩壁或雲層自然把畫面分成上下入口。
- 路牌顯示兩個區域名稱，例如「上：冰原／下：洞穴」。
- 玩家可飛入入口選定區，或直接點選路牌。
- 路牌本身不是選定判定，避免不小心碰到就選錯。
- 選定後入口亮框，另一條路淡出，再無縫銜接下一區。
- 到截止點仍未選擇時，從兩條合法路線隨機選擇。
- 分岔期間降低敵人及敵彈密度，讓玩家有公平的選擇時間。
- 路線生成必須保證最終能進入 BOSS，不出現死路。

### 10.3 區域玩法

| 區域 | 地圖特色 | 環境威脅 | 專屬敵人方向 |
| --- | --- | --- | --- |
| 空中 | 空間寬闊、雲層與浮島 | 強風帶、浮島障礙 | 大型編隊、背後突襲 |
| 湖泊 | 水面、霧氣、荷葉及倒影 | 移動霧團造成短暫減速；水花預警 | 從水面跳出的敵人、水面砲台 |
| 洞穴 | 上下岩壁形成狹窄通道 | 落石、收縮通道 | 壁面砲台、伏擊怪；彈跳武器有優勢 |
| 岩漿海 | 熱浪、熔岩河及噴發口 | 地面先發光，再噴出拋物線火山岩 | 耐熱裝甲怪、火焰噴射怪 |
| 濕地 | 藤蔓、泥霧與孢子 | 黏泥減速、漂浮孢子遮蔽部分視線 | 潛伏型與纏繞型敵人 |
| 冰原 | 雪霧、冰柱及冰晶峭壁 | 冷風減速、冰柱預警後掉落 | 蓄力衝刺怪、冰晶砲台 |
| 樹海 | 密集枝幹及上下岔路 | 枝條阻擋、側面落葉旋風 | 側面突襲、枝幹伏擊怪 |

環境減益必須有清楚視覺提示：

- 霧氣減速：機體周圍出現水滴或濕氣。
- 冰原減速：機體邊緣出現結霜。
- 黏泥減速：機體後方拖出黏稠痕跡。
- 減速效果不可無限制疊加，也不可降低到幾乎無法操作。
- 只有明確實體障礙或攻擊才扣 HP；單純霧氣以減益為主。

## 11. 敵人設計原則

每個區域採用「通用敵人＋區域專屬敵人＋環境機關」，避免只換背景。

每種敵人資料至少包含：

- HP。
- 碰撞傷害。
- 普攻傷害。
- 攻擊距離。
- 移動速度及軌跡。
- 攻擊 CD。
- 出場位置及波次。
- 攻擊前預警。
- 被擊中、擊敗及淨化動畫。
- 是否受緩速、黏著、擊退或鎖定影響。

第一批行為定位：

| 類型 | 行為 |
| --- | --- |
| 砲灰編隊 | 低 HP，以 V 字、S 型或直線群體進場 |
| 衝刺怪 | 懸停並預警後，鎖定玩家當下位置直線衝刺 |
| 坦型路障 | 高 HP、慢速，占據通道，鼓勵使用重型或貫穿武器 |
| 固定砲台 | 固定在地形上發射扇形彈幕 |
| 軌跡干擾怪 | 以波浪、上下穿梭或不規則但可觀察的路線前進 |
| 補給敵人 | 擊敗後掉落武器、回復或強化資源 |

所有攻擊需有能閱讀的前搖或警示，不使用毫無提示的貼身生成與立即命中。

## 12. HP、受傷與敗北

- 玩家生命上限為 2 HP。
- 每次有效受傷扣 1 HP。
- 兩次被擊中即進入墜落流程。
- 受傷後需要短暫無敵，避免同一波攻擊重複扣血。
- 第二次受傷後先播放墜落動畫，再判定是否有「母上守護」等復活效果。
- 沒有復活效果或效果已使用，顯示正式敗北畫面。
- 重試點、是否保留武器與能量，需在雛型測試後定案。

## 13. UI 顯示原則

- 左上：2 格 HP、分數及目前飛行器。
- 右側：特殊攻擊、大招、武器艙，以及有需要才出現的套裝技能。
- 大招按鍵以環形能量條顯示進度。
- 特殊攻擊按鍵顯示武器圖示及 CD 倒數。
- 武器艙內顯示武器用途，不只顯示攻擊數字。
- 敵彈、環境危險與玩家特效需使用不同顏色及輪廓。
- 手機按鍵不能遮住分岔入口、敵彈或 Boss 關鍵攻擊。

## 16. 尚待討論與測試

以下項目目前不應視為最終定案：

1. 聚氣雷射已確認為「點一下 → 自動集氣 0.5 秒 → 發射 → CD」；只需測試 5 秒 CD 與傷害平衡。

7. 分岔選擇時間、路線出現頻率與敵彈降量程度。
8. 服裝能力對不同射速武器的增傷換算方式。
