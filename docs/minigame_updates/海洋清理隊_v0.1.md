# 海洋清理隊 v0.1

2026-09-09｜第三款新幼童遊戲｜觀察推理

## 玩法

每局 12 個任務，分三段各 4 題，合計回收 15 個物品。沒有倒數失敗、扣命或 Game Over。每段開始有圖像教學，按「我準備好了」才繼續。

| 階段 | 操作 | 畫面內容 |
|---|---|---|
| 認識海洋朋友 | 點垃圾，小潛艇自動發射泡泡網 | 1 個垃圾、小魚與海龜；位置隨機 |
| 垃圾分分類 | 先點垃圾，等泡泡網抓到，再點回收桶 | 塑膠瓶→塑膠、金屬罐→金屬、紙箱→紙類；桶上有圖片 |
| 小隊長任務 | 看圖卡，只收指定物品 | 首題 1 個，後三題各 2 個；保留其他垃圾與海洋生物作為干擾 |

回收物限定明確的塑膠瓶、金屬罐與紙箱，不延伸至複合材質或真實地區回收規定。

點錯海洋生物：牠搖搖頭，顯示保護提示，原地保留並變淡，不會被網住。任務段點到非指定垃圾：提示本次目標，留待下一隊。分類選錯桶：垃圾保留在泡泡中，繼續選其他桶。每題每個錯誤選項只記錄一次。

答對後回收物消失；同一物品不會重複計數。完成時給正向感謝，不顯示負面排名。

## 操作

- 觸控或滑鼠直接點大圖案、回收桶。
- 1–4 選物品；A／B／C 選塑膠／金屬／紙類桶。
- P 或 Escape 暫停／繼續；H 提示；S 切換慢慢玩。
- 慢慢玩停止物品漂動，仍可作答，泡泡網的回收動畫正常播放。
- 提示只在按下按鈕後出現，維持 2.5 秒遊戲時間，暫停不消耗提示時間。
- 切到背景或失焦自動暫停；回到畫面需手動繼續。
- 支援音效開關、暫停說明、重玩、回到列表。
- 採原專案 1280×720 等比例縮放；手機、平板建議橫向。沒有另做直向版。

## 整合

實際累積基準是 `Color_Bubble_v0_1_Direct_Update_v2.zip`，不是交接檔列出的損壞 `Color_Bubble_v0_1_Update.zip`。

| 檔案 | 作用 |
|---|---|
| src/scenes/OceanCleanupGame.js | 獨立幼童場景、互動與生命週期 |
| src/data/OceanCleanupData.js | 題庫及純規則；預留 adult=false |
| src/data/MiniGameCatalog.js | 第 11 款，觀察推理類，列表第一張 |
| src/main.js | 匯入及註冊 OceanCleanupGame |

| assets/ocean-cleanup/sprites.png | 3×2 透明圖集，每格 512×512 |
| tests/ocean_rules.test.mjs | 規則、題庫及前兩款核心回歸 |
| tests/ocean_scene.test.mjs | Phaser API 模擬場景流程 |
| tools/build_ocean_demo.py | 使用相同源碼生成離線 HTML |

只沿用 AnimalSnackGame 的繪圖、按鈕、音效 helper；不沿用點心題庫、計分或輸入流程。MiniGameHub 由 catalog 自動取得數量、分類與分頁，因此不需更動 Hub。

新場景不寫正式進度、不發獎勵、不扣愛心、不解鎖成就、不綁地圖。成人版尚未開放，只保留能力設定。直接覆蓋包中原有點心、泡泡檔案及素材沿用基準，沒有改前兩款玩法。本包未包含原始完整主專案或衣櫥更新。

## 驗證與限制

```sh
node --test tests/ocean_rules.test.mjs tests/ocean_scene.test.mjs
```

- 200 個固定隨機種子、共 2400 個海洋任務：可完成、素材分布、目標數量、干擾項與總回收數 15。
- 保護生物、非指定垃圾、連點、錯誤桶重試、未回收前不能分類、提示計數、完成邊界。
- 模擬場景：飛行時暫停、慢慢玩仍能作答、提示期限、分類飛行鎖、階段卡、完成畫面、重玩返回、監聽清理。
- 前兩款核心回歸：80 組彩色泡泡隊／960 題各有一個正解；點心隊漏接重排、12 位送達完成。
- 新場景沒有正式存檔／獎勵寫入；catalog 11 款與場景註冊確認。
- PNG 尺寸、透明通道、離線 HTML JavaScript 語法、ZIP CRC 與解壓雜湊另行確認。

**限制：場景測試是 Phaser API 模擬，不是真實渲染器。** 此環境瀏覽器無法連線本機預覽（ERR_BLOCKED_BY_CLIENT），尚未完成瀏覽器畫面、真實點擊命中、觸控、音量及 file:// 雙擊離線驗收。也未在使用者完整主專案中啟動全部 11 款；這次不可當成完整 11 款回歸。

首輪實機試玩：解壓 DEMO，開啟 index.html；點魚、切慢慢玩、選錯一次桶、連點同個瓶子、完成 2 個物品任務、切換視窗後繼續、重玩及返回。玩法確認後再安排水域地圖、正式獎勵、收藏及成人難度。
