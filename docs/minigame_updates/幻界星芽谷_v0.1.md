# 幻界・星芽谷 v0.1

這次新增真正的 3D 小型探索地圖：地形、坡道、拱橋、樹木、房屋、水車均為立體網格；人物為透明的 2D 四方向圖集。使用固定 45 度俯角、固定方位的正交鏡頭跟隨人物，也可切換鳥瞰。沒有手動旋轉鏡頭。

## 安裝與入口

將 Phantom_Realm_v0_1_Integrated.zip 包內檔案覆蓋至原完整森林益智樂園，保留其他原檔，沿用原啟動方式。仍需要原完整主遊戲與既有 v5.3 衣櫃。
遊戲列表第一張「幻界・星芽谷」，或「觀察推理」分類。當前共 22 款入口。
本版由遊戲列表進入；尚未改動世界地圖選擇頁。離開會回到原遊戲列表。

## 第一章：沉睡的水車

1. 與榛果爺爺交談，取得引風扇。
2. 前往營地北方夢藤，使用引風，取得星芽齒輪。
3. 越過拱橋，從東岸南側木坡道登上高台。
4. 閱讀石碑，依「葉、月、星」順序點亮引水符印。選錯可重試。
5. 開閘後解鎖南方浮橋與樹屋滑索。可用滑索回營地，修復水車。

任務完成後水車轉動、星燈點亮，仍可自由探索。支線是尋找三隻螢火蟲，分別位於西岸、東岸南端與高台深處。
沒有戰鬥、死亡懲罰、付費或正式寶箱掉落。這次集中驗證立體探索與工具／任務流程。

## 操作

手機橫放：左側搖桿移動，右側互動、引風、按住快走。右上手帳有完整任務線索，鳥瞰切換全景，暫停可返回列表。
鍵盤：WASD／方向鍵移動，E 互動，Q 引風，Shift 快走，Esc 暫停／關閉面板。
直向會鎖住探索並提示橫放；恢復橫向後手動繼續。切換分頁或失焦會暫停。

## 進度與素材

任務階段與螢火蟲使用獨立 localStorage 鍵 forest_phantom_realm_v1 保存，不寫入主遊戲裝備、愛心或水晶。重新進入會在營地出生，保留任務結果；符印尚未完成的點選順序不保存。
請使用相同網址與連接埠，勿清除網站資料。手帳中的重玩只重設本章。
角色是原創阿晨晨 Q 版暫代形象，非真人肖像。四方向各一張站立、一張行走姿勢交替；未接入紙娃娃、多裝備分層或八方向動畫。
場景採低多邊形童話美術，屬第一版可玩空間，不代表已達到商業 RO 場景的材質、建築密度或動畫品質。樹屋外側高台可探索，屋內與橋下水路尚未開放。

## 技術交接

- src/scenes/PhantomRealmGame.js：原 Phaser 遊戲入口與返回清理。
- src/realm/RealmApp.js：觸控／鍵盤、介面、任務互動、保存與暫停。
- src/realm/RealmRules.js：世界高度、碰撞與任務規則。
- src/realm/RealmWorld.js：真正 3D 幾何、鏡頭、陰影、人物圖集與遮擋淡化。
- src/vendor/three.module.js：Three.js r170，MIT 授權附 THREE-LICENSE.txt；已包含本地檔案，執行時不向 CDN 下載。
- assets/phantom-realm/hero-directions.png：生成圖集，完整提示詞另附。

採獨立 3D 畫布與 DOM 操作面板，在離開場景時釋放 RAF、事件、材質、貼圖與 WebGL 資源。需要支援 WebGL 2 的瀏覽器；載入失敗提供返回入口。
官方技術參考：[Three.js 文件](https://threejs.org/docs/)。

## 驗證與下一步

本章規則測試涵蓋橋與坡道高度、河流／懸崖阻擋、正常步行通關、錯序重試與保存。另使用 Chromium 實際執行 WebGL 畫面與操作流程，預覽資料夾內為瀏覽器截圖。
桌面瀏覽器以軟體 GPU 執行；手機尺寸與觸控透過瀏覽器模擬，尚未在使用者手機／Game Viewer 實機驗收，不能當成實機效能或手感的結論。
下一步先收集人物大小、鏡頭角度、立體感、搖桿、遮擋與任務趣味回饋，再擴充 NPC、分支任務、第二種工具、素材細節與正式大地圖入口。
