# 雪屋躲貓貓｜遊戲方式

版本：v0.1 幼童試玩版  
更新日期：2026-09-12

## 遊戲目標

動物會先在雪屋門口露臉，再鑽進去躲好。連續打開兩間雪屋，找到兩隻相同的動物朋友。配錯不扣分，也不會出現失敗畫面。

## 五關安排

- 第 1 關：4 間雪屋，2 對動物。
- 第 2 關：4 間雪屋，更換另一組動物。
- 第 3～5 關：6 間雪屋，3 對動物。

每一關開始都會自動露臉約 2.4 秒；開啟「幫幫我」後會延長到約 3.3 秒。

## 操作方式

- 滑鼠或觸控：直接點雪屋。
- 鍵盤：按 `1`～`6` 選擇編號雪屋。
- `H`：讓尚未配對的動物暫時露臉。
- `P` 或 `Esc`：暫停／繼續。
- 「幫幫我」：成對動物的雪屋下方會出現相同顏色的提示標記。

## 幼童友善設計

- 前兩關先使用 4 間大雪屋，熟悉後才增加到 6 間。
- 雪屋的點擊範圍大於門與外觀。
- 點錯後保留觀察時間，再把門關上。
- 配對成功的動物會留在門口，不需要重複記憶。
- 可不限次數使用露臉提示，不扣愛心、不減少進度。
- 切換到背景或視窗失焦時自動暫停。
- 本原型不寫入正式存檔，也不發放正式獎勵。

## 回家後建議測試

1. 4 間與 6 間雪屋的尺寸是否適合手機、平板點擊。
2. 預覽 2.4 秒對阿晨晨是否太長或太短。
3. 妍妍使用「幫幫我」時，是否能享受開門與動物出現的回饋。
4. 配錯後約一秒的觀察時間是否足夠。
5. 暫停、提示、本關重來及返回列表是否正常。
