# 森林機關探險 v0.1

2026-09-09｜森林益智樂園第 12 款｜棋盤策略｜小學生版

## 本次方向

使用者實測動物點心隊與彩色泡泡隊後，認為過於簡單、玩法相似且容易單調。本次改為規劃型冒險：操作狐狸在格子地圖上走路、推箱、解機關，思考站位、順序及回頭路。以國小程度為設計目標，前幾關教操作，後段結合多種機關。

只交付整合更新包，直接加入首頁列表。不製作、交付或要求使用獨立試玩版。

## 核心規則

- 狐狸每次走一格；碰到木箱時，若後方可放置，推動一格。木箱不能拉、不能同時推兩箱。
- 所有圓形底座都被木箱壓住後，樹門可通關。沒有底座的關卡直接找出口。
- **水晶是額外目標**，沒有收齊也可以通關，再重玩挑戰。
- 金色鑰匙拾取後，這一關的金色鎖門保持開啟，通過不消耗鑰匙。
- 綠色閘門受全部底座控制；箱子離開底座會關閉。
- 每次走進橘色開關，橋在接通／關閉之間切換。停留原地不會反覆切換。
- 紫色傳送陣成對出現，走進一端傳到另一端，算一步；不會連續來回傳送。離開後再次踩入即可返回。
- 木箱只能推到空地或底座；已收走物品的空格也可放箱子。不能推上橋、傳送陣、開關、閘門、鎖門或樹門。
- 箱子若卡入非底座的石牆角，會提醒撤回，不強制結束遊戲。更複雜的無解局面可使用第三段提示檢查。
- 不設倒數、不扣命，不修改正式愛心、收藏、寶箱、成就或存檔。

## 重玩深度

18 關全部開放，直接選擇適合的難度。每關有三個獨立星星目標：

1. 成功通關。
2. 通關時收齊水晶。
3. 在目標步數內完成，而且未使用任何提示。

撤回不扣星，撤回後恢復路徑步數；提示使用次數不因撤回清除。重新挑戰才重算提示。每關顯示本次最佳星數，不把不同局的星星條件拼湊為三星。

星星存在目前遊戲記憶體；返回主遊戲列表後再進入仍保留，關閉或重新整理整個遊戲會清除。這是測試入口，尚未連接正式長期存檔或獎勵。返回選關可點同一關繼續當前未完成路線；切換到另一關會開始那一關，原未完成路線不另外存檔。

## 操作與分段提示

| 操作 | 方法 |
|---|---|
| 移動 | 方向鍵、WASD、畫面方向按鈕，或點狐狸旁邊的地格 |
| 撤回 | Z、Backspace 或「撤回一步」 |
| 分段提示 | H 或提示按鈕 |
| 重來 | R，遊戲內確認後重開本關 |
| 暫停／繼續 | P、Escape；切背景／失焦自動暫停，回來需手動繼續 |
| 返回 | 選關、遊戲列表皆有按鈕 |

第一次提示提醒觀念；第二次提示提供更具體策略；第三次起，以**目前的玩家、木箱、機關及收集狀態**求解，只標出下一步，七秒後消失。操作後提示失效，下次重新計算。

提示優先找能收齊水晶的路；若確定無法收齊但仍可通關，改提示通關方向。若完整搜尋證明走不通，建議撤回；若只是達到搜尋上限，會說尚未找到路線，**不把搜尋上限當作無解**。搜尋拆成每幀小批次，移動、撤回、選關皆可中止，不鎖死操作。暫停時搜尋與提示倒數一起停止。

## 程式與整合

| 檔案 | 內容 |
|---|---|
| src/scenes/ForestMechanismGame.js | 選關、格子畫面、輸入、動畫、分段提示、暫停與關卡結算 |
| src/data/ForestMechanismRules.js | 移動規則、撤回、收集、機關狀態與分批搜尋器 |
| src/data/ForestMechanismLevels.js | 18 張手工設計地圖、提示及步數目標 |
| src/data/MiniGameCatalog.js | 新增第 12 款，棋盤策略類、全部列表第一張 |
| src/main.js | 匯入並註冊 ForestMechanismGame |
| tests/mechanism_rules.test.mjs | 規則、18 關解法、撤回與首頁註冊檢查 |
| tests/mechanism_scene.test.mjs | 模擬 Phaser API 的場景流程驗證 |

以本對話海洋清理隊整合版本為底，繼承 AnimalSnackGame 的視覺及音效 helper，不繼承點心配送玩法。遊戲地圖、輸入、規則和關卡皆獨立。正式首頁 MiniGameHub 依 catalog 自動更新數量與分頁，不需要修改 Hub。

整合包根目錄即 src、assets、docs、tests，不套 UPDATE／DEMO 資料夾。包含前面三款遊戲必要檔案供累積覆蓋；不包含獨立 HTML、試玩引擎或 DEMO 建置工具。需要已安裝小遊戲總表 v4.0 的原始森林益智樂園完整專案；不提供整套原始主程式或衣櫥素材。

## 驗證

41 項測試通過，0 失敗。包括本次 23 項與前版 18 項回歸。執行環境 Node.js 24；這是開發檢查，一般玩家不需要執行。

```sh
node --test tests/mechanism_rules.test.mjs tests/mechanism_scene.test.mjs tests/ocean_rules.test.mjs tests/ocean_scene.test.mjs
```

- 18 關皆能通關、收齊水晶，並在效率目標內取得三星；不使用隨機擺牆冒充已驗證關卡。
- 每關完整路線經規則層與場景輸入方法各跑過一次；每一步撤回後可恢復起始人物、木箱、步數、鑰匙、橋及水晶狀態。

- 驗證鍵盤／方向按鈕共用移動方法的冷卻、防連點、相鄰地格點選、三級提示、提示過期、暫停搜尋、背景手動繼續。
