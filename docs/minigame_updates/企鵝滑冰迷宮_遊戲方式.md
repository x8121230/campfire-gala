# 企鵝滑冰迷宮｜遊戲方式

版本：v0.1 幼童試玩版  
更新日期：2026-09-12

## 遊戲目標

企鵝站在結冰湖面上，選擇一個方向後會一直滑到湖邊、雪堆或岩石前才停下。規劃上下左右的順序，讓企鵝在滑行途中抵達溫暖的營火。

## 五關安排

- 第 1 關：一次滑行，認識基本規則。
- 第 2 關：兩次滑行，第一次練習轉彎。
- 第 3 關：三次滑行，開始利用湖邊停下。
- 第 4 關：四次滑行，繞過多個障礙。
- 第 5 關：五次滑行，完成極光迷宮挑戰。

每一關都已用求解器驗證可完成，提示也會依照企鵝目前位置重新尋找路線。

## 操作方式

- 畫面按鈕：點選上下左右。
- 觸控或滑鼠：在冰面上朝想去的方向滑動。
- 鍵盤：方向鍵或 `WASD`。
- `H`：顯示下一步提示。
- `Z` 或 `U`：復原一步。
- `R`：本關重來。
- `P` 或 `Esc`：暫停／繼續。

## 幼童友善設計

- 沒有倒數、愛心或失敗畫面。
- 選到不能移動的方向只會提示換個方向。
- 可不限次數復原、重來及查看提示。
- 提示包含文字方向、放大的方向按鈕及冰面金色路線。
- 第一關只需一次滑行，逐步增加空間規劃難度。
- 切換到背景或視窗失焦時自動暫停。
- 本原型不寫入正式存檔，也不發放正式獎勵。

## 回家後建議測試

1. 手機和平板上的滑動手勢是否容易辨識正確方向。
2. 企鵝滑行速度是否需要加快或放慢。
3. 阿晨晨是否能理解「利用障礙物停下來」。
4. 第 4、5 關是否需要再增加圖像提示或拆成更簡單關卡。
5. 復原、提示、本關重來、暫停與返回列表是否正常。
