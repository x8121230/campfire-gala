# 森林設定選單 v0.1.1｜位置與齒輪修正

依使用者錄影修正，保留全畫面設定選單。

原因：原地圖 btn_edit 齒輪是佈置模式按鈕，點擊會變綠。上一版新增了 btn_setting 文字圖框加圓底，與原齒輪疊在一起。

本版直接重用原 btn_edit 齒輪物件，移至灰色橫幅內（中心 1210,40，圖案 60×60），移除上一版的設定圖框與圓底。地圖名稱回到原 y=20、32px 字體，右緣移到 x=1120 讓出齒輪空間。座標基於 1280×720 畫布。

齒輪的新點擊功能為全畫面選單，滑入／開啟時有暖色回饋，返回後恢復一般顏色。原佈置模式功能移至選單下方「佈置地圖／完成地圖佈置」按鈕，仍呼叫原地圖流程；佈置中齒輪保留原綠色提示。其餘語音、音樂、音效、手冊和寶箱入口沿用。

驗證：用原地圖按鈕身分模擬，確認重用 btn_edit、刪除錯誤框圖、舊點擊不再啟動佈置、恢復標題高度、返回復色、選單可啟動原佈置功能。導航與聲音檢查亦通過。檢查全部交付 JS 語法與 ZIP CRC／內容。368 項全套測試沿用上一版通過結果，本次針對修改的設定流程驗證，沒有重新宣稱真人或瀏覽器畫面已驗收。

安裝：將 Forest_Settings_v0_1_1_Fixed.zip 內檔案覆蓋至原完整專案，關閉舊分頁再重開，不清除網站存檔。保留 19 款遊戲、寶箱與冒險手冊。
