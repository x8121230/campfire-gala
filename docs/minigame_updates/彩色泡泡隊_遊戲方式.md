# 彩色泡泡隊｜遊戲方式 v0.1

## 一局三段，每段四題

| 階段 | 題目與選項 | 玩家判斷 |
| --- | --- | --- |
| 顏色 | 都是圓形，分別是紅、藍、黃 | 找到與圖卡同色的泡泡 |
| 圖形 | 都是同一種中性色，分別是圓、三角、星形 | 找到與圖卡同形的泡泡 |
| 雙條件 | 一顆全對、一顆只對顏色、一顆只對圖形 | 顏色和圖形必須同時符合 |

每題三個選項、只有一個答案，位置會洗牌。題目圖示常駐左欄，不依靠識字才能判斷。
一般狀態三顆泡泡的框線、大小相同，沒有答案光效。

## 操作

- 直接點選泡泡，飛行器送出魔法光球；飛行中暫時鎖定其他選擇，避免多次計分。
- 鍵盤 1／2／3 對應左、中、右泡泡；P／Esc 暫停或繼續。
- 泡泡在三個互不重疊的區域柔和往返，不會飛出畫面，沒有超時失敗。
- 「慢慢玩」隨時開關，只停止泡泡移動，仍然可選答案。
- 「小精靈提示」停住泡泡並圈出正確答案 2.5 秒。同題多次查看只記一次提示題數。
- 答錯選項變淡且本題不可重複點擊，避免同一個錯誤被連續計算；其他選項保持可選。
- 雙條件答錯會說明差在顏色或圖形。
- 每段結束換規則時顯示說明卡，按「我準備好了」才繼續。
- 視窗失焦、切到背景自動暫停，回來後手動繼續。

## 計分與完成

十二題全答對才完成。答錯可繼續嘗試，不扣愛心、不扣體力、不顯示失敗。
結算顯示完成題數、未用提示且一次找對題數、重試次數、使用提示題數。
「未用提示且一次找對」須該題沒有答錯、沒有按提示；與慢慢玩無關。
所有紀錄只保留在當局，不發寶箱、不解鎖正式成就、不寫入存檔。

## 美術與音效

森林天空背景、新生成的柔和水彩風格；飛行器沿用點心隊。
圖形以程式繪製，目標與選項共用繪圖函式；圓形、三角形、星形輪廓不同。
紅／藍／黃對比明確；顏色題本身依賴辨色，本版尚未提供色覺輔助符號模式。
提供柔和合成提示音，尊重全域靜音／音量；本版沒有 BGM 或口語配音。
