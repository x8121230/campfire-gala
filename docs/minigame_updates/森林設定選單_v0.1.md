# 森林設定與冒險選單 v0.1

累積整合包，保留 19 款遊戲、冒險手冊、寶箱與當場開啟。覆蓋原完整主遊戲，關閉舊分頁再重開，不清除網站存檔。

## 地圖與首頁入口

地圖與首頁加入右上正式齒輪。地圖名稱移到齒輪左側並略向下，位置 x=1090、y=43，右對齊、28px 字體；齒輪中心 x=1206、y=66，淡色圓底、圖案 68×68、點擊範圍 100×100（1280×720 邏輯畫布）。在 667px 寬橫向畫面約為 52px 點擊範圍。原 btn_setting 齒輪由新入口替換；愛心、水晶、聲望和彩蛋點擊保留。

## 選單

語音、音樂、音效為三個獨立開關，新增正式「森林冒險手冊」「我的寶箱」連結。關閉選單恢復原場景；前往手冊或寶箱後，返回按鈕回到原地圖編號或首頁。寶箱內再進手冊，也會保留返回地圖的路徑。不經過測試樂園。

聲音開關是全域允許開關；遊戲本身若另有關閉音效，仍尊重該局設定。音樂開關套用 Phaser 背景音樂／循環聲音；音效套用其他 Phaser 聲音、點心系列合成音、營火完美音與星空音階、衣櫃合成音。衣櫃自身音樂／音效按鈕也同步保存全域偏好。語音開關控制既有 speechSynthesis 朗讀，沒有旁白的內容不會新增語音。

設定獨立儲存在 forest_preferences_v1，切場景與重開沿用；首次啟用會沿用主存檔既有 wardrobe_audio 音樂／音效偏好（若有）。與寶箱、愛心、進度存檔分開。儲存被阻擋時會提示，不把失敗的偏好當成保存成功。

## 驗證與限制

368 項既有自動測試通過。另有模擬檢查：語音偏好持久化、音樂／音效分開靜音、儲存失敗保留、齒輪位置與替換、標題位置、設定選單及地圖編號傳遞。手冊模擬檢查也通過。尚未實際驗收瀏覽器聲音、語音引擎、手機安全區和畫面排版，請先測三個聲音開關與兩條返回路徑。

程式入口：AdventurePreferences.js、AdventureSettings.js、AdventureSettingsIntegration.js。美術重用現有齒輪，圓底與面板由 Phaser 繪製，無新增外部素材依賴。後續可再擴充音量滑桿和各款遊戲原生設定整合。
