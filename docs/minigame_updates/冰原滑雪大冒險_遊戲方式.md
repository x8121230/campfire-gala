# 冰原滑雪大冒險 v0.1｜幼童試玩版

## 目標

在雪道上收集 12 顆藍色冰晶，抵達冰晶雪村。不限時間，撞到障礙不會結束遊戲。

## 操作

- 鍵盤：`←`／`A` 往左，`→`／`D` 往右，`↑`／空白鍵跳躍，`P`／`Esc` 暫停。
- 滑鼠與觸控：點畫面左右兩側的大按鈕移動，點「跳起來」跳躍。
- 滑動：在雪道上向左、向右或向上滑動。
- 「慢慢滑」會把雪道速度降到約六成，收集與完成規則不變。

## 幼童友善規則

- 開始前有圖像與文字教學。
- 前兩顆冰晶較常出現在玩家目前的雪道，先讓孩子熟悉左右移動。
- 障礙包含雪松、岩石、冰洞和雪人，可換道或跳過。
- 撞到障礙只會短暫翻滾並獲得保護時間，不扣冰晶、不重來。
- 頁面切到背景或視窗失焦時自動暫停。
- 試玩結果不扣主畫面愛心、不發寶箱、不解鎖成就、不寫正式進度。

## v0.1 驗收重點

1. 左右移動是否太快或太慢。
2. 跳躍高度與落地時間是否自然。
3. 障礙物是否清楚、是否太密集。
4. 冰晶是否容易看見和收集。
5. 觸控大按鈕與滑動是否會互相干擾。
6. 角色大小、雪道寬度與畫面資訊是否適合孩子。
