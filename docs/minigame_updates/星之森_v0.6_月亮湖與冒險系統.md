# 星之森 v0.6｜月亮湖與冒險系統

2026-09-10 · 累積整合版。保留 A 版 3D，B 版新增月亮湖與共用冒險規則。

## 安裝與入口

將 ZIP 內容合併覆蓋至原「森林益智樂園_v2_完整測試版」，保留原本未出現在包內的檔案。沿用原啟動方式，在遊戲列表選「星之森・2.5D 手繪繪本版」。新存檔從月亮湖開始，可由西岸出口往返星之森。

同一包內也附 `storybook-play.html`，可在原伺服器網址下直接開啟這兩個版本。若僅有此包，可在解壓資料夾執行 `python -m http.server 8000`，再開啟 `http://localhost:8000/storybook-play.html`。這是同一套遊戲程式的入口，不另分一份試玩包。請勿以 file:// 直接雙擊載入模組。

完整主遊戲仍需原有底層場景、啟動器與相依套件。此次取得的是累積整合檔案，不包含原完整主遊戲的所有底層來源。

## 這次可玩的內容

- 月亮湖：連續的西岸與東岸、深靛藍湖水、慢速星光倒影、波紋、月光水母與感應發亮／響鈴的蘆葦。
- 月亮湖四段委託：安撫三隻水豚 → 探索五片荷葉 → 淨化月冠天鵝 → 沿南側星霜路回西岸。
- 隱藏荷葉由固定的蒲公英閃避照亮，不依賴 A／B 裝備。照亮後保留，踩過的進度保存；水域碰撞逐小段檢查，閃避不能跳過不支援的湖面。
- 水豚、貝殼水獺、泥巴蛙、月冠黑天鵝各有普攻與特殊攻擊；橘色提示先出現，再發動潑水、直線滑行、泥巴區域或旋風。
- 安撫後不流血、不消失：水豚入睡、水獺／青蛙休息，黑天鵝變回白天鵝並開啟永久星霜捷徑。
- 星之森保留連續草地與坡地，改用相同 HP／MP、裝備、技能與單一委託規則。委託依序為八隻動物、五顆蘋果、三處泥巴、小鴨護送；30 秒金橡果活動保留。
- 走近居民自動觸發：短暫停頓、音效、視窗動畫、大字分頁與逐字顯示。點文字立即顯示；離開較大的範圍後才會再次觸發。對話期間世界暫停。

## 操作

| 功能 | 手機 | 鍵盤 |
| --- | --- | --- |
| 移動 | 左搖桿 | WASD／方向鍵 |
| 普攻 | 右下大按鈕，按住連發 | 按住空白 |
| 蒲公英閃避 | 普攻左側 | Shift |
| 技能 A／B | 右側上排兩格 | Q／R |
| 任務／出口／活動 | 靠近時出現的中央情境按鈕 | E |
| NPC 對話 | 靠近自動觸發 | 靠近自動觸發 |
| 暫停 | 右上按鈕 | Esc |

情境按鈕只在有可用目標時出現，不占用 A／B。動物的淨化一律透過戰鬥技能；「清洗小路」僅對當前任務的泥巴生效。採集與清洗不消耗魔力。技能點按會自動選近處目標；拖曳 A／B 可指定蜂蜜落點或大象噴水方向，放開施放。

一次只有一件主要委託。跨區保留目前委託；想先做另一區，可在手帳放下委託，已完成的安撫、採集、荷葉與清洗不會重置。金橡果是獨立限時活動，不占主要委託欄。

## 驗證與目前範圍

38 項規則測試通過（16 項新版＋22 項既有森林／3D 規則）。瀏覽器執行真實新版模組，檢查自動對話、逐字跳過、按住攻擊、耗魔、換裝、技能換格、任務按鈕、存檔重載、兩區往返、失焦取消演出、直向暫停，以及 844×390／667×375 橫向控制元件邊界與互不遮擋。原 3D 七個來源檔雜湊保持不變。

完整 Phaser 主遊戲整合與實體手機多點觸控、音量及真人難度尚待在原主遊戲環境試玩。月亮湖與第一區已實作；泡泡泥沼、巨大黑熊及完整世界地圖是後續區域。本版只有初始兩件可穿卸裝備，新武器掉落與更多防具日後可從資料表延伸。
