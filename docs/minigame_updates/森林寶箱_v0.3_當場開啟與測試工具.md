# 森林寶箱 v0.3｜當場開啟與測試工具

本次為累積整合更新，保留 19 款遊戲。覆蓋原完整專案後關閉舊分頁、重新開啟；不清除網站資料。需要原完整主遊戲與 v5.3 衣櫃及其現有依賴。

## 立即開箱

獲得寶箱後，動畫下方改成兩個大按鈕：

- 立即開啟 ♥ 1：花一愛心開啟剛取得的那個寶箱。寶箱搖動後揭曉裝備，點「收下，繼續」回到原成就／結算，無須前往寶箱小屋。
- 先收起來：沿用飛入寶箱架動畫，之後到寶箱小屋開啟。

愛心不足時提示先收好，不扣箱。已開過的箱子不再扣心。裝備與扣心在揭曉動畫前保存，中途關閉也保留结果。開箱結果沿用目前裝備、升階和滿階轉水晶規則。測試遊戲的舊快照會同步明確支付的愛心，離開測試遊戲不會把開箱扣心還原。

## 衣櫃測試工具

衣櫃右上「測試工具」→「獲得寶箱／補滿愛心」。原取得選取裝備、補齊全道具按鈕保留。

新增工具頁：五款指定寶箱各一個按鈕、隨機獲得一箱、五種各獲得一箱、補滿愛心。指定與隨機送箱直接接獲箱演出，也可立即開啟。五種各一箱一次保存全部五箱，先展示苔蘚寶箱，另四箱留在架上。退出工具或收完獎勵回到衣櫃，衣櫃會重新顯示最新收藏。

測試寶箱確實加入目前存檔，但不建立通關領取紀錄、不占用每日首勝、不改保底。測試箱為三星；開箱仍花一愛心、仍走正常裝備與前三次開箱優先新裝備規則。補滿愛心使用目前 max_hearts 上限並清除恢復倒數，不額外改寶箱、水晶或裝備。沒有新增重置存檔功能。

## 驗證及接續

356 項自動測試通過。新增送箱與存檔失敗、首勝保底隔離、補心、立即開啟的場景交接、無愛心及連點處理。另用主遊戲存檔模組確認測試快照恢復後，開箱扣心和裝備仍保留。場景顯示／輸入為模擬；實際瀏覽器、手機和完整衣櫃操作仍待真人驗收。參考衣櫃缺少舊全道具測試依賴，QA 以禁止執行的替身補足導入，此替身不交付，也未聲稱舊全道具功能通過本次測試。

修改入口：ChestTestTools.js、InstantChestOpen.js、ChestRewardCelebration.js；衣櫃入口位於 ChestIntegration.js。ChestLedger.js 負責測試送箱與補心；ForestChestService.js 負責當場開箱及快照同步。沿用原童話圖集，沒有新增外部美術依賴。
