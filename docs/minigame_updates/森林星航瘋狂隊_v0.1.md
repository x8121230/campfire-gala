# 森林星航瘋狂隊 v0.1

2026-09-10｜糖果雲端嘉年華｜累積整合更新

本版依使用者 IMG_0166.MOV 確認的橫向飛行模式製作。1280 × 720 橫向畫面，飛行區域 1280 × 480。阿晨晨從左側出發，能在畫面內自由飛行，背景自動向左捲動，主射擊向右。原「森林天空守衛隊」「森林守夜隊」維持各自玩法。

## 安裝與入口

解壓 `Forest_Starflight_v0_1_Integrated.zip`，將包內檔案覆蓋原完整森林益智樂園；保留原本其他檔案與存檔。需要原完整主專案及既有衣櫃 v5.3 基礎，本包包含衣櫃 v5.4 更新。沿用原啟動方式，不能把本累積更新包當成完整空白專案獨立啟動。

入口：遊戲列表第一張「森林星航瘋狂隊」，或「反應節奏」分類。總表 23 款。註冊於 `src/main.js` 與 `src/data/MiniGameCatalog.js`。

## 一關內容

- 0–120 秒：花糖雲海。熟悉能量收集、編隊、斜向彈與救援。
- 120–240 秒：氣球市集。加入柱狀障礙和上下通道。
- 240–360 秒：積木拱門。通道較窄、障礙較密，武器也會被柱體擋住。
- 360 秒後：熊船長飛行城堡。三階段依生命比例切換：瞄準扇形彈 → 蓄力星光炮 → 增強彈幕與小隊增援。
- 大部分敵人從右邊進場。約每 38 秒可能有一次左／上／下偷襲，提前 2.7 秒顯示警告。
- 六種對手：飛行貓頭鷹、氣球松鼠、砲塔甲蟲、野狼飛行員、螺旋蝸牛、緞帶星精靈。救援目標同為星精靈，外加薄荷色圓環區分。
- 救援可回血與加分；連續擊退維持倍率，最高四倍。角色不流血，敵人消散為星光。

滿強化的自動操作測試約 7 分多鐘完成；初次遊玩預估 7–11 分鐘，實際會受強化選擇、命中率與重試影響。這是流程初版，趣味與難度需要真人回饋。

## 操作

| 功能 | 手機 | 鍵盤 |
| --- | --- | --- |
| 自由飛行 | 左側拖曳搖桿，可從左下區開始拖曳 | WASD／方向鍵 |
| 射擊 | 右下按住射擊；預設開啟自動射擊 | J |
| 循環強化 | 拾取金色能量後按「兌換」 | 空白鍵 |
| 無敵衝刺 | 衝刺鈕，4 秒冷卻 | Shift |
| 清彈星爆 | 星爆鈕，消耗一顆 | K |
| 暫停 | 右上暫停 | P／Escape |

手機直放、切換分頁／離開視窗時自動暫停。回到橫向後點繼續。指標取消和場景退出會清掉按住狀態。支援移動、射擊與技能多指操作。

## 六格循環強化

游標從未選取開始。每顆金色能量推進一格，六格循環；按兌換購買當前格並重設游標。已滿級不浪費選取，可繼續拿能量前進。每局起始為青葉連射。

| 格 | 功能 | 上限 |
| --- | --- | --- |
| 加速 | 提高自由移動速度 | 2 |
| 飛彈 | 追蹤前方目標的副武器 | 2 |
| 雙重 | 增加斜上射擊；第二級增加斜下 | 2 |
| 雷射 | 增強傷害並貫穿數個敵人 | 2 |
| 精靈 | 最多兩位跟隨射擊的星光僚機 | 2 |
| 護盾 | 補至三次抵擋；有損傷可再次兌換 | 3 層 |

雙重與雷射互斥，已投資等級保留，再次兌換可切回；其餘可同時生效。衝刺短暫免傷，仍需避開持續佔據通道的障礙。星爆清除當前敵彈、傷害敵人並給予短暫保護。

## 難度與重試

標準 8 生命；挑戰 5 生命，敵彈更快。每段開始補 2 生命、1 星爆。失敗可以從當段起點重新飛行，恢復生命、至少 2 星爆，回復該段起點的強化、分數及統計。無限次重試，避免為測試末段而反覆重玩整關。

本遊戲的分數、強化、檢查點僅保留於當局；返回列表或重載後不保留。尚未接正式寶箱、成就與紙娃娃。原本五款基礎遊戲的寶箱系統與既有衣櫃更新保留。本版沒有另外新增背景音樂曲目；新遊戲短音效遵循全域音效偏好。
