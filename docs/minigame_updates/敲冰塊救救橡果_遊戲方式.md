# 敲冰塊救救橡果 v0.1｜備用幼童試玩版

## 目標

觀察橡果目前站在哪一塊冰上，依序敲碎支撐冰塊，利用掉落與滑動讓橡果安全抵達底部雪堆。共有五座冰塔。

## 操作

- 滑鼠與觸控：直接點擊冰塊。
- 鍵盤：左右方向鍵選擇冰塊，空白鍵／Enter 敲擊。
- `H` 或「亮出支撐冰塊」顯示目前正支撐橡果的冰塊。
- `R` 或「本關重來」重新堆好冰塔；`P`／Esc 暫停。

## 雙年齡層設計

- 小小孩可以自由點擊裝飾冰塊，享受冰塊碎裂、飛散和清脆聲音的因果回饋。
- 大孩子需要觀察橡果腳下的支撐，依照由上而下的正確順序敲擊。
- 提前敲到未來支撐時只會出現裂痕與提示，不會讓關卡無法完成。
- 敲錯不扣分、不扣生命；所有關卡都能隨時重來。
- 每敲對一塊，橡果會受到重力掉落到下一層，並依冰橋位置左右滑動。
- 五關依序加入直落、左移、左右轉折、長階梯與五層冰晶塔。
- 切到背景或視窗失焦時自動暫停。
- 不扣主畫面愛心、不發寶箱、不解鎖成就、不修改正式存檔。

## v0.1 驗收重點

1. 冰塊是否夠大、容易點擊。
2. 橡果目前站立位置是否容易判斷。
3. 碎裂特效、掉落速度與聲音回饋是否有趣。
4. 提前敲擊、提示與本關重來是否正常。
5. 五座冰塔完成後是否正常結算。
