# 星之森 v0.4：3D 原版＋2.5D 繪本地塊版

這次依參考圖修正為 2.5D 繪本地塊版，保留原 3D 版及其進度，兩者可在遊戲列表分別進入。仍是一份累積整合更新包，不分 UPDATE / DEMO。

## 安裝與入口

關閉遊戲並備份原資料夾。解壓 `Star_Forest_v0_4_Isometric_Tiles_Integrated.zip`，把包內檔案直接貼到原「森林益智樂園_v2_完整測試版」，合併資料夾並取代同名檔案，保留其餘原檔。沿用原啟動方式與網址，不要清除網站資料。

遊戲列表最前面現在有兩張卡片：

- B 版：「星之森・2.5D 繪本地塊版」。新畫風，獨立保存。
- A 版：「星之森・3D 原版」。保留上一版的立體場景與進度。

繪本版右上「版本」也可以直接轉入 3D 原版；返回遊戲列表可以再次選擇另一版。原 3D 檔案、其他遊戲及衣櫃沒有被替換成繪本地塊版。

本包依原累積整合包擴充，仍須覆蓋到既有完整主遊戲；不包含原附件缺少的主遊戲啟動頁、Phaser、PlatformStorage 等基礎檔案。

## 可以比較什麼

| 項目 | A：3D 原版 | B：2.5D 繪本地塊版 |
|---|---|---|
| 場景 | 真正 3D 低多邊形地形與物件 | 2.5D 等角手繪地塊、可見土層側面、紙片景物 |
| 主角 | 原阿晨晨四方向人物 | 同一位棕髮阿晨晨，新增星杖、葉片翅膀及四方向站立／行走圖 |
| 遮擋 | 鏡頭射線判斷樹冠透明 | 依前後排序，擋住主角的景物淡化 |
| 地圖／魔法 | 原第一章 | 相同地圖座標、8 隻動物、5 顆蘋果、相同魔法數值 |
| NPC | 靠近自動對話 | 靠近自動對話，保留離開再靠近的防重複判定 |
| 採蘋果 | 靠近後按互動 | 接任務後，走近自動採摘 |
| 小鴨護送 | 搖桿控制慢走 | 護送時自動降低移動速度，直走／斜走一致 |
| 蘑菇 | 地景 | 靠近會出現音符與短音效，走開後可再次觸發 |
| 引導 | 手帳與地圖 | 加入可關閉的方向箭頭、下一目標及距離 |
| 鏡頭 | 固定跟隨 | 標準／廣角／近看三段視野 |
| 存檔 | 保留原進度 | 新的獨立進度，不複製或清除原版 |

建議先比較樹屋村與蘑菇林的整體畫風，再看人物能否清楚辨識、走到樹後是否容易找回角色、左手移動加右手施法是否順手。兩版都可繼續玩，不需要先決定刪除哪一個。

## 繪本地塊版玩法

1. 走近貓頭鷹村長，自動接下委託。
2. 按住星光泡泡，安撫 8 隻森林動物；到東方高坡走近 5 顆陽光蘋果，自動採摘。
3. 完成後回村，走近村長自動交任務。
4. 走近小鴨自動接護送，沿小路帶回鴨媽媽旁；護送中自動慢走。
5. 靠近金橡果風鈴，按互動開始 30 秒活動，可反覆挑戰。

手機橫放：左搖桿移動，右側四個魔法。蜂蜜可從按鍵拖曳指定落點；泡泡按住自動連射。右上「指引」可開關箭頭，「視野」切換遠近。

鍵盤：WASD／方向鍵移動，J 泡泡，Q 蜂蜜，空白鍵蒲公英滑步，R 大象，E 操作風鈴／路牌，M 地圖，Esc 暫停。

指引箭頭只指向目標方向，不會替玩家移動或繞路，仍要避開樹幹與池塘。採蘋果、任務完成與橡果最佳成績自動保存。NPC 對話、地圖、手帳、失焦與直放手機時暫停所有玩法，繼續後不會殘留按住輸入。

## 版本保留與限制

- 3D 版存檔鍵：`forest_star_forest_ch1_v1`，原樣保留。
- 繪本地塊版存檔鍵：`forest_paper_forest_ch1_v1`，獨立儲存。
- 手帳「重玩繪本版」有再次確認，只清除 B 版。
- 舊幻界水車章存檔及衣櫃資料不受影響。
- 本次第一章範圍相同；泥沼與月亮湖仍是待開放入口，沒有新增黑熊頭目。
- 繪本地塊版用 2D 畫布呈現斜俯視與高低差，不支援旋轉鏡頭、進屋或從橋下穿越。
- 阿晨晨尚未連動衣櫃紙娃娃；新造型是本版本固定造型。
- 兩版仍依賴原完整遊戲環境。瀏覽器模組與觸控模擬驗證範圍詳見 `Paper_Forest_QA.json`，實機 Game Viewer 與手機仍待試玩。
