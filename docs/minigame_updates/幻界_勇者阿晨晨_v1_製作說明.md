# 幻界・勇者阿晨晨 v1

## 正式造型

- 名稱：勇者阿晨晨
- 初始套裝：星芽旅行者套裝
- 比例：2.5～3 頭身 Q 版幼童比例
- 髮型：深棕色微捲雙馬尾、雛菊髮飾
- 服裝：奶油白泡泡袖、星芽綠背帶短裙褲、莓紅小斗篷
- 鞋子：草莓棉拖鞋
- 主武器：黃銅星光吹泡泡棒
- 副手：橡果小木蓋圓盾
- 收集包：斜背雛菊水壺包

## 已接入遊戲

- 前、後、左、右四方向正式透明角色素材。
- 星芽營地與晨曦蒲公英丘陵共用同一套角色。
- 依移動方向切換角色視角。
- 待機呼吸、跑步上下彈跳與輕微身體擺動。
- 丘陵草地腳步會揚起青草碎屑。
- 進入淺水窪會產生兩側小水花。
- 完成 MAIN_03 後取得第一顆「微光星芽珠」，在背後環繞顯示。
- 最多顯示三顆已持有靈珠，使用柔白、星藍與幻紫光色。
- MAIN_01 的布隆克獎勵已改名為「星芽旅行者套裝」。

## 素材規格

- 四方向遊戲素材：420 × 720 PNG、RGBA 真透明。
- 母版：1536 × 1024 PNG、四方向角色轉向表。
- 遊戲顯示高度：154 世界像素，與營地 NPC、丘陵怪物比例一致。
- 色鍵清理工具：`tools/chroma_key_magenta.py`。

## 後續擴充介面

目前 v1 是正式四方向角色母版與預設裝備。下一階段可在相同 420 × 720 基準上增加：

- 八方向與逐格跑步動畫。
- 玩具木劍、星光吹泡泡棒、蒲公英手搖鈴三種武器附件。
- 揮劍、施法、受擊、閃步、採集動作。
- 將既有紙娃娃服裝轉換成 2.5D 方向附件。
