# 森林星航瘋狂隊 v0.3｜連續卷軸街機修正

## 套用基準與範圍

需要已安裝星航 v0.2 的完整森林益智樂園。本次是小型修正檔，不是完整遊戲。
只替換兩個執行檔：`src/data/StarflightRules.js`、`src/scenes/ForestStarflightGame.js`。
沿用 v0.2 的五張背景與人物素材，不覆蓋 Collection、裝備表、MiniGameCatalog、其他遊戲或存檔。
因此之後加入的衣櫃 11～20 件內容不會被本包改回舊版。
遊戲列表卡片的舊描述不在本包修改範圍內；開始畫面顯示「v0.3 · 無縫街機航線」即可確認更新。

## 玩法改動

- 保留十段相容接點與種子亂數，但隱藏段數；背景依同一世界時間持續移動、區域色調漸變，不再突然替換背景或閃白。
- 遠景 18、中層雲 48、近景浮島 95 世界單位／秒；實體障礙 155／秒。
- 使用分段資料及重複背景，不建立巨大的單張圖片。所有接點保留中心通道。
- 每段 15 秒，150 秒警報後出現熊船長，目標約 3～4 分鐘完成一局。
- 敵人與補給由秒數事件表生成，不等待清光敵人。地形在場時不安排新的高速混合編隊。
- 移除六格循環強化、武器箱三選一及自動暫停選單。
- 擊破紅帽補給雲，掉落每 1.5 秒循環一次的變色星星。綠草／藍光／金絨各有不同圖案，非僅依顏色辨識。
- 星星接近玩家時短暫鎖色 0.35 秒，降低碰觸瞬間跳色的誤拿機率；不會自動磁吸武器道具。
- 同款升級，異款切換；三種武器各自保留本局等級，最高 Lv.3；滿級同款轉換 750 分。

## 武器與敵人

| 項目 | 本版行為 |

| 幸運草連射 | Lv.1 雙向、Lv.2 三向、Lv.3 五向，快速散射 |

| 蒲公英導彈 | Lv.1 雙發、Lv.2 四發、Lv.3 六發；Lv.3 命中附帶小範圍爆破 |

| 打嗝小烏雲 | 1 HP，V 字與波浪編隊 |
| 紙飛機鼯鼠 | 懸停瞄準一秒，固定 Y 軸後直線衝刺，不再追著玩家轉向 |

新敵人本版使用程式繪製的試作造型，背景與主角仍沿用既有繪本素材；後續可替換為精修手繪圖而不更動行為。

## 操作與視覺

- 預設自動射擊，移除底部大型黑色儀表板；生命、武器、分數集中上緣。
- 手機左手搖桿，右手聖爆，另保留小型閃避鍵；關閉自動射擊後出現手動射擊鍵。
- 電腦 WASD／方向鍵移動、J 射擊、K／空白聖爆、Shift 慢速、L 閃避、P／Esc 暫停。
- 主機受傷判定半徑 5 世界單位，接近子彈或按慢速時強調中心光點。
- 擦彈加分，每顆彈只計一次；敵人命中反白約 0.035 秒、淨化白雲、掉落星星分數。
- 撞地形扣一格生命並回到安全通道，保留受傷無敵，不立即秒殺。
- 受傷、精英淨化及聖爆輕震；標題可切換柔和效果，並尊重系統降低動態效果偏好。
- 失焦或轉直向自動暫停。手动暫停保留，僅取消強制換武器暫停。

## 額外修復

瀏覽器多指測試發現原先用 `children.removeAll(true)` 切換畫面時，未確實銷毀互動物件。
舊「開始飛行」按鈕可能在手機聖爆區域繼續接收觸控。本版改為逐一銷毀舊顯示物件，避免中途重開與看不見的觸控區。

## 驗收

- Node 全套測試：471／471 通過，含 21 項星航專項。
- 三個普通控制自動試玩種子：182、175、187 秒完成，沒有使用武器選單或修改生命。
- Chromium 桌機：即時換武器、接點連續滾動、背景漸變、手動暫停、聖爆及 Boss 畫面通過。
- Chromium 手機模擬：觸控開始與繼續、雙指移動＋聖爆、放開手指、直向暫停通過，無瀏覽器 JS 錯誤。
- 這些不是實體手機 FPS 或真人難度驗證；仍需你的手機試玩回饋。

## 未包含

隱藏關卡解鎖、永久武器成長、新章節、裝備能力與衣櫃修改不在此包範圍內。
