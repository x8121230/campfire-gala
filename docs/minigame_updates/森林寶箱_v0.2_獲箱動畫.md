# 森林寶箱 v0.2｜獲箱動畫

新增整合於主遊戲的 ChestRewardCelebration 獎勵場景。遊戲仍共 19 款，獎勵動畫不列入遊戲列表。

成功掉箱並保存後，原遊戲暫停，進入森林綠底、金色邊框的獎勵畫面：光暈與光芒聚攏、340 像素寶箱彈跳登場、18 顆星光散開、寶箱輕浮動。顯示對應的五款寶箱外觀、星數，以及每日首勝／保底／隨機發現的說明。短音效沿用柔和合成音，尊重靜音設定。

玩家可隨時按「收進寶箱架」（440×88 像素）略過等待；寶箱縮小飛向右上寶箱架，約 0.48 秒後繼續原遊戲的成就／結算。未掉箱或儲存失敗不播放成功動畫。原成就計時、遊戲输入在演出期間暫停，避免成就遮蓋寶箱；關閉動畫恢復原場景。

動畫純粹展示已保存的結果，不發第二份獎勵、不扣愛心。尚未進入開箱流程。開啟寶箱仍在寶箱小屋確認消耗 1 愛心。中途關閉遊戲後，已保存的寶箱仍在架上。五款地圖與測試入口共用的首勝、掉率與保底沿用 v0.1.1。

同時縮小開箱結果中的箱子並調整垂直間距，避免「已存入装備收藏與衣櫃」壓在箱子上。重用既有童話寶箱圖集，光暈／光芒／星光由 Phaser 繪製及補間動畫生成，沒有新增外部素材依賴。

安裝：Forest_Chests_v0_2_Animation.zip 直接覆蓋原完整主遊戲。關閉舊分頁再重開，不清除網站存檔。需要原完整主遊戲及既有 v5.3 衣櫃。手機請橫放。

349 項自動測試通過；新增六項場景模擬測試覆蓋五款外觀、彈跳星光、提早收下與連點、外部關閉、缺圖備援、靜音。另以實際踩地雷通關方法驗證存檔先於動畫、暫停主場景、同局不重播。這些檢查使用模擬顯示／輸入，不代表真人手感或真實瀏覽器／手機畫面已驗收。
