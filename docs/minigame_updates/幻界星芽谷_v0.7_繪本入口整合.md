# 幻界・星芽谷 v0.7｜繪本入口整合

本包合併月亮湖 v0.6 與森林星航瘋狂隊 v0.1（取得版本 13），延續累積整合方式。

入口消失的原因：星航包更新了共用 `MiniGameCatalog.js`、`main.js` 及 `PhantomRealmGame.js`，但這三個檔案仍使用繪本／月亮湖開發前的幻界內容。後覆蓋的版本使繪本卡片與場景註冊消失，原幻界入口也回到舊水車 3D。

## 本次修正

- 第一頁保留森林星航瘋狂隊，以及「幻界・星芽谷｜繪本版」。全部 23 款，沒有多算一個 3D 副本。
- 原 `phantom_realm` 遊戲 ID 和 `PhantomRealmGame` 場景名稱保留，內容直接使用繪本冒險。舊列表／地圖連結無需改名就能開新版。
- `PaperForestGame` 也保留為相容入口，兩者使用同一套繪本程式與存檔。遊戲列表只顯示一張卡片。
- 入口內容包含星之森、月亮湖、HP／MP、装備、技能 A／B、靠近自動對話與單一任務。
- 移除手帳和 `storybook-play.html` 的 A／B 比較、3D 選項。
- 合併星航的場景、規則、素材與註冊；其他小遊戲保持原內容。
- 繪本存檔仍是 `forest_storybook_adventure_v2`，不重設進度。舊繪本轉入規則照舊，其他存檔不刪除。歷史 3D 來源檔保留在累積檔案內，但正常入口不再使用。

## 安裝

把 `Phantom_Realm_v0_7_Storybook_Integrated.zip` 內所有檔案直接合併覆蓋原「森林益智樂園_v2_完整測試版」，不用分 UPDATE／DEMO，也不需要先刪除原專案。

關閉遊戲分頁、重啟原啟動程式，再開啟遊戲並按 Ctrl+F5。進入第一頁的「幻界・星芽谷｜繪本版」。請以此累積包作為後續更新基準，避免再用較舊的星航包覆蓋共同入口。

若使用同包的 `storybook-play.html`，由原網站伺服器開啟即可，現在只有繪本入口。

## 驗證範圍

28 項目錄／場景註冊、月亮湖、星航規則測試通過。瀏覽器另驗證23款目錄的繪本入口、舊／新場景名稱實際載入相同繪本 App、共用存檔、退出清理及單一網頁入口。場景掛載測試替代缺少的主遊戲底層 AnimalSnackGame 與 PlatformStorage（使用瀏覽器 localStorage）；入口場景、繪本 App、素材與規則均執行實際檔案。完整主遊戲與實機手機仍需在原專案驗證。
