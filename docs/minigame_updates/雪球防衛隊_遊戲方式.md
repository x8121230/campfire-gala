# 雪球防衛隊 v0.1｜幼童試玩版

## 目標

守護冰晶小屋，點擊雪怪自動丟雪球，讓 15 隻可愛雪怪變回亮晶晶雪花。

## 操作

- 滑鼠與觸控：直接點擊雪怪。
- 鍵盤：`1`、`2`、`3` 選擇上、中、下雪道中最靠近小屋的雪怪。
- `P`／Esc 暫停；「慢慢玩」降低移動速度；「幫我瞄準」標出最需要先處理的雪怪。

## 幼童友善規則

- 狐狸會自動朝點選的雪怪發射，不需要另外控制方向。
- 一般雪怪一顆雪球完成；圓滾雪怪有兩層厚雪。
- 每第 5 顆是大雪球，可以一次打掉兩層厚雪。
- 雪怪抵達小屋前會被柔軟雪堆安全彈回，不會 Game Over。
- 漏接只記錄次數，不扣進度、不扣生命。
- 共三階段逐步增加速度；可以隨時開啟慢速模式。
- 切到背景或視窗失焦時自動暫停。
- 不扣主畫面愛心、不發寶箱、不解鎖成就、不修改正式存檔。

## v0.1 驗收重點

1. 雪怪大小與點擊範圍是否足夠。
2. 雪怪速度、出現密度與三條雪道是否清楚。
3. 大雪球提示和圓滾雪怪兩層厚雪是否容易理解。
4. 觸控點擊、鍵盤選道及慢速模式是否正常。
5. 漏接彈回與完成結算是否正常。
