# 森林光路工坊 v0.1

2026-09-09。直接合併到森林益智樂園的小遊戲總表，累積 13 款，入口分類為「觀察推理」。交付一份整合更新 ZIP，延續使用者不需要獨立試玩版的要求。

## 設計與深度

以小學生能逐步學會的空間推理與條件組合為主。前五關教反射，第六關加入分支，第十一關起加入混光與濾色，第十六關起同時處理多條光路、不同配方與必須保持暗的水晶。20 關均可自由選擇；已熟悉反射的玩家可直接挑戰第三或第四章。

玩家需要預想調整一個機關會如何影響其他目標，也可以從水晶倒推光源。畫面即時呈現光路；最後由玩家按「啟動光路」確認。關卡為手工設計，不以隨機排列充當新關；重玩目標是減少調整與不用提示完成。

## 光路規則

- 鏡子在兩個斜向間切換，將光轉彎。分光片保留一路直行並產生一路反射。
- 可控制的光源能開關，標「固」的光源固定。光源外殼即使關閉也擋住別的光。
- 濾光片依紅 → 綠 → 藍 → 紅切換，只讓選定成分通過；沒有該成分就不會有光穿出。
- 紅光 + 綠光 = 黃光；綠光 + 藍光 = 青光；紅光 + 藍光 = 洋紅；三色 = 白光。這是混光，並非混顏料。
- 接收水晶累加收到的光色；必須與指定顏色完全相同，多出另一色不算成功。標「暗」的水晶必須完全沒有光。
- 光束交叉後各自前進，不把彼此的顏色帶去其他地方。沿同一段路的多色光以合成色顯示。
- 石牆與水晶會終止光束；光束照到水晶後不再穿出去。光路循環有狀態去重，不會無限運算。
- 這是簡化光學益智規則，分光不計強度衰減，圖中的三角機關不模擬真實稜鏡色散或折射角。

## 操作與輔助

| 操作 | 方式 |
| --- | --- |
| 調整機關 | 直接點機關、右側調整按鈕，或鍵盤 1–9 |
| 選取機關 | Tab／Shift+Tab |
| 調整目前選取 | 空白鍵 |
| 確認完成 | 「啟動光路」或 Enter |
| 撤回 | Z／Backspace／畫面按鈕 |
| 提示 | H／畫面按鈕 |
| 重來 | R／畫面按鈕，會先確認 |
| 暫停 | P／Esc／畫面按鈕；離開視窗也自動暫停 |
| 混光配方 | 左下角「查看混光配方」 |

沒有倒數。前兩次提示提供方向與具體思路，之後從目前配置計算下一個可調整的機關，不自動操作。暫停時不推進提示搜尋或提示圈時間，回來需手動繼續。試光錯誤會指出一顆不符合的水晶，保留配置和調整次數。

三星分別為完成、目標調整次數內完成、不使用提示。撤回會還原配置及調整次數，但不抹掉已使用提示的紀錄。重來會清除該次調整及提示。每關保留本次開啟中最高星數，不把不同次遊玩的星星條件拼在一起。返回選關後點同一未完成關可繼續；換關會開始新局。

## 整合與資料界線

新增 `src/scenes/LightWorkshopGame.js`、`src/data/LightWorkshopRules.js`、`src/data/LightWorkshopLevels.js`，並在 `src/main.js` 註冊場景、`src/data/MiniGameCatalog.js` 加入入口。場景沿用 AnimalSnackGame 的基本繪圖、按鈕及音效工具，遊戲規則獨立。

僅本次開啟保存星星，不接正式獎勵、愛心、收藏或地圖進度。保留原有四款新遊戲程式與素材。本包是累積差異更新，需覆蓋到既有完整專案；未附原始引擎、首頁或全套遊戲資源。

## 新增美術

兩份原創生成素材已直接放進更新包：

- `assets/light-workshop/sprites.png`：1536 × 1024，RGBA 透明 3 × 2 圖集，每格 512 × 512。包含貓頭鷹工匠、向右的黃銅光源、空鏡座、接收水晶、分光片、苔石。生成方向：童話手繪、靛藍青綠配暖黃銅、清晰剪影、無文字、每格留透明邊距。
- `assets/light-workshop/workshop.png`：1672 × 941，樹屋光路工坊背景。生成方向：暮色森林、木製拱架、黃銅燈與邊緣水晶架，中央低細節深青藍留白，無角色與文字。

精確鏡面方向、光束、目標標記、濾光顏色與介面由程式繪製，避免將解題資訊固定在插畫裡。

## 驗證與限制

65 項自動測試全部通過：新規則 16 項、新場景模擬 8 項、森林機關探險與海洋清理隊既有回歸 41 項。

20 關全部可解，沒有初始配置已完成的關卡；完整枚舉共 612 個機關配置，檢查光束有限終止、目標精確匹配與三星門檻可達。另驗證各方向反射、分光、混色、濾色、交叉不傳色、暗晶、光路循環、不可解資料、當前狀態提示與撤回。

場景以 Phaser API 模擬測試檢查全部關卡操作到完成、鍵盤、試光失敗、提示、暫停、重來、選關、離開清理。這不是完整瀏覽器渲染測試；實際 Game Viewer 畫面、觸控、音量及使用者本機整合仍待確認。

測試輸出見同資料夾 `森林光路工坊_測試結果.txt`。開發環境可執行：

```sh
node --test tests/light_rules.test.mjs tests/light_scene.test.mjs tests/mechanism_rules.test.mjs tests/mechanism_scene.test.mjs tests/ocean_rules.test.mjs tests/ocean_scene.test.mjs
```

後續應依玩家回饋調整後段關卡難度與節奏；持續採小學生程度、增加推理組合與變化的方向，直接整合進主遊戲。
