# 幻界・晨曦蒲公英丘陵 v1

## 場景狀態

晨曦蒲公英丘陵已完成第一版可玩整合，從星芽營地北門進入，並可由丘陵南側花環木橋返回營地北門。北側螢火古橡樹林出口已預留傳送錨點，目前依主線進度維持鎖定。

星芽營地北門的可行走通道已加寬，互動半徑提升為 150 像素；完成序章後，營地右上方另會顯示「前往丘陵」快捷按鈕。兩種入口都會進入同一個丘陵場景，避免舊存檔或觸控操作卡在狹窄碰撞區。

## 已完成內容

- 2.5D 童話繪本丘陵背景、跟隨鏡頭與鳥瞰模式。
- 可行走區、深水／岩石／邊界阻擋，以及全區連通性驗證。
- 草地波波鼠、蒲公英浮空雀、星芽露珠精靈、園藝小鼴鼠、貪食的南瓜兔。
- 草地波波鼠已換成星芽谷正式水彩版本，具備 8 個透明動作關鍵格：雙待機、雙滾動、抱頭受擊、驚嚇彈跳、撞牆暈眩與柔光消散。
- 被動、受擊逃跑、浮空、中立反擊、採集仇恨、水泡、泥團致盲與南瓜籽陷阱。
- 星光彈自動鎖定、閃步無敵幀、生命值、倒下後安全前哨復歸。
- MAIN_02「軟綿綿的試煉」與 MAIN_03「磨亮第一顆星核珠」。
- 晨曦蒲公英、香脆橡果採集，移動或受擊會中斷復古讀條。
- 彈性蒲公英的 3 秒移速增益。
- 蒲公英大遷徙隨機微事件、採集加倍與低機率星光微風種子。
- 獨立丘陵存檔，不會改寫星芽營地序章進度。

## 掉落規則

- 光團從怪物中心高拋約 1～1.5 個身位，果凍阻尼彈跳兩次。
- 落地後離地懸浮，週期約 1.2 秒。
- 一般磁吸半徑約 1.5 格；持有「橡果迅捷珠」後額外擴大。
- 掉落保留 60 秒，資料層預留擊殺者 15 秒歸屬保護。
- 任務光團標記為玩家獨立掉落，為未來隊伍同步預留。
- 柔白＝普通素材、明黃驚嘆號＝任務素材、星藍＝稀有靈珠。
- 貪食的南瓜兔必定爆出星藍靈珠與大量柔白光團。

## 操作

| 功能 | 鍵盤 | 觸控 |
|---|---|---|
| 移動 | WASD／方向鍵 | 左側搖桿 |
| 星光彈 | J／Space（按住） | 右側星光彈（按住） |
| 閃步 | Shift | 閃步按鈕 |
| 採集／傳送 | E | 互動按鈕 |
| 暫停 | Esc | 暫停按鈕 |

手機直向時會暫停並提示橫放，避免戰鬥按鈕與視野重疊。

## 驗證結果

- 丘陵、營地、主角與新版波波鼠整合測試：30/30 通過。
- JavaScript 語法檢查：通過。
- 怪物、採集點、出生點與兩個傳送錨點皆位於可行走區。
- 從出生點可經由碰撞導航抵達全部怪物、採集點與傳送錨點。
- 舊營地 NPC、MAIN_01、碰撞與存檔回歸測試通過。

全專案既有 npm 測試仍有一項與本更新無關的舊問題：灌木小遊戲「五成就舊存檔補發」斷言失敗。本次未修改該系統。
