# 水流迷宮・幼童版 v0.1

## 核心玩法

- 點擊大型水道，每次旋轉 90 度，把泉源與花朵之間的水路接起來。
- 五關使用 2、2、3、3、4 塊大型水道，依序加入直道、彎道與高低轉折。
- 接好後按「放水看看」，小水滴會沿目前路線前進，成功抵達時讓花朵盛開。

## 幼童友善設計

- 金色正確方向影子預設開啟，也可關閉進行純空間旋轉挑戰。
- 放水失敗不扣分，水滴會停在第一塊方向錯誤的水道並提供提示。
- 沒有倒數、步數限制、破裂水管或生命失敗，可不限次數旋轉與測試。
- 提供單格提示與本關重來；支援鍵盤 1～4、空白鍵、H、R、G。

## 整合範圍

- 首頁「棋盤策略」新增「水流迷宮」入口。
- 水世界正式地圖名稱仍未定案，本版先以獨立小遊戲驗證操作。
- 全部水道、水滴、泉源、花朵與水世界背景使用 Phaser 程式繪製。
- 本版不寫入正式獎勵、裝備、愛心或成就。
