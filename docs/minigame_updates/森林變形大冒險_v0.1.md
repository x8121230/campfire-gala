# 森林變形大冒險 v0.1

2026-09-09。使用者反映森林機關探險、森林光路工坊與森林快遞調度站雖然規則不同，但玩起來都偏向盤面解謎，因此本次依已討論方向製作真正的即時平台動作遊戲。重點是操作、變形時機、落點控制及高低支線探索。直接整合森林益智樂園，總表增至 15 款，入口歸在既有「反應節奏」分類（4 款）。

## 本次內容

12 關手工設計、4 章，由低洞、高跳、衝刺破藤逐步加入彈跳菇、限時石門、橫向葉舟、升降葉台、順逆風、上升氣流與預警落石。地形寬度約 1900–3300，畫面跟隨角色橫向捲動；高跳時也向上追蹤，避免角色飛出可見區域。

每關有三枚徽章，其中多關把一枚放在高處的可選路線。玩家可以選擇先抵達終點，或以更好的跳躍與變形操作取得全收集。每關第三顆星採不同任務：控制失足次數、使用三種形態、清除藤蔓、乘坐彈跳菇或啟動壓板。

這是短關卡形式的第一版，尚未做無限隨機關卡、長篇世界地圖或角色養成。三種精靈是同一角色的不同形態，沒有多角色切換選單。

## 三種形態

| 形態 | 操作定位 | 實際規則 |
| --- | --- | --- |
| 圓形 | 快跑、鑽洞、利用浮風 | 碰撞寬 30、高 28；地面速度 330；低洞高度 32；上升氣流降低其重力 |
| 三角形 | 高跳、衝刺破藤 | 碰撞寬 36、高 44；速度 270；跳躍初速 650；X 衝刺 0.18 秒、速度 660，冷卻 0.65 秒 |
| 方形 | 壓板、穩定抗風 | 碰撞寬 40、高 44；速度 210；風力位移影響為其他形態的 16%；在壓板站穩 0.45 秒開門 |

可在地面或空中變形，腳底位置保持一致。若變大會撞進低洞或牆壁，變形會被拒絕並顯示原因。只有三角形在衝刺中能清除藤蔓；普通行走或其他形態按 X 都不能破藤。

圓形加速快，但會更明顯被風帶動；方形在強逆風中能比較穩定地前進。上升氣流只加強圓形的跳躍。彈跳菇可由地面踩上或從上方落下觸發。

## 操作與容錯

| 操作 | 鍵盤 | 畫面按鈕 |
| --- | --- | --- |
| 左右移動 | ← →／A D | 左下左右鍵，可持續按住 |
| 跳躍 | 空白鍵／↑／W | 右下跳躍鍵，可與移動同時按住 |
| 圓／三角／方形 | 1／2／3 | 下方三個形態按鈕 |
| 三角衝刺 | X | 右下衝刺鍵 |
| 回到檢查點 | R | 暫停選單中的回到檢查點 |
| 暫停／繼續 | P／Esc | 右上暫停 |
| 整關重來 | 暫停選單 | 有確認步驟 |

按住跳躍可跳得較高，提早放開會縮短跳躍。支援離開平台後短暫 0.10 秒的補跳，以及落地前 0.12 秒的跳躍預輸入，降低小學生操作時剛好錯過邊緣或落地時機的挫折。

觸控保留至少三個觸點，可同時移動、跳躍與變形。手指離開按鈕或在畫布外放開會解除按住狀態；切到背景也會清除輸入。回到視窗後需手動繼續，重新按鍵或觸控，不會保留離開前的移動指令。

## 地形與檢查點

- 綠色葉舟可承載角色，包含水平移動與垂直升降。跳離後不再被帶著走。
- 葉舟與高處葉台是單向落腳平台，可從下方跳穿、從上方落下站住；土壁、低洞天花板、藤牆與石門都是實體障礙。
- 方形壓板開門 8 秒，離開壓板後可換形態過門。若門倒數結束時角色已在門內，會等角色清空門口後再關閉，避免夾進牆中。
- 金色垂直虛線與地面圈是 0.8 秒的落石預警，本身不造成失足；之後掉落的石頭有碰撞判定。
- 燈籠是檢查點，角色站在附近會點亮。失足、碰到落石或被移動平台擠入實體時會回到最近燈籠。
- 回檢查點會計一次失足，包括手動 R；已收集徽章、清除的藤蔓與本次能力使用紀錄保留，石門倒數與壓板充能重置，角色回到圓形。
- 沒有全局倒數、生命耗盡或主遊戲愛心扣除。落石週期、葉舟、石門倒數與重生等待在暫停時全部停止。

## 星星與進度

三顆星分別為抵達終點、收齊三枚徽章、完成本關特別挑戰。徽章及特別挑戰是額外目標，不會阻止一般通關。返回選關可接續目前未完成關卡；換關或整關重新開始會開新局。關閉頁面或重新載入後清空本次紀錄。

本次開啟中，每關只會保留最高星數，重新挑戰不降低既有記錄。不連接正式獎勵、收藏、愛心或長期存檔。

## 程式與整合

新增 `src/data/MorphRules.js`、`src/data/MorphLevels.js`、`src/scenes/ForestMorphGame.js`。規則使用固定 1/120 秒步進，負責角色加減速、跳躍、形態碰撞、地形與移動平台、風、落石、檢查點及星星。場景負責繪圖、鏡頭、按鍵與多點觸控。

沿用 AnimalSnackGame 的文字、按鈕及音效 helper，但本款採全寬動作畫面。沒有引入外部物理套件，也不要求修改主遊戲的 Phaser 物理設定。長幀最多推進 0.1 秒，避免背景卡頓後突然快轉穿過危險。

`src/main.js` 註冊 ForestMorphGame；`src/data/MiniGameCatalog.js` 增加第一張入口卡。舊測試僅更新總表數量與入口位置預期。其餘既有六款新遊戲場景、規則及素材保留原檔內容。

本包只有 `src`、`assets`、`docs`、`tests` 與根目錄安裝說明，直接覆蓋現有完整森林益智樂園。需既有分類總表 v4.0，不包含原始完整主程式、引擎、全套衣櫥或獨立 HTML 試玩入口。

## 驗證與界線

132 項自動測試全部通過：本次純規則 22 項、場景流程 12 項，既有四款遊戲回歸 98 項。

12 關均以連續的方向、跳躍、變形、衝刺及等待輸入完成，收齊三枚徽章、零失足並取得三星。驗證路線沒有傳送到終點、直接標記過關或關閉碰撞；收集、移動平台搭乘及石門都經過實際規則步進。

另測試 30／60／120 FPS 的一致性、長短跳、補跳與預輸入、低洞禁止擴大形態、衝刺防穿牆、壓板時間、門口防夾、風力差異、彈跳、移動平台承載、防擠壓、落石預警、檢查點還原與暫停。場景測試覆蓋多指同時移動與跳躍、移出畫布放開、鍵盤放開、背景暫停、鏡頭跟隨高跳、重新挑戰、返回列表與清除監聽。

場景測試使用 Phaser API 模擬。實際 Game Viewer 畫面、真實觸控手感、音量及使用者完整專案的整合仍待實機確認；不把模擬測試稱為實機驗收。

測試輸出：`森林變形大冒險_測試結果.txt`。開發可在解壓根目錄執行 `node --test tests/*.test.mjs`。連續操作驗證腳本在 `tests/fixtures/morph_routes.mjs`，僅供自動測試使用，不是遊戲內自動通關功能。

## 後續開發原則

使用者已明確指出連做盤面解謎會疲乏。後續規劃應交替安排即時動作、消除、節奏、競技等不同操作體驗，再回到推理類。不要只靠增加限制條件、關卡數或換題材來宣稱玩法不同。

本款下一輪優先依實玩調整跳躍手感、移動平台等待節奏、鏡頭與按鈕可讀性，再考慮延長關卡、加入新動作或更多可探索分岔。維持直接整合更新包，不恢復獨立試玩版或 UPDATE／DEMO 分層。
