確認問題
1. START_WINDOWS.bat 指向 START_PREVIEW.py；該預覽啟動器開啟 wardrobe-preview.html。
   新增 START_FOREST.cmd / START_FOREST.py 專門啟動主入口。
2. index.html 重複宣告 main.js 模組；本包整理成一次宣告。
3. src/data/BushExploreGenerator.js 第 70 行在 randomInt(0, 處截斷，語法不完整。
   對 src 的文字搜尋沒有發現其他檔案引用此模組，目前保留原檔，沒有臆造剩餘邏輯。
   未來要使用這個生成器，需補齊原始檔後再啟用。

- 掃描 386 個相對 import 引用，未檢出主 src 的缺失引用。

  遇到上述既有錯誤會回傳非零狀態，不代表錯誤已修好。
