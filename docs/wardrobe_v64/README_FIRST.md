# v6.4 裝備物品縮圖更新

本包適用於已安裝 v6.3「雙睡衣分離版」的森林益智樂園。只更換裝備清單圖示，不重畫或取代左側角色。

## 安裝

1. 關閉遊戲，先備份遊戲內這三個檔案：`src/data/FairyWardrobeData.js`、`src/data/PaperDollConfig.js`、`src/scenes/Collection.js`。
2. 解壓縮本包，將裡面的 `src`、`assets` 合併到遊戲根目錄（與 `index.html` 同一層），遇到同名檔案選擇取代。不是把整個更新資料夾套在外面；也不要刪掉原本的 src 或 assets。
3. 重新開啟遊戲並按 Ctrl+F5。衣櫃頁尾應顯示「v6.4 · 童話新裝 61 件 · 獨立物品縮圖」。
4. 檢查貪睡熊毛絨睡衣與星眠長抱枕睡衣：右側應是兩張不同的衣物圖，左側仍是穿戴後的人物。

本包包含新增的 `src/data/WardrobeIcons.js`，務必一併複製。漏掉它會造成模組載入失敗。

## 本次內容

- 31 件童話服裝各有一張獨立衣物縮圖，不再用全身人物。
- 休閒裝、粉色居家服另補兩張，共 33 張 256×256 PNG。
- 30 頂童話帽子沿用既有獨立帽子圖，飾品沿用原有物件圖。
- 圖示等比例縮放，缺圖顯示「待補圖示」，不以全身圖頂替。
- 稀有度、能力、造型圖層、裝備 ID、持有與穿戴狀態沒有因本次修改而改變。
- 圖示為淺奶油色實底縮圖。它們不是透明素材，不可拿來疊到人物身上。

解壓縮後可直接打開 `docs/wardrobe_v64/ICON_PREVIEW.html`，不用進遊戲即可看這批新圖。頁面僅是縮圖總覽，不代表已在完整遊戲中驗收。

## 驗證範圍與待辦

已做：新圖解碼與尺寸檢查、物品圖示設定、清單圖示函式測試、原有穿卸與 930 組帽衣配對邏輯測試；930 組是邏輯測試，不是逐組畫面驗收。

待在你的最新版遊戲確認：

- 頭部、服裝、能力飾品、收藏各分頁是否有「待補圖示」。若有，提供名稱或截圖，可精準補圖。
- v5.0 基礎資料中的其他 10 件舊服裝／套裝原有獨立 icon，本包保留。其最新版是否更換過素材，仍需對照你的實際遊戲。
- 獨立素材驗收台若也要用同一套縮圖，後續接入同一份圖示設定；本包尚未修改驗收台。
- 通用真透明版縮圖可後續另做；本版採用已檢查的實底，不將格紋背景誤認為透明。

這次沒有新增能力實作。先前睡衣的 Zzz 是外觀素材；打呼動態／音效及 futureAbility 中列出的玩法效果，仍屬待實作內容。

## 回復

要回到更新前，還原你備份的上述三個程式檔案並重新整理即可。新增的圖示資料夾與 WardrobeIcons.js 可留著，不會主動更改存檔。沒有刪除舊素材。
