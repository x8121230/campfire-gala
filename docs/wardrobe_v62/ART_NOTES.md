# v6.2 首組正式四層素材說明

本組實際使用三個槽位；`outfitBack` 目前不需要圖片：

| 槽位 | 素材 | 內容 |
|---|---|---|
| `outfitBody` | `outfit_bear_longpillow_v62.png` | 脖子以下的睡衣、手腳與普通長抱枕 |
| `headStyle` | `headstyle_nightcap_sleepy_v62.png` | 完整臉、表情、頭髮與素面睡帽 |
| `effectFront` | `effect_bear_nightcap_zzz_v62.png` | 透明的 `Zzz`，不含泡泡 |

三張圖固定為 RGBA、1024×1536、相同角色中心與比例。這一組只在兩件指定裝備同時穿戴時啟用，以免尚未重繪的舊帽搭配無頭衣服。
