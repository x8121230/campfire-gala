# v6.2.1 睡衣圖片載入修正

## 問題

同時裝備「貪睡熊毛絨睡衣」與「星光泡泡睡帽」後，人物仍顯示棕色舊版，畫面下方顯示「暫用原版」。

## 原因

v6.2 首包沒有附上 `src/data/PaperDollConfig.js`。若玩家的主系統仍是較早版本，新三層素材不會加入 Phaser 預載清單；安全機制因此判定圖片缺失並退回舊版。

## 修正

- 補上含 `LAYER_FILES` 預載登記的 `PaperDollConfig.js`。
- 更新版本提示為 `v6.2.1`。
- 重新附上三張 v6.2 圖片，避免第一次覆蓋時有漏檔。
- 新增預載清單自動測試。

解壓到遊戲根目錄並覆蓋同名檔案後，關閉舊遊戲頁籤，重新啟動本機伺服器，再按 `Ctrl + F5`。
