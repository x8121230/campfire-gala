1. 先備份「森林益智樂園_v2_完整測試版」。
2. 確認已套用 v6.0 與 v6.1。
3. 將本覆蓋包解壓到遊戲根目錄，合併資料夾並允許同名檔案取代。

- 睡帽表面不應再有泡泡圖案，`Zzz` 特效也沒有呼吸泡泡。
- 只裝睡衣、只裝睡帽，或任一新圖檔載入失敗：安全使用舊版素材。
- 卸下所有衣帽：顯示原本預設底裝。
