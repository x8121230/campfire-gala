# 童話衣櫃 v5.5

## 整合

沿用原 v5.4 Collection，一鍵穿卸、卡片選取框、滑入縮放、換裝音效與特效維持原流程。
新增 FairyWardrobeData，十件道具使用獨立穩定 ID；只補缺少的這十件到 owned_items，不重設其他存檔。
ITEM_DB 透過 PaperDollConfig 載入時增補，不覆蓋原 GameData.js，以保留完整專案自己的道具與預設資料。
effects 全部為空，未來效果仅在 futureAbility 字串中，不參與任何數值計算。

新服裝維持 1024×1536 母檔。新頭飾使用 1024×1800 畫布，頂部多保留 264 像素，避免橘子和星星裁切。
fitImage 對新頭飾使用原人物縮放比例，垂直校正 132 像素；衣櫃與原 CharacterManager 均沿用此共用函式。
舊版頭飾仍使用原規格。圖示另外提供緊密裁切素材。
雨衣 integratedHat=true，穿戴狀態中的外加頭飾保留，僅在顯示時隱藏。

## 素材

使用內建影像生成工具逐件生成，參照既有阿晨晨母檔，不使用不同人物替代。
生成檔來源對照見 assets/wardrobe_v55/asset-provenance.json。
使用者允許耳下髮型與髮色依服裝搭配；保留頭頂輪廓、瀏海、五官與姿勢。
對部分烘焙棋盤格的圖使用一般影像處理移除背景，帽子裁切、對位及透明 PNG 輸出。
蒲公英斗篷細絲保留，薄紗底層重建為低透明度象牙白，避免棋盤格殘留。
