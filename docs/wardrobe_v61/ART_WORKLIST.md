# 正式美術待辦清單

## 每件衣服都要做

- 以 1024 × 1536 透明畫布、相同人物中心點與比例輸出。
- 從 `outfitBody` 移除舊髮型、表情與頭部造型，保留固定頸部銜接位置。
- 用 30 頂帽子逐一混搭驗收，不可遮住臉部或留下雙重頭髮。
- 透明邊緣不得含白底、棋盤格或裁切殘影。

## 優先拆成 `outfitBack`

蒲公英絨毛斗篷、大象水車雨衣、蓬鬆松鼠連體衣、月光貓頭鷹披風、秋楓精靈飛膜斗篷、古銅齒輪工裝服、蒸汽飛行員皮夾克、發電線圈背包服、變色龍迷彩連身衣、孔雀開屏華麗舞裙、胖企鵝滑冰衣、暴龍大腳丫連體衣、劍龍骨板防護背包裝、翼龍滑翔飛翼裝。

## 優先補 `effectFront`

- 貪睡熊毛絨睡衣：穿衣本體改成抱枕抱在胸前；與睡帽組合時顯示呼吸泡泡或 Zzz。
- 發光苔蘚燈籠裙：幽藍苔蘚呼吸光。
- 古銅齒輪工裝服：動能蓄滿的齒輪閃光。
- 蒸汽飛行員皮夾克：衝刺白色蒸汽。
- 發電線圈背包服：藍色靜電弧。
- 孔雀開屏華麗舞裙：開屏時的寶石亮光。

## 睡衣＋睡帽組合定稿

| 圖層 | 內容 |
|---|---|
| `outfitBack` | 可留空；若抱枕後方有垂帶才放此層 |
| `outfitBody` | 毛絨睡衣＋雙臂抱住抱枕，頭部接口保持固定 |
| `headStyle` | 睡帽＋收進帽內的頭髮＋沒睡飽表情 |
| `effectFront` | 呼吸泡泡或 Zzz；只在睡衣與睡帽同時裝備時啟用 |

## 程式待辦

- 加入「衣服 ID＋頭飾 ID」組合特效條件表。
- 美術交付後逐件加入 `outfitBack`／`effectFront` 檔名。
- 在完整遊戲檢查場景切換、縮放、動作與特效清除。
- 童話能力要另做碰撞、冷卻、地圖條件與平衡測試。
