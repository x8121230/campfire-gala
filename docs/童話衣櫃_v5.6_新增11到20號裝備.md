# 童話衣櫃 v5.6｜11～20 號紙娃娃

本版以 v5.5 累積整合包為底稿，保留原本十件童話新裝，再加入五件頭飾與五套服裝。

## 紙娃娃規格

- 服裝母檔：1024×1536 RGBA，頭頂、腳底與人物中心沿用既有阿晨晨母檔。
- 頭飾母檔：1024×1800 RGBA，沿用 v5.5 加高畫布及 132 像素顯示校正。
- 角色頭身比例不變；依使用者允許，姿勢與髮型可小幅調整。
- 頭飾另有緊密裁切 icon，實際穿戴則使用完整 overlay。
- 所有圖片完成透明底與邊緣檢查；衣櫃和大地圖共用 `PaperDollConfig`。

## 存檔與互動

`ensureFairyWardrobe` 會以穩定 ID 只補入缺少的童話裝備，因此舊存檔更新後會取得 11～20 號，既有收藏、品質、水晶與目前穿戴不會被清空。`FAIRY_IDS` 現含 20 件，童話分類自動變成四頁。

穿卸仍走既有 `Collection` 流程：單擊穿上／再擊卸下、服裝互斥、頭飾獨立、綠框、已裝備標籤、滑入放大，以及人物光圈、星光、輕彈與換裝音效。

## 能力邊界

十個童話效果已逐件保存於 `futureAbility`，`effects` 保持空物件。本版不改角色速度、碰撞、NPC 感知、掉落、技能冷卻或獎勵倍數；後續應逐項接入實際關卡並個別驗證。

## 圖像生成規格

本版使用內建圖片生成，以日常阿晨晨作身分、比例、頭部中心及腳底基準，以 v5.5 蜜桃裝／既有帽子圖層作畫風與圖層參考。服裝逐件 identity-preserve，頭飾逐件 precise-object-edit；共同限制為透明背景、無文字、無場景、無額外肢體、完整頭腳及固定頭身比例。逐件來源見 `assets/wardrobe_v56/asset-provenance.json`。
