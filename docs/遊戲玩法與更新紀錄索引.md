## 共通設計原則

- 目前優先完成幼童版；成人／挑戰版保留資料欄位，之後再製作。
- 小朋友即使失誤，也盡量能把一局玩完；用提示、補救與鼓勵取代突然中斷。
- 各遊戲紀錄互相分離，GM 控制台也依「共用／各遊戲」分頁管理。
- 所有遊戲目前皆可直接遊玩；是否逐步解鎖，等整體框架完成後再測試決定。

## 更新文件規則

1. 修改程式時，同步更新該遊戲的「目前玩法」。
2. 在「更新紀錄」最上方新增日期、版本、變更內容。
3. 若更動存檔欄位、GM 功能或共用規則，也要在本索引補充。
4. 未完成的構想放在「後續候選」，不要寫成已完成。
