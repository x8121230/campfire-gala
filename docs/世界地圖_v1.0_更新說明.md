# 世界地圖 v1.0

## v1.1.1 森林入口流程簡化

- 移除森林三地點之間的連接線與大型圓圈。
- 三個入口改為獨立的童話繪本木牌圖標，不遮住背景地貌。
- 點擊晨光營地、翡翠樹海或苔光溪谷後，直接進入該地圖的遊戲入口畫面。
- 移除中途的子地圖資訊卡以及「自由探索／冒險挑戰」選擇畫面。
- 自由探索程式先保留但不顯示入口，方便未來評估後再啟用。
- 各地圖只顯示自己的遊戲：晨光營地 2 款、翡翠樹海 2 款、苔光溪谷 1 款。

## v1.1.0 森林繪本與幻界入口優化

- 世界地圖每個區域只保留一個大型橢圓熱區，不再疊加多顆迷霧小圓。
- 大型熱區依區域地貌調整寬高，盡量完整包住實際島嶼或地貌。
- 森林導覽頁改用全新童話繪本全景，畫面中直接呈現晨光營地、翡翠樹海與苔光溪谷。
- 晨光營地、翡翠樹海、苔光溪谷各自使用不同的 16:9 童話繪本背景。
- 幻界正式取消三子地圖流程；解鎖後點擊會播放異界漩渦轉場，直接進入 3D「幻界・星芽谷」。
- 新增 `RealmWorldGame` 包裝場景與首頁補註冊，避免直接入口發生場景未註冊黑屏。
- 幻界角色素材缺少時會使用內建繪製角色，不再因單一角色圖遺失而中斷載入。
- 修正解鎖判斷，使所有達到星星門檻的區域都能進行迷霧解鎖。

## v1.0.1 黑屏修正

- 修正首頁按下「開始冒險」後出現 `Scene key not found: WorldAtlas` 的黑屏。
- `main.js` 正式註冊五個世界地圖相關場景。
- 首頁另加入場景自動補註冊，避免舊版 `main.js` 被瀏覽器快取時再次黑屏。
- `index.html` 加入版本參數，強制重新載入新版入口。

## 本版完成

- 正式建立 10 個世界區域；其中 9 區採每區 3 張子地圖，幻界改為直達星芽谷。
- 首頁「開始冒險」改為進入世界地圖總覽。
- 使用正式世界地圖美術作為背景，所有區域都有可點擊熱區。
- 森林已開放，點擊後會先放大，再以樹葉遮幕進入區域繪本導覽頁。
- 森林包含晨光營地、翡翠樹海、苔光溪谷三張子地圖。
- 每張子地圖都有星星進度、貼紙狀態、服裝剪影、自由探索與冒險挑戰入口。
- 自由探索沒有倒數、生命或失敗；互動 6 次會取得參與貼紙。
- 冒險挑戰先接入既有 5 款正式森林遊戲，其他位置顯示「逐步開放」。
- 水世界解鎖條件為累積 3 顆星；達成後可用滑鼠或手指擦除迷霧，70% 自動完成，也可跳過。
- 世界進度寫入原本的 `forest_save_data`，不會另建互相衝突的存檔。

## 操作流程

首頁 → 開始冒險 → 世界地圖 → 森林 → 三張子地圖 → 資訊卡 → 自由探索／冒險挑戰。

## 資產說明

本更新包包含世界地圖及四張森林新背景。原始壓縮檔為縮小容量而未包含既有完整 `assets`，使用時需覆蓋到電腦中原本含完整素材的正式遊戲資料夾。
