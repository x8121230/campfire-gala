- 31 套童話衣服都有 1024×1536 無頭 `outfitBody` 與可替換 `headStyle`。
- 翼龍滑翔飛翼裝重新繪製比例，腳底、肩線與其他服裝一致；姿勢改為張臂滑翔。

- 衣服原本連著的帽子、頭套與髮飾不再烘焙在衣服身體層。
