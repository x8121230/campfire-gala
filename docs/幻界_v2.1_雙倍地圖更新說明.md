# 幻界 v2.1｜雙倍地圖與比例修正版

## 本次完成

- 星芽營地與晨曦蒲公英丘陵的世界座標由 1672×941 擴充為 3344×1882。
- 角色、NPC 與怪物維持原本閱讀尺寸；建築、門、道路、廣場與地貌相對角色放大兩倍。
- 兩張背景重新繪製並補上工房前庭、菜圃、休息區、丘陵戰鬥草坪、水域木橋、採集樹、鼴鼠花圃與支線步道。
- 所有碰撞輪廓、NPC 互動點、採集點、怪物出生點及南北傳送錨點同步換算到新版座標。

- 為較大的探索距離微調玩家步行與奔跑速度，鏡頭近距離閱讀比例不變，總覽模式可查看完整大地圖。

## 比例基準

- 阿晨晨約為一般工房門高的 70～80%。
- 可行走主路至少容納角色並排閃避，丘陵戰鬥空地保留投射物與翻滾距離。
- 裝飾物不取代碰撞資料；看得見的主路與橋面均納入連通測試。

## v2.2 修正

- 星芽營地改為四區塊原生細節重建，移除整張插值放大造成的模糊。
