阿晨晨・雲端滑翔 v1.4（水彩生物完成版）
========================================

安裝方式
1. 解壓縮本更新包。
2. 將內容複製到「森林益智樂園」遊戲根目錄。
3. 允許覆蓋同名檔案。
4. 開啟遊戲，到「小遊戲測試樂園」選擇「阿晨晨・雲端滑翔」。

操作
- 按住畫面／空白鍵／↑／W：上升，消耗耐力。
- 放開：滑翔下降，恢復耐力。
- 按住右下「俯衝蓄能」／↓／S：快速下降並累積風能。
- 右下「風能爆發」／X：消耗 35 風能短暫加速，可穿越彩虹爆發圈。
- 「航線提示」／H：顯示下一個風圈方向 3 秒。
- P／Esc：暫停。

新版內容
- 阿晨晨專屬水彩滑翔造型：雙馬尾、護目鏡、紅圍巾與翼龍飛翼。
- 完整童話水彩雲海背景，不再使用方塊人物與幾何背景。
- 三種手繪風圈：柔雲圈、稀有金圈、彩虹爆發圈。
- 金圈提供額外分數與風能；彩虹圈成功後會獲得晴空護盾。
- 阿晨晨在 v1.3 基礎上再縮小 10%（目前約為最初版本的 72%），飛行路徑更清楚。
- 阿晨晨新增平飛、拉升、俯衝、風能爆發四個水彩動作影格。
- 柔雲圈、金圈、彩虹圈各有四格水彩呼吸動畫。
- 風圈從遠方 0.6 倍逐漸放大到近處 1.0 倍，增加迎面飛來的景深感。
- 擦到內緣時會有柔和的微風吸附，不易因小幅偏移直接漏圈。
- 完美穿心加入水彩氣泡、星芒與分數飄字。
- 飛行儀表精簡為進度、愛心、耐力與風能；詳細紀錄集中於結算畫面。
- 開局操作提示改為圖示動畫，約三秒後自動淡出。
- 第 2、4 段加入上下分岔雲門；未主動選擇時會依阿晨晨高度自動選路，不會卡關。
- 星光捷徑增加金圈與速度壓力，柔雲航道會減少危險雲朵。
- 彩虹低谷增加彩虹爆發圈，雷雲高空則有更多金圈與障礙。
- 小雨燕會陪飛並提示航線，雲朵綿羊會恢復全部耐力。
- 最終航線加入暴風雲鯨流程，會交替吹出上升與下沉氣流。
- 風能爆發與俯衝兩個主要按鍵移到右下角並排，單手觸控更直覺。
- 小雨燕、雲朵綿羊、暴風雲鯨、厚雲、雷雲、雲鯨氣流與晴空護盾全數換成正式水彩美術。
- 上述七類生物、妨礙物與收集物各有四格循環／狀態影格；雲鯨吹氣時會切換專用動作。

開發註記
- 阿晨晨、背景、三種風圈、天空朋友、雲鯨與飛行障礙都已統一為正式童話水彩美術。
- 分岔選擇卡保留清楚的圖示與短文字，方便後續繼續測試航線節奏。
- 5 段航線、25 個成功風圈才完成。
- 耐力、俯衝蓄能、風能爆發、精準穿心、連擊與評級。
- 移動風圈、窄圈、極速圈、逆風、厚雲、雷雲及一次性晴空護盾。
- 漏圈或撞雲只會中斷連擊；流程不會因單次判定停住。

本包只含必要更新檔，不會覆蓋其他小遊戲內容。
