# 微光星芽谷 v3.20：南瓜兔動畫與攻擊美術

適用於已套用 **v3.19** 的主遊戲。關閉遊戲，將本包 `src` 與 `assets` 資料夾直接合併到遊戲根目錄，覆蓋同名檔案後重新啟動。只有必要更新檔，不是獨立遊戲。

## 本次內容
- 待機：8 張不同姿勢的真實影格，抱南瓜、啃食、眨眼、耳朵回彈、拍南瓜；約 1.76 秒一輪。依圖集逐格播放，沒有以放大縮小冒充動作。
- 透明圖集逐隻分離後重新排列，每格 384×448，留足耳朵及腳掌空間，統一腳底基準。角色碰撞中心維持原地。
- 原有起跳、攻擊、受擊與陣亡姿勢保留；這次新補的是待機影格及紅蘿蔔彈體。
- 落地：沿用既有 `bossSlam` 落地事件，新增向外伸展的分岔裂痕、碎石、塵霧與震盪圈，1.25 秒淡出。繪製在地面、角色後方，不建立障礙物，也不額外扣血。
- 南瓜兔遠程彈體改成巨大紅蘿蔔，4 張葉片動作影格以 10 FPS 循環，尖端沿飛行方向，帶暖金尾光與地面陰影。飛行速度、數量、射程、原有傷害判定維持原設定；外觀不等於新增整棵紅蘿蔔的碰撞面積。
- 僅標記南瓜兔在自身 AI 更新中產生的敵方彈體，不影響水精靈、小鼴鼠與其他怪物。

## 檔案相依
本版呼叫原先已安裝的 `PumpkinBoss.js`，沒有替換或重寫它。必須保留 v3.19 主遊戲及既有怪物、地圖素材。其餘 v3.19 導師任務、斬擊、四格道具、紀念品等級功能保留。
